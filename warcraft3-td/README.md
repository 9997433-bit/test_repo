# 边境要塞塔防 · Frontier Keep TD

独立目录中的《魔兽争霸 III》风格塔防致敬作。玩法参考 Element TD、Wintermaul 与经典迷宫 TD，**不含暴雪版权素材与专有名词**（画布绘制 + WebAudio 合成，英雄与地名均为原创）。

## 运行

用浏览器直接打开 `index.html`（`file://` 可用），或：

```bash
cd warcraft3-td
python3 -m http.server 8080
```

然后访问 http://127.0.0.1:8080/

## 操作

- 点选命令卡或快捷键建造四族防御塔（人类 / 兽族 / 暗夜 / 亡灵，各 3 系 3 阶）
- 左键选择，右键取消建造或给英雄下达移动
- `U` 升级 · `S` 出售（75% 退款）· `N` 下一波 · `Space` 暂停
- `F1` 选中英雄，`Q` `W` `E` 施法，`R` 大招（天罚圣光 / 钢铁旋风 / 混沌裂隙 / 亡者军团）
- `F11` 盟友面板：**伐木场升级**（利息 / 锻造 / 视野 / 修缮，木材购买）· `F9` 战斗日志
- 滚轮缩放，Shift+右键拖动镜头，`+`/`-` 调速

## 魔兽式规则

- 攻击类型 × 护甲类型倍率表（穿刺克轻甲、攻城克城甲、魔法克重甲、混乱打满……），
  命令卡 tooltip 与选中面板实时显示对当前波次的倍率
- 护甲减伤采用 TFT 公式 `0.06a / (1+0.06|a|)`
- 空中单位仅能被标记 `canHitFlying` 的塔攻击；魔免单位免疫 magic / spells
- 每 15 秒按未花费黄金结算利息（2%–8%，木材科技提升）
- 每 5 波 +1 木材；30 波，每 5 波单体首领（漏掉 -3 生命，普通漏怪 -1）
- 首领会践踏 / 再生 / 寒冰光环 / 邪影护罩，5 成减速抗性，半血狂暴

## 波次与难度（R1 平衡）

- 波次总血量按指数预算增长（每波 ×1.16，20 波后放缓为 ×1.11）；
  赏金与血量成比例，飞行波 / 魔免波血量有折扣但赏金不打折
- 难度改变手感：简单 0.7×血 / 30 命 / 怪速 -8%，普通 1.0× / 20 命，
  困难 1.3×血（前 12 波渐进）/ 15 命 / 怪速 +6%，疯狂 1.65× / 10 命 / +12%
- 平衡回归由 `tests/balance.mjs` 的确定性机器人把关：
  混合流机器人简单难度通关且 ≥10 命；三阶速升机器人普通难度通关；
  困难最佳机器人 ≥18 波；疯狂允许失败但需撑过开局
