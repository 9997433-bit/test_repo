# 余烬要塞 · 塔防 (Emberhold TD)

独立目录中的《魔兽争霸 III》风格塔防。灵感来自 Element TD、Wintermaul 等经典自定义地图。
全部美术与音效均为 canvas / WebAudio 程序化生成，**不含暴雪版权素材，也不使用暴雪专有名称**。

## 运行

直接用浏览器双击打开 `index.html` 即可（纯 `file://`，无需服务器、无需构建、无第三方依赖）。
也可以起一个静态服务器：

```bash
cd warcraft3-td
python3 -m http.server 8080
```

## 测试

```bash
node tests/run.mjs      # 91 项，零依赖
node tests/report.mjs   # 逐波次平衡报表
```

## 操作

| 操作 | 说明 |
| --- | --- |
| `1` `2` `3` `4` | 选择种族（人类王庭 / 兽人部族 / 月夜精灵 / 不朽亡军） |
| `Q` `W` `E` `R` … | 命令卡 4×3 快捷键，与暴雪的指令面板一致 |
| 左键 | 选中箭塔 / 小兵 / 指挥官；建造模式下放置 |
| 右键 | 取消建造；否则命令指挥官移动 |
| `H` | 选中指挥官并把镜头拉过去 |
| 空格 / `+` `-` | 暂停 / 调整游戏速度（1× 1.5× 2×） |
| 方向键、`WASD`、屏幕边缘 | 平移镜头；滚轮缩放 |
| `Esc` | 取消 → 取消选中 → 打开暂停菜单 |

## 与 WC3 玩法的对应关系

### 攻击类型 × 护甲类型

核心是原作的 7×7 伤害系数表（`js/data/damageTable.js`）。每次命中依次结算：

1. 在 `[最小, 最大]` 之间掷出基础伤害（使用固定种子的确定性随机数）
2. 加上 `bonusVsArmor` 对特定护甲的固定加成
3. 乘以「攻击类型 × 护甲类型」系数
4. 扣除护甲值减免：`1 - (0.06·A) / (1 + 0.06·A)`
5. 再乘以情境系数（溅射衰减环、闪电跳跃衰减、暴击）
6. 最低不低于 0

攻击类型：`普通 穿刺 攻城 魔法 混沌 英雄 法术`
护甲类型：`无甲 轻甲 中甲 重甲 加固 英雄 神圣`

选中箭塔时，状态面板会把整行系数列出来，并高亮当前目标的护甲列，
最下面一行直接给出「对某个具体小兵的实时 DPS」以及倍率 —— 换目标数字就会跟着变。

### 12 条箭塔路线（4 种族 × 3 路线 × 3 阶）

| 机制 | 路线 |
| --- | --- |
| 暴击 | 人类 · 哨塔序列，兽人 · 瞭望序列 |
| 攻城溅射 + 克加固 | 人类 · 火炮序列 |
| 魔法溅射，可对空 | 人类 · 奥术序列 |
| 中毒 + 减速，穿刺，可对空 | 兽人 · 投矛序列 |
| 闪电链，可对空 | 兽人 · 图腾序列 |
| 概率缠绕定身，仅对地 | 精灵 · 远古序列 |
| 酸液溅射 + 中毒 | 精灵 · 巢穴序列 |
| 多重射击，可对空 | 精灵 · 月井序列 |
| 幽魂穿刺 | 亡灵 · 幽魂序列 |
| 减速 + 蛛网（把飞行单位拽到地面），可对空 | 亡灵 · 蛛族序列 |
| 克重甲 / 加固 + 中毒溅射 | 亡灵 · 血肉序列 |

三阶终极形态需要木材。出售返还累计投入的 75%。

### 对空规则

只有同时满足「目标列表含 `air`」且「攻击类型属于 `穿刺 / 魔法 / 混沌`」的箭塔才能打飞行单位。
蛛网命中后飞行单位落地，落地期间任何箭塔都能打；缠绕则对空中单位无效。

### 弹道

弹丸会解算与目标当前速度的交点方程进行提前量预判；无正根时退化为直线射击。
溅射按 100% / 50% / 25% 三环衰减，且只会波及该箭塔本来就能命中的目标。

### 经济

初始 120 金 / 0 木 / 20 命（随难度缩放）。每 15 秒结算一次利息（2% 起，8% 封顶），
每 5 波掉落木材，Boss 额外掉落。提前召唤下一波可以吃到剩余倒计时的赏金。
