# 疯狂水世界

独立目录的网页复刻：洪水末世、自由木筏建造、拾荒 / 钓鱼 / 潜水、居民经营、英雄委任与关卡海战。

同仓库其他游戏请放在 `games/` 平级目录，不要改本目录。

线上地址（GitHub Pages 一级隔离）：https://9997433-bit.github.io/test_repo/crazy-water-world/

## 开发

```bash
cd games/crazy-water-world
npm install
npm run dev      # http://0.0.0.0:4174
npm test
npm run probe
npm run bench
```

## 操作

- 鼠标 / 触控：点击海面漂浮物拾荒，拖拽建筑摆放
- `B` 建造  `F` 钓鱼  `D` 潜水  `H` 英雄  `C` 关卡  `1/2/4` 变速  `M` 静音
- `Esc` 返回木筏
