## 0. 文件地图（谁该改哪）

| 文件 | 职责 | 改动纪律 |
| --- | --- | --- |
| `src/styles/tokens.css` | 全部 CSS 变量、字体、基础重置、`data-*` 钩子 | 加变量可以，改色值先过本文档色板 |
| `src/styles/layout.css` | 结构：网格 / 定位 / 尺寸 / 断点；顶部 `@import` 引入其余三层 | 不许写颜色和质感 |
| `src/styles/sea.css` | 皮肤：木板、遮阳棚、贴纸卡、按钮、鱼漂滑杆、玩法组件质感 | 装饰一律走伪元素，不碰点击目标 |
| `src/styles/motion.css` | 全部 `@keyframes` / `transition` / `@property` | 新动画必须过第 6 节预算 |
| `src/styles/a11y.css` | 焦点环、触控热区、色盲图案、对比 / 强制色彩偏好 | 覆盖顺序在 sea/motion 之后，别挪 |
| `src/ui/skin.js`（UI 侧，非美术地盘） | UI 轮新部件（`cww-*`）的结构打底，运行时注入 `<style>` | 美术不改此文件；styles/** 覆盖它见下方级联说明 |

级联顺序（Vite 内联后）：`tokens → sea → motion → a11y → layout 自身规则 → ui/skin.js 注入的 UI_CSS（运行时 append 到 head 末尾）`。

**覆盖纪律**：UI_CSS 排在最后，styles/** 想赢它不许用 `!important`，统一用祖先选择器抬一级优先级（`.cww-ghost .cww-ghost-cell`、`.panel .cww-meter`、`.cww-dive .cww-node`）。UI_CSS 的选择器最多两级（0,2,0），加一层祖先即稳赢。唯一例外是 motion.css 两条“减弱动态一刀切”，它们本来就是 `!important`。

## 1. 气质三军规

1. **末世但不丧**：残骸是玩具箱不是坟场。旧木板晒得发白也要配阳光黄描边。
2. **一切皆贴纸**：圆角 ≥10px、2–3px 墨线描边（`--ink`）、硬投影（`0 3px 0`）不用模糊投影表达「按得动」。
3. **歪一点才对**：遮阳棚歪 0.5°、启航卡歪 0.6°、救生圈斜 14°。手作感靠微小旋转，不靠噪点贴图。

母题词库：阳光、泡沫、旧木板、救生圈、歪遮阳棚、绳结、鱼漂、褪色救生衣。

### 2.3 用色守则

- 危险只用 `--coral`/`--buoy`，安全只用 `--kelp`，货币奖励只用 `--sun` 系——语义色不许串岗。
- 资源色全部使用 `--res-*`（16 个，与 `src/data/resources.js` 的 `RESOURCE_META` 逐项同步），画布浮标、后轮仓库图例都从这里取。
- 大面积深色只允许海与夜空；面板永远是奶油色系，避免「丧」。

## 3. 字体与标题层次

- 展示体：`--font-display`（ZCOOL KuaiLe）。**只有 400 字重**，禁止加 `font-weight: 700`（浏览器伪加粗会糊），tokens.css 已强设 400。
- 正文：`--font-body`（Noto Sans SC 400/600/700/900）。
- 数字一律 `font-variant-numeric: tabular-nums`（资源数、倒计时不跳宽）。

## 4. 昼夜 / 天气天空

天空 = 双色纵向渐变，token 与 `src/data/weather.js` 逐项同步：

| 天气 | `--sky-*-hi` | `--sky-*-lo` | 情绪 |
| --- | --- | --- | --- |
| clear 晴 | `#7ec8e3` | `#0e7c8a` | 默认，度假感 |
| haze 雾 | `#9bb7c4` | `#3d6d78` | 灰蓝，慵懒 |
| rain 雨 | `#4a6270` | `#16323c` | 压低饱和不压亮度到底 |
| storm 风暴 | `#1b2a33` | `#06151b` | 唯一允许的近黑 |
| tsunami 海啸 | `#14243a` | `#3a1020` | 底部渗一点血红预警 |

接线方式（后轮 UI 只需两行 JS）：

- 在 `html` 或 `.shell` 上落 `data-weather="clear|haze|rain|storm|tsunami"`，`.sea-wrap` 背景即随 `--sky-hi/--sky-lo` 走 **1.2s**（`--dur-scene`）`@property` 颜色渐变；不支持 `@property` 的浏览器直接跳变，可接受。
- 昼夜落 `data-phase="day|dusk|night"`：CSS 夜幕 `.sea-wrap::after` 的 `--night-alpha` 取 0 / 0.14 / 0.3，同样 1.2s 淡入。
- **注意**：`canvas.js` 目前自己画夜幕（`dusk < -0.2` 时叠 28% 黑）。后轮接管 `data-phase` 后必须删掉画布那笔，否则双重变暗。
- 天气永远同时有文字标签（顶栏「晴 · 1x」已有），不许只靠天色传达。

## 5. 形状语言与母题实现

全部零资产、纯 CSS，画布轮可直接抄公式：

- **救生圈**：`conic-gradient` 四段红白 + `radial-gradient` 环形 mask（`.title-screen > div::before`）。
- **歪遮阳棚**：红白 `repeating-linear-gradient` + 半圆扇贝 mask（26px 周期）+ `rotate(-0.5deg)`（`.topbar::after`）。
- **旧木板**：奶油罩色 + 每 92–120px 一道 3px 深木缝的 `repeating-linear-gradient`（顶栏 / 船坞）。
- **绳缝**：`outline: 2px dashed` 内缩 7px（面板）。
- **鱼漂**：滑杆 thumb 上红下白对半（`input[type="range"]`），节奏条指针同款红白对半（`.cww-needle`）。
- **泡沫浪**：三排错尺寸 `radial-gradient` 半圆 repeat-x（标题页）。

Round 2 玩法组件公式（同样零资产）：

- **建造三态格**：合法 = 实线深绿描边 + 中心白光 `radial-gradient` + 锚点 ✓；非法 = 虚线深红描边 + 45° 珊瑚斜纹 + 每格 ✕；拿起 = 点线阳光描边。三种**线型**先于三种颜色。
- **氧气条**：水蓝填充 + `13×9px` 气泡点纹（`radial-gradient` 平铺）；低氧切珊瑚 + 135° 斜纹。氧量数字常驻条内。
- **节奏条窗口**：绿窗两端 3px 白色「界桩」+ 内描边深绿；完美核 = 金底 + 90° 竖纹。窗口只画不写数（`FISHING_RULES.windowHidden` 口径）。
- **战报横幅**：display 体 + `rotate(-0.4deg)` 贴纸歪，🏆/🌊/🤝 前缀盖章；战报正文铺 22px 周期手账横线纸。
- **敌我血条**：我方 = 海藻绿纯色 + 光泽，敌方 = 珊瑚 + 135° 斜纹，阵亡 = 半透明 + 删除线。

## 6. 动效预算

| 层级 | 时长 token | 缓动 | 配额 |
| --- | --- | --- | --- |
| 触觉反馈（按压 / 悬停） | `--dur-tap` 90ms / `--dur-quick` 160ms | `--ease-out` | 不限，但只动 transform/filter/阴影档位 |
| 入场 / 一次性结算（面板 pop、战报横幅、上钩弹跳） | `--dur-pop` 240ms | `--ease-spring` | 每次界面切换或结算 ≤1 个 |
| 场景（天空 / 夜幕） | `--dur-scene` 1200ms | ease | 天气切换各 1 个 |
| **反馈循环（Round 2 新增）** | 0.8–1.6s alternate | ease-in-out | **同屏 ≤2**，只动 opacity/transform；现役：建造幽灵呼吸（建造屏 1 个）、低氧警报 + 危险圈（潜水屏至多 2 个） |
| 环境循环 | 5–18s | ease-in-out / linear | **≤3 个且仅标题页**；游戏内环境动效全部交给画布 |

硬约束：

- 属性白名单：`transform`、`opacity`、`filter`、`background-position`、已注册颜色变量。禁动 width/height/top/left 与 box-shadow 模糊半径。
- 禁止 >3Hz 闪烁（癫痫风险），禁止整屏晃动。低氧警报 0.8s alternate = 0.625Hz，远离红线。
- 反馈循环与环境循环的区别：前者携带玩法信息（预览未确认 / 氧气告急 / 鲨鱼贴脸），后者纯氛围。氛围永远不进游戏内 CSS，交给画布。
- ~~当前实现限制：`ui/app.js` 每帧重写 innerHTML~~ Round 2 UI 已改脏检查渲染（`ui/dom.js` 的 `setText/setClass/rebuildIf`），按压 / transition / keyframe 均正常生效，此限制解除。

## 7. 减弱动态（双通道）

1. 系统偏好：全部动画声明包在 `@media (prefers-reduced-motion: no-preference)` 内；`reduce` 命中时一刀切压到 0.01ms。
2. 游戏设置：`settings.reduceMotion` → UI 已接线，在 `documentElement` 落 `data-reduce-motion="on|off"`（选择器只匹配 `"on"`，`"off"` 与缺省等价），CSS 侧全局冻结，对 `ui/skin.js` 注入的 UI_CSS 同样生效（`!important` 压制）。画布侧同步冻结波浪，保持一致。

冻结清单（Round 2 扩充）：太阳浮动、浪drift、小船摇、救生圈摆、面板 pop、天空渐变（跳变代替）、建造幽灵呼吸、低氧警报、危险圈脉冲、战报横幅入场、上钩弹跳、吐司滑入。按钮按压位移保留（0.01ms 即时档，不属于「动态」）。

**不冻结的东西**：钓鱼指针扫动、潜水员 / 鲨鱼 / 点位的移动。它们是 JS 每帧写 `style.left/top` 的玩法本体，不是装饰——冻结它们等于游戏没法玩。reduceMotion 的承诺是「没有装饰性动态」，不是「画面静止」。

## 8. 色盲友好

原则：**颜色永不孤军**，每个用色状态必须另有图案 / 图标 / 文字 / 位置中的至少一样。

- 三条状态条：饱食 = 纯色 + 光泽 / 口渴 = 45° 白斜纹 / 生命 = 横向细纹，另各缝 9px 图标（🍗💧❤️）+ 条内数字文字（UI 已接 `role="meter"`），红绿色盲下依旧三形三态。
- 建造预览三态：合法 = **实线** + ✓ / 非法 = **虚线** + 斜纹 + ✕ / 拿起 = **点线**；预览标签文字再写一遍结论（✓/✕ 前缀 + 中文说明）。
- 氧气条：常态气泡点纹，低氧换斜纹 + 图标 🫧 + 条内百分比数字，三通道。
- 钓鱼窗口：绿窗白界桩（亮度通道）、金核竖纹（图案通道），提示文案同步说明「指针进绿区收杆，金条是完美区」。
- 战报：胜 / 负 / 平横幅各配 🏆/🌊/🤝 图标 + 文案本身写明结果；敌方血条斜纹、我方纯色、阵亡删除线。
- 语义按钮：出战（珊瑚）/ 吃喝交单（海藻绿）都配墨字 + 中文动词，不靠底色识别。
- 资源：仓库格永远「名字 + 数量」，`--res-*` 色只做辅助；深海稀有点位 = 金圈 + ★ 形状标记，画布浮标的形状区分仍留给画布轮（见第 13 节）。
- 天气：天色变化必配顶栏文字。
- 选中态（dock active / build primary）：阳光黄 **+ 上浮 2px 位移**，双通道。
- 英雄稀有度：标签文字（普通 / 稀有 / 史诗 / 传说）是主通道，卡片描边色只做氛围。
