## 1. 原型与基调

网页复刻益玩《疯狂水世界》的核心体验，而不是做一个泛化的“海上生存”。

- 设定：冰川融化、陆地沉没。玩家被命运钦点当“老大”，从一叶破木筏起步。
- 气质：清新卡通手绘 + 诙谐打工人幽默。末世但不丧，生存但不焦虑碾压。
- 一句话：海上拾荒，摸鱼不慌；自由建造浮岛，养活岛民，招募英雄，称霸废海。

## 2. 核心循环与新手 10 分钟

### 2.1 核心循环

```
海面点击拾荒 / 钓鱼 / 潜水
        ↓
   资源入仓（木、塑、铁、鱼、淡水、蓝图）
        ↓
 建造 / 升级建筑（自由拖拽网格）
        ↓
 生产加工 → 满足居民订单 → 经验 + 好感 + 漂流币
        ↓
 招募 / 委任英雄 → 加速生产或出战推图
        ↓
 解锁更远海域 / 更深层潜水 / 更猛天气事件 → 回到拾荒
```

## 4. 资源 reciprocal 总表

16 + 1 种资源（新增「工具」），每种必须同时有来源与去向，禁止死端。
完整来源/去向已写入 `resources.js` 的 `from`/`into` 字段，下面是回路图与本轮修复的三个死端：

```
拾荒/拾荒船 ─→ 木/塑/铁/绳/石 ─→ 建造·升级·扩建 ─→ 更多产能
钓鱼/钓鱼椅 ─→ 生鱼 ─→ 切鱼厂 ─→ 鱼片/熟食 ─→ 吃饭·订单 ─→ 经验/漂流币
净化器 ─→ 淡水(+盐) ─→ 喝水·灌溉农田 ─→ 小麦 ─→ 熟食配方·选种厂 ─→ 种子 ─→ 农田
关卡 ─→ 沙漏/徽章 ─→ 招募英雄 ─→ 推图/委任 ─→ 更快的一切
Boss首通+深海稀有点 ─→ 传说碎片 ─→ 升星 ─→ 更高的墙
潜水/灯笼鱼/稀有拾荒 ─→ 蓝图 ─→ 高级升级（核心瓶颈）
订单/关卡/图鉴首钓 ─→ 漂流币 ─→ 漂流商人（事件）买蓝图/沙漏/种子
```

**本轮修复的死端**（验收红3/红9 对应项）：

1. `shard`（传说碎片）：全库原本只有消耗无产出。现在两条获取链：
   Boss 关首通固定掉落（5/10/15/20/25/30 关 → 10/15/20/25/30/40，合计 140，见 `stages.js`）
   + 深海稀有点可重复刷取（`dive.js`：wreck 25 权重 ×1、city 45 权重 ×1–2、trench 60 权重 ×2–3）。
   全里程碑升星需求约 160（§8.3），关卡供 140、潜水补 20+，刻意留潜水缺口制造复玩动机。
2. `salt`（海盐）：来源 = 净化器副产（0.006/秒/级）+ 青壳蟹；去向 = 腌鱼配方（鱼片+盐→熟食×2）+ 订单。
3. `coins`（漂流币）：来源 = 订单奖励、关卡通关、图鉴首钓；去向 = 漂流商人事件（买蓝图/沙漏/种子/建材）、招募居民。
4. `wheat`：新增去向 = 熟食配方（生鱼+小麦→熟食）与选种厂维持消耗，农田反过来吃淡水（`farm.input`），形成水→麦→种→更多田的正循环。
5. `tool`（工具，新资源）：来源 = 工坊配方（木2+铁1→工具1）；去向 = 高等级升级附加消耗（≥4 级）、围栏加固、高阶订单换蓝图。

`diamonds` 仅作后期加速，免费来源 = Boss 首通与图鉴首钓（禁逼氪节奏，无付费入口）。

### 4.3 居民与订单（`orders.js`，接线）

- 订单池 9 种，按 HQ 等级分 3 档；交单后轮换抽取、同居民不连抽同单，需求数量随 HQ 放大（+15%/级）。
- 居民池 6 人（含开局阿强），广播站按等级招募，人口上限 = Σ小屋 pop；每人有岗位被动（对口建筑 +8%，同岗可叠 3 层）。
- 超时 240 秒不交单：心情 −10 并轮换，不没收资源（保持“不焦虑”的基调）。

## 6. 探索三线

### 6.1 海面拾荒（现行为主）

主视角点击漂浮物；权重表见 `salvage.js`（蓝图 2% 稀有闪光）。风暴/海啸刷新 ×0.35。
拾荒船建筑提供挂机版（§5），天气用 `salvage` 轴。

### 6.2 钓鱼（节奏条规格，`fish.js`）

- **交互（接线，替换滑杆+明示数字）**：指针在节奏条上 0→1→0 往返扫动，基准一个来回
  `FISHING_RULES.barSweepSec = 1.6` 秒，单鱼实际速度 ×`fish.bar`（0.85–1.55）。
  窗口画成条上的高亮区（`windowHidden: true`，禁止数字泄底），点按收杆：
  窗口内 = 命中；窗口中心 35% = 完美，产物 ×2（蓝图等唯一掉落不翻倍）。
- **窗口可玩规则**（表内自检通过）：窗口整体在 [0.12, 0.88]；宽度下限
  junk/common ≥ 0.16、rare ≥ 0.12、epic ≥ 0.09、legend ≥ 0.07。
  灯笼鱼窗口 0.20–0.34（宽 0.14）——蓝图鱼技巧可达，修复“半数鱼种不可命中”（验收红1 数据侧）。
- **鱼池**：18 鱼种 4 海域。近海 7 种开局可钓；远洋 5 种 + 深海 4 种随潜水船坞入池（现行逻辑已支持）；
  深渊 2 种（幽灵灯鱼、海王鱼苗）待 `SEAS.abyss` 解锁条件接线。
- **图鉴（接线）**：`rarity` 分档剪影图鉴；`firstCatch` 首钓一次性奖励（币/钻石）；`xp` 替换现行写死 +6。
- 天气：`WEATHERS[*].fishing` 为咬钩率倍率，海啸 = 0 禁钓。

### 6.3 深海潜水（`dive.js`）

三个区域 wreck / city / trench，由船坞等级 + 通关数解锁；氧气、氧耗、鲨鱼数、
普通点/稀有点加权表全部在 `DIVE_ZONES`，通用常数（移速 18、拾取半径 5、鲨鱼半径 6、
上浮深度 8、失败掉血 18）在 `DIVE_RULES`，与现行 `dive.js` 硬编码一一对应，接线时直接替换。
稀有点是 shard 的复刷来源（§4），必须有区别于普通点的持续闪光。
天气 `diveO2` 为氧耗倍率，海啸 = 0 禁潜。

## 7. 英雄与战斗（`heroes.js`）

### 7.1 阵容

品质：普通 / 稀有 / 史诗 / 传说（`RARITY_MULT` 1 / 1.08 / 1.16 / 1.28）。
原作七将全保留：大嘴山姆（坦/嘲讽）、一龙（连珠）、米娅（治疗）、巫师老侃（AOE）、
兰博（爆发）、微醺之龙（酒劲 buff）、机器屠夫（铁钩）。
新增三名开荒英雄补招募梯度：铁皮罐头（普通坦，二星嘲讽）、椰子妹（稀有射手）、水博士（稀有奶）。

### 7.2 数值公式

- 战斗属性 = `base × RARITY_MULT × (1 + (star−1) × growth)`。growth 入表（0.16–0.2），
  现行代码写死 0.18，接线后按表。
- 技能字段补全：`kind/value/star/period/target/desc`。period 与现行 `t%4/t%3/t%5` 对齐；
  连珠目标口径 = 1 + value×0.1（现行写死 ×1.15，接线后 value=2 → ×1.2）；
  酒劲（buff）现行无实现分支，规格：每 3 回合自身攻击 ×1.35，最多叠 3 层（Round 2 必接，验收 G-P2）。
- 委任：加成 = 1 + star × 0.12（现行）；接线后委任到 `assign.likes` 对口建筑时星级项 ×2
  （如二星山姆守围栏 = 1.48）。
- 招募（接线）：`recruitCost`，沙漏招普通/稀有（4–8），徽章招史诗/传说（4–10）；米娅剧情赠送。
  广播站等级控制档位。
- 升星：消耗 shard = 星级 ×10（1→5 全程 100/人），上限 5 星，口径入 `STAR_RULES`。

### 7.3 战斗规则

5v5 自动战棋：前/后排两列，出战上限 5 人（`STAGE_RULES.teamCap`，现行全员上阵待接线），
10 秒后可跳过，结果由纯函数复现（同 seed，seed = `meta.seed + stage×99` 不变）。

## 9. 动态世界

### 9.1 昼夜与天气（`weather.js`）

昼夜 4 分钟一天（可加速）。五档天气轴：`salvage`（拾荒/拾荒船）、`prod`（生产）、
`damage`（天灾伤害）不变；新增 `hunger/thirst`（生存消耗）、`fishing`（咬钩，海啸禁钓）、
`diveO2`（氧耗，海啸禁潜）、`stillBonus`（暴雨接雨水 ×1.4）、`durationSec`、
`warnSec`（风暴 12 秒 / 海啸 25 秒预警撤离窗口）。
天气权重按 HQ 等级分档（`WEATHER_SCHEDULE`）：HQ1 无风暴海啸——开荒 10 分钟不被天灾打断；
HQ5 起全档开放。现行全局 `WEATHER_WEIGHTS` 保留为回退。

### 9.2 随机事件（`events.js`，接线）

海盗袭击（可战可躲，战力 = 最高通关 ×0.6）、鲨群过境（禁钓 + 潜水加鲨）、
漂流商人（coins 唯一大额去向）、海鸥快递 / 风平浪静（正反馈小事件）。
每 45 秒掷一次、基础 12% 概率、事件间隔 ≥120 秒、每昼夜 ≤3 次；袭击类有预警时长；
开荒期（<3 关 / HQ1）不出袭击。种子公式与天气同源，保证可复现。
