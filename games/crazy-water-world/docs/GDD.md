# 疯狂水世界 · 游戏设计文档（GDD）

## 1. 原型与基调

网页复刻益玩《疯狂水世界》的核心体验，而不是做一个泛化的“海上生存”。

- 设定：冰川融化、陆地沉没。玩家被命运钦点当“老大”，从一叶破木筏起步。
- 气质：清新卡通手绘 + 诙谐打工人幽默。末世但不丧，生存但不焦虑碾压。
- 一句话：海上拾荒，摸鱼不慌；自由建造浮岛，养活岛民，招募英雄，称霸废海。

## 2. 核心循环

```
海面点击拾荒 / 钓鱼 / 潜水
        ↓
   资源入仓（木、塑、铁、鱼、淡水、蓝图）
        ↓
 建造 / 升级建筑（自由拖拽网格）
        ↓
 生产加工 → 满足居民订单 → 经验 + 好感
        ↓
 招募 / 委任英雄 → 加速生产或出战推图
        ↓
 解锁更远海域 / 更深层潜水 / 更猛天气事件
```

## 3. 生存三指标

对玩家（老大）与每位居民结算：

| 指标 | 下降触发 | 补给 | 归零后果 |
| --- | --- | --- | --- |
| 饥饿 | 时间流逝、劳动 | 熟食 / 生鱼片 | 生产效率腰斩，随后掉血 |
| 口渴 | 时间流逝、暴晒 | 淡水 | 同上 |
| 生命 | 饥饿/口渴归零、战斗、海啸、鲨鱼 | 医疗建筑 / 食物 | 角色暂时倒下，需救援 |

## 4. 资源

- 基础：浮木、塑料、废铁、绳索、石材
- 生存：生鱼、熟食、淡水、小麦、海盐
- 稀缺：蓝图、沙漏、徽章、传说碎片
- 货币：漂流币（贸易）、钻石仅作后期加速（网页版给足免费途径，禁止逼氪节奏）

## 5. 建筑（最小可玩集合）

| id | 名称 | 功能 |
| --- | --- | --- |
| hq | 指挥中心 | 等级上限、委任加速、解锁科技 |
| house | 小屋 | 人口上限 + 休息回复 |
| fish_chair | 钓鱼椅 | 解锁钓鱼小游戏与自动摸鱼 |
| fish_plant | 切鱼厂 | 生鱼 → 生鱼片 / 熟食 |
| farm | 海上农田 | 种植小麦等 |
| seed | 选种厂 | 产出种子，后期粮食瓶颈 |
| still | 淡水净化 | 海水 → 淡水 |
| salvage | 拾荒船 | 自动海面收集 |
| dive_dock | 潜水船坞 | 解锁深海探索 |
| radio | 广播站 | 招募英雄 / 居民 |
| workshop | 工坊 | 工具、围栏、装备 |
| wall | 围栏 | 抗风暴 / 海盗 |

建筑必须支持：网格占用、自由拖拽、旋转（0/90）、邻接加成、升级消耗蓝图。

## 6. 探索三线

1. **海面拾荒**：主视角点击漂浮物，带轻微物理漂流与稀有闪光。
2. **钓鱼**：节奏条 / 鱼种图鉴，不同海域鱼池不同。
3. **深海潜水**：侧视或俯视氧气条，沉船 / 沉没都市，躲鲨鱼，捞蓝图。

## 7. 英雄与战斗

品质：普通 / 稀有 / 史诗 / 传说。

预设角色（必须可玩，不可只写名字）：

- 大嘴山姆：主坦，三星解锁嘲讽全场
- 一龙：远程持续输出
- 米娅：治疗 / 护盾辅助
- 巫师老侃：减益与群体法术
- 兰博：爆发主 C
- 微醺之龙：近战战士
- 机器屠夫：钩人集火

战斗为 5v5 自动战棋：前排 / 后排两列，10 秒后可跳过，结果必须由纯函数可复现（相同种子）。

## 8. 动态世界

昼夜循环（4 分钟一天，可加速）。天气：晴、薄雾、暴雨、风暴、海啸预警。风暴降低拾荒刷新、伤害未加固建筑。海盗与鲨鱼为随机事件。

## 9. 胜利与失败

- 无硬失败：木筏可被打残，但总能从废板重启（符合轻松气质）。
- 软目标：指挥中心 8 级、推过 30 关、建成浮动城邦（≥18 格木筏 + 8 种建筑）。

## 10. SOTA 体验门槛

- 60fps 海面（目标），低配降粒子
- 全中文 UI，语音气泡用“老大”口吻
- 键盘 + 鼠标 + 触控
- 本地存档，刷新不丢
- 无障碍：减弱动态、色盲友好资源色
- 独立目录，零框架污染
