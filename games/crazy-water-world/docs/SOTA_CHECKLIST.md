# SOTA 验收清单（分级可勾选版）

> Round 1 由 Fable-4 验收官重写为 P0/P1/P2 分级清单。
> 勾选状态 = 截至 Round 1 实测结果（见 `ACCEPTANCE.md` 复现步骤）。
> 规则：P0 全绿才允许对外宣称可玩；P1 全绿才允许宣称 SOTA；P2 是打磨项。
> 每项附「验证」方法，后续轮次改完必须按验证方法回归后才能勾选。

## A. 手感（Game Feel）

- [ ] **P0** 钓鱼计时输入真实有效：玩家拖动/点按的时机值必须传入 `resolveHook`，不被渲染循环重置。
  验证：开钓鱼屏，把计时控件拖离默认值，下一帧检查值未被重置（jsdom 复现脚本见 ACCEPTANCE R1-红1）；实机连钓 10 次，非窗口时机必须脱钩。
- [ ] **P0** 钓鱼是节奏交互而非「读数字填空」：目标窗口不能以数字直接泄底，需要移动指针/节奏条实时收杆。
  验证：人工玩 5 次，闭着眼按不该稳定命中；`tuna`（窗口 0.28–0.40）与 `angler`（0.20–0.34）必须可通过技巧钓到。
- [ ] **P0** 潜水场景可见：canvas 必须渲染潜水员、氧气条、鲨鱼、资源点；不能只有一行文字。
  验证：造潜水船坞→下潜，肉眼可见鲨鱼移动并可主动躲避；捞到 `n2` 蓝图点后仓库蓝图 +1。
- [ ] **P0** 潜水操作用真实帧时长（dt）且按住方向键连续移动，不依赖键盘自动重复。
  验证：按住 A 键 1 秒，位移 ≈ 18 单位（`spd*dt` 积分）；代码中不得出现硬编码 `0.032`。
- [ ] **P1** 建筑可拖拽移动：`moveBuilding` 必须有 UI 入口（拖拽或选中后点新位置）。
  验证：放一座小屋，拖到新格子，旧格清空、新格占用；拖到非法位置时回弹并提示原因。
- [ ] **P1** 建筑可旋转（0/90）：建造与移动时可切换朝向。
  验证：2×1 小屋按 R（或按钮）后以 1×2 落位，`tiles` 占用与 `footprint` 一致。
- [ ] **P1** 放置有幽灵预览与失败反馈：悬停显示绿/红占位，失败时展示 `canPlace().reason`。
  验证：把 2×2 农田悬停在木筏边缘，出现红色预览与「超出木筏」提示；成本不足时提示缺什么。
- [ ] **P1** 拾荒点击命中判定用二维距离（x 与 y），且只在木筏/主屏生效。
  验证：点击漂浮物正上方远处海面不应捡取；在英雄屏点海面不应捡取。
- [ ] **P2** 拾荒漂浮物有稀有闪光动画与收集飞入动画（reduceMotion 时静态替代）。
  验证：肉眼观察蓝图漂浮物有区别于普通物的持续视觉提示。

## B. 信息层次（UI/UX Hierarchy）

- [ ] **P0** 三条状态条（饥饿/口渴/生命）必须有文字标签与数值，不能只靠颜色。
  验证：截图给不看色彩的人辨认，能说出每条是什么、值多少。
- [ ] **P1** 建造菜单展示成本、占地、当前资源是否足够。
  验证：木材不足时「拾荒船」按钮呈禁用态并显示缺口数量。
- [ ] **P1** 升级/委任有可发现的 UI 入口（当前 Shift+点击 / Alt+点击是隐藏操作）。
  验证：新玩家不看代码/README，3 分钟内能完成一次升级与一次委任。
- [ ] **P1** 战报可读：战斗结算展示完整 `BattleResult.log`（回合流、技能触发、存活血量），可跳过。
  验证：打第 1 关，能看到「大嘴山姆开启嘲讽全场」等技能行与双方剩余血量。
- [ ] **P2** 新手引导：启航后前三步（拾荒→建钓鱼椅→交订单）有指引气泡。
  验证：清档新开，跟指引 2 分钟内完成第一笔订单。
- [ ] **P2** 软目标追踪 UI：指挥中心 8 级 / 推过 30 关 / 浮动城邦（≥18 格 + 8 种建筑）进度可见。
  验证：主屏或菜单能看到三个目标的当前进度。

## C. 存档（Persistence）

- [x] **P0** 本地自动存档，刷新不丢：4 秒间隔写 `cww.save.v1`，标题屏可「继续漂流」。
  验证：开局造一座建筑，等 5 秒刷新页面，点继续后建筑仍在。
- [ ] **P0** 旧档/缺字段容错：load 后与 `defaultState` 深合并，缺失字段回填默认值，坏 JSON 走新档。
  验证：手工删除存档 JSON 里 `world.weatherTimer` 后载入，天气系统仍轮转（当前会 NaN 锁死，见 ACCEPTANCE R1-红6）。
- [ ] **P1** 离线补算：关页一段时间后回来，按 `idleSince`/时间戳结算生产（有上限），并弹「离线收益」摘要。
  验证：造钓鱼椅存档，改系统时间或 mock 时间戳 +1 小时载入，生鱼增量 > 0 且有摘要提示。
- [ ] **P2** 存档版本迁移与导出/导入（文本串）。
  验证：`cww.save.v1` → v2 迁移函数有单测；导出串可在清档后导入还原。
- [ ] **P2** `beforeunload` 时落盘，避免最多 4 秒进度丢失。
  验证：捡到资源后立即关页重开，资源仍在。

## D. 无障碍（Accessibility）

- [ ] **P0** 减弱动态有 UI 开关（当前 `settings.reduceMotion` 只有状态无入口），并尊重 `prefers-reduced-motion`。
  验证：开关后海浪振幅归零（canvas 已支持）；系统级 reduce motion 时默认开启。
- [ ] **P0** 静音状态在载入存档后生效：启动时须以 `settings.muted` 调 `setMuted`，并提供可见按钮（非仅 M 键）。
  验证：静音→刷新→点任意音效动作，无声。
- [ ] **P1** 键盘可完成核心循环：拾荒（或替代性「一键打捞」）、建造、交订单不强制鼠标。
  验证：拔掉鼠标用 Tab/快捷键走通「捡资源→建小屋→交订单」。
- [ ] **P1** 色盲友好：资源圆点加形状/图标区分，不只靠色相（GDD 明确要求）。
  验证：灰度截图仍能区分木/塑料/蓝图漂浮物。
- [ ] **P2** 按钮有 aria-label，焦点态可见；触控目标 ≥ 44px。
  验证：Lighthouse a11y ≥ 90。
- [ ] **P1** 触控可玩全部三线：潜水需要虚拟摇杆或点按移动（当前潜水必须 WASD）。
  验证：浏览器设备模拟为触屏，完成一次带战利品的潜水。

## E. 性能（Performance）

- [ ] **P0** 渲染循环不得每帧重建 DOM：`meters/left/right/dock` 只在相关 state 变化或屏幕切换时更新。
  验证：DevTools Performance 录 5 秒，无每帧 innerHTML 布局风暴；滑杆/按钮 hover 不闪烁。
- [ ] **P0** bench 必须测到声称的负载：给足资源真实放置 40+ 建筑后测 `tickWorld`，报告 `buildings >= 40`（当前报告 `buildings: 0`，门槛虚测）。
  验证：`npm run bench` 输出 JSON 中 `buildings >= 40` 且 `tickMs` 门槛保持。
- [ ] **P1** 有浏览器侧 fps 探针：主场景 40+ 建筑 + 满漂浮物时统计平均 fps，目标 60、低于 30 报警。
  验证：`?fps=1` 或调试面板显示实时 fps；录屏证明。
- [ ] **P1** `tickWorld` 摆脱整状态 `structuredClone`（4x 速时每秒 40 次全量克隆）。
  验证：bench 中 `tickMs` 在 40+ 建筑下 < 1ms；profile 无 clone 热点。
- [x] **P2** 生产构建可用：`npm run build` 通过，产物 gzip < 100kB。
  验证：`npm run build`，检查 dist 体积（R1 实测 JS gzip 12.63kB）。

## F. 内容密度（Content Density)

- [ ] **P0** 升星链路可达：`shard`（传说碎片）必须有真实获取来源（关卡首通/Boss 掉落/潜水稀有等）。
  验证：从新档正常游玩推图 ≤ 10 关内可完成一次升星（当前 shard 全游戏无来源，升星永久死路）。
- [ ] **P1** 居民系统成立：radio/小屋能增加居民，多居民各有订单与岗位；订单奖励轮换不退化。
  验证：造广播站招 1 名新居民；连续交 5 单，订单需求/奖励有变化（当前第二单起永远 meal×1）。
- [ ] **P1** 随机事件上线：海盗袭击与鲨鱼事件（`world.event` 当前恒 null），风暴对未加固建筑有实际后果。
  验证：加速游玩 10 分钟至少触发一次事件，日志与画面均有表现。
- [ ] **P1** 每种建筑有职能闭环：workshop 有产出/合成，house 人口上限生效，wall 减伤可在 UI 感知。
  验证：逐一放置 12 种建筑，说得出每种的可观测效果。
- [ ] **P2** 鱼类图鉴：6+ 鱼种收集进度、首钓奖励。
  验证：图鉴屏显示已解锁/未解锁剪影。
- [ ] **P2** 货币闭环：coins 有获取与消费（贸易），diamonds 有免费获取途径（禁逼氪节奏）。
  验证：完成一次用 coins 的交易。
- [ ] **P2** 关卡多样性：30 关不只数值膨胀，5 的倍数 Boss 关有机制差异（当前仅换名换血量）。
  验证：打 5/10 关，Boss 战斗日志出现独有技能行。

## G. 原作还原度（《疯狂水世界》Fidelity）

- [x] **P1** 七位预设英雄全部可玩且技能有实现：山姆嘲讽、一龙连珠、米娅治疗、老侃AOE、兰博爆发、屠夫铁钩。
  验证：单测 + 战报中出现对应技能行。（微醺之龙 `buff` 技能未实现 → 记 F/P2 补）
- [ ] **P2** 微醺之龙「酒劲」buff 技能在战斗中生效（当前 `kind: "buff"` 无任何实现分支）。
  验证：同 seed 对照：带/不带酒劲的输出差异符合 `value: 0.35`。
- [ ] **P1** 5v5 自动战棋成型：上阵位选择（前/后排）、最多 5 人、10 秒后可跳过。
  验证：拥有 6+ 英雄时必须做取舍；跳过按钮生效且结果与完整播放一致（同 seed）。
- [x] **P0** 战斗纯函数可复现：同 seed + 阵容字节级稳定。
  验证：`tests/combat.test.js` 的 `toEqual` 断言 + probe 通过。
- [ ] **P1** 科技解锁挂在指挥中心等级（GDD：hq 提供等级上限/解锁），而非仅玩家等级；不造 HQ 应有实际约束。
  验证：不建 HQ 时高级建筑不可解锁；升级 HQ 后解锁列表扩展。
- [x] **P1** 昼夜（4 分钟/天）+ 五档天气改变海面颜色与产率。
  验证：`tickWorld` 单测 + 观察 `WEATHERS[*].prod/salvage` 生效；夜晚画面加暗。
- [ ] **P2** 「老大」口吻语音气泡与打工人幽默文案覆盖主要交互（当前仅日志有少量）。
  验证：交订单/升级/事件均有气泡台词。
