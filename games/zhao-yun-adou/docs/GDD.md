# 赵云与阿斗 · 游戏设计文档（基线）

## 一句话

三国长坂坡意象的**汉字合成策略塔防**：消耗馒头征兵，拖拽合并汉字兵种，拼出武将姓名召唤名将，守护「斗」字阿斗，在对称战场上先破对方阿斗者胜。

## 原型对照

| 原作要点 | 本复刻落地 |
| --- | --- |
| 蜜獾工坊 / 抖音微信小游戏爆款 | 单机网页，零后端，可离线 |
| 1v1 上下半区对称 | 玩家下半区 vs AI 上半区，规则完全镜像 |
| 馒头征兵，费用递增 | `cost = 10 + 4 * recruitCount`，击杀与阿斗掉血回馒头 |
| 刀 / 枪 / 弓 / 骑 | 四基础兵种，同种同级合并升 1 级（白→绿→蓝→紫→橙，1–5） |
| 武将单字碎片 | 赵/云、张/飞、黄/忠、关/羽、刘/备、马/超；相邻按序拼成即觉醒 |
| 铲子扩地 | 解锁相邻锁定格 |
| 阿斗三心 | `斗` 字头顶 3 心，敌人抵达扣 1 心；先归零者败 |
| 水墨汉字即单位 | 静止为书法字，进入射程后墨迹变形攻杀 |
| 兵营 5 格 | 底部手牌栏，满则无法征兵 |
| 单局 3–5 分钟 | 波次加速 + 双方阿斗血量竞赛 |

## 核心循环

1. 点「征兵」消耗馒头，随机入手牌（兵种 / 单字 / 铲子，偶尔神兵符）。
2. 拖到手牌或棋盘：放置、合并、拼字、扩地。
3. 单位自动攻击路线上的敌军；击杀掉馒头。
4. 拼出武将 → 占一格，定期放大招并给邻格加成。
5. 守住己方阿斗，同时己方路线也会向对方阿斗施压（镜像出兵）。
6. 一方阿斗 0 心，或撑过最终波次后比较剩余心与击杀。

## 棋盘

- 每侧 5×4 可建造格，环绕一条「几」字形固定路线。
- 开局解锁 8 格，其余锁格需铲子。
- 近战（刀/枪/骑）打相邻路线格；弓打两格；武将按技能表。

## 征兵权重（可调）

刀 22 / 枪 22 / 弓 22 / 骑 16 / 单字 12 / 铲子 4 / 神兵符 2。

## 敌军与波次

- 12 波，每波数量 `4+wave`，生命 `20+wave*14`，移速随波次微增。
- 第 4/8/12 波出 Boss（更高血、技能：加速 / 护盾 / 分裂）。
- 漏敌：抵达阿斗扣 1 心，系统补偿 `8+2*wave` 馒头（「卖血经济」）。

## 镜像对抗

玩家击杀与驻防强度会按公式在对方路线刷出对应强度的「我方压力波」，让 AI 半区同样需要防守。AI 使用启发式：优先合并、近战外圈、弓内圈、优先拼赵云/黄忠。

## 非目标（本复刻不做）

付费、广告、当天失效商城、在线匹配、账号。武器库做成局内随机掉落即可。
