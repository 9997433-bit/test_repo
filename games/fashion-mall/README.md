# 时尚百货城（独立致敬版）

女性向超休闲放置经营：从快餐店起步，盘活百货城，换装、家装、招募伙伴，成为商业女王。

本目录与仓库内其他游戏隔离，不依赖仓库根目录。

## 启动

```bash
cd games/fashion-mall
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## 测试

```bash
cd games/fashion-mall
npm test
npm run bench
```

## 玩法速览

1. 刮刮乐开场，取名并初次换装。
2. 经营快餐店：按订单点击流水线出餐。
3. 升级主角与店铺，解锁生鲜 / 服装 / 盲盒 / 占卜。
4. 员工满员后可自动经营；离线最多结算 8 小时。
5. 伙伴按特长委派可大幅加成；换装魅力与家装影响客流和离线收益。
