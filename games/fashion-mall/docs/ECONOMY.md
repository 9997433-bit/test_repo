## 1. 资源与转化链

```
店铺挂机/技巧小游戏 ──→ 金币 ──→ 升级/招聘/研发/家具/培训（产能沉没）
                              └──→ 盲盒/占卜（负期望抽水）──→ 碎片 + 少量阅历
碎片 ──→ 伙伴签约（PARTNER_SIGN_SHARDS = 3）──→ 店收入乘区
阅历（XP）：技巧小游戏 + 目标奖励 + 被动供给 ──→ 主角等级 ──→ 店铺解锁
魅力：换装（免费）──→ 全店 ×(1 + 0.002×魅力)
```

硬性不变式（测试守护）：

1. **付费随机玩法金币期望必须 < 成本 ×0.85**（RTP ≤ 85%）。金币只能从店铺产出与技巧玩法进入经济，随机玩法只承载碎片与惊喜。
2. 碎片只出自付费随机玩法（现状），是伙伴签约的唯一货币。
3. 等级是双门槛：累计营收 + 阅历，缺一不可（`nextLevelReady` 保持不变）。

## 2. 小游戏赏金表 `MINIGAME_PAYOUTS`（B1/B6/E4）

Round 2 起视图一律查表/调纯函数，禁止内联数值（review 用 `rg '[0-9]{2,}' src/minigames` 抽查）。

### 2.1 技巧型（正收益，由操作耗时与技巧上限约束）

| 玩法 | 函数 | 公式 | 满技巧产率参考 |
|---|---|---|---|
| 星光快餐 | `fastfoodTip(orderSize)` | 28 + 12×件数，+2 阅历 | 3 件单 ≈ 9s → ≈7.1 金/s、0.22 xp/s |
| 晨光生鲜 | `freshPayout(caught)` | 18×接住数，阅历 = ⌈接住/3⌉ | 掉落 0.7s/件 → 上限 ≈25.7 金/s |
| 缪斯服装 | `boutiquePayout(score)` | 40 + 35×评分，阅历 = 3 + 评分 | 评分 4 单 ≈ 12s → ≈15 金/s、0.58 xp/s |

数值与基线一致（基线此三处无经济漏洞），Round 2 接线是行为保持的重构。技巧型产率高于同期挂机是刻意设计：主动玩就该是最优路径。

### 2.2 付费随机型（负期望，碎片承载价值）

**盲盒潮玩**：`cost 60`，+1 阅历，`blindboxRoll(rand01)` 按权重查池：

| 奖项 | 权重 | 金币 | 碎片 |
|---|---|---|---|
| 普通亚克力立牌 | 55 | 18 | 0 |
| 稀有闪卡 | 30 | 45 | 0 |
| 隐藏款手办 | 12 | 100 | 1 |
| 城主签名隐藏 | 3 | 280 | 3 |

期望 = **43.8 金（RTP 73%）+ 0.21 碎片**；净成本 16.2 金/盒 → 碎片净价 ≈77 金，签一名伙伴（3 碎片）≈ 14.3 盒 ≈ 净 231 金。基线为 90.2 金 + 0.69 碎片（RTP 150%，正期望印钞机）。

**星语占卜**：`cost 30`，+2 阅历，`fortuneSpin(rand01)` 均匀六槽：

| 槽位 | 金币 | 碎片 | 吉兆 |
|---|---|---|---|
| 大吉 | 40 | 1 | ✓ |
| 桃花 | 30 | 0 | ✓ |
| 偏财 | 36 | 0 | ✓ |
| 平稳 | 10 | 0 | — |
| 小凶 | 0 | 0 | — |
| 奇遇 | 27 | 0 | ✓ |

期望 = **23.83 金（RTP 79%）+ 1/6 碎片**；碎片净价 ≈37 金（晚一级解锁、单次转盘更耗时，故费率优于盲盒）。基线为 66.7 金（RTP 222%）。

`paidGameExpectation(id)` 返回精确期望，供测试断言与 UI 概率公示。随机数由调用方注入（`blindboxRoll(Math.random())`），公式层保持确定性可测。

## 3. 限时目标续期曲线 `rollNextGoal`（A5）

接口按 ARCHITECTURE §4.3 锁定：`rollNextGoal(state) -> goal`，core 在 settle 管线中于目标完成发奖后、或超时后调用。返回 `{ target, until, done, tier, reward: { gold, xp } }`。

```
区间 span = max(560 × 3^(Lv−1),  累计营收 × 12%) × 1.35^tier
target    = goldEarned + span          until = now + 8 分钟
reward    = { gold: span × 25%,  xp: (14 + 6×Lv) × (1 + 0.15×tier) }
tier      = 上一目标完成 → +1（封顶 6）；超时 → −1（下限 0）
```

设计要点：

- **区间自缩放**：等级基准（560×3^(Lv−1)）覆盖正常节奏；等级内收入爆发时改跟「累计营收 ×12%」，杜绝“目标秒完成 → 奖励变高频反馈泵”。模拟中稳定在每小时 12–17 个目标。
- **tier 自适应**：连续完成升档 ×1.35（tier 6 = ×6.05），强玩家吃更大区间与更高阅历；超时降档重发，弱玩家/挂机玩家不会被卡死。模拟中 tier 会在玩家增速放缓时自动回落（60 分钟处 tier 6→4）。
- **回流受控**：金奖 = 区间 ×25%，即目标系统对总营收的放大率恒为约 +25%，不随节奏失控（曾试 35%，模拟中与 tier 泵叠加导致爆炸，已降）。
- **旧档兼容**：基线 `goal` 无 `tier/reward` 字段，`rollNextGoal` 按 tier 0 处理不抛错；Lv1 从初始 40 金起算的首个目标 = 600，与基线 `defaultState` 完全对齐。
- 阅历奖励是**挂机玩家的主要阅历来源**（目标靠挂机营收也能完成），tier 0–6 下每目标 20–95 阅历。

## 4. 被动阅历供给 `passiveXpPerSec`（B3）

```
passiveXpPerSec(Lv) = 0.02 × 1.6^(Lv−1)   （离线按 0.65 折减，与金币同策）
```

纯被动过阅历门用时（不含目标奖励，最坏情况）：

| 门 | Δ阅历 | 速率/s | 用时 |
|---|---|---|---|
| Lv1→2 | 20 | 0.020 | 16.7 分 |
| Lv2→3 | 40 | 0.032 | 20.8 分 |
| Lv3→4 | 80 | 0.051 | 26.0 分 |
| Lv4→5 | 160 | 0.082 | 32.6 分 |
| Lv5→6 | 320 | 0.131 | 40.7 分 |
| Lv6→7 | 660 | 0.210 | 52.5 分 |

三层供给：被动滴灌（保底，慢于门槛差增速）＜ 目标奖励（挂机可得，每小时数百）＜ 主动小游戏（0.22–0.58 xp/s，约为被动 10–20 倍）。主动始终最优，纯挂机不再卡级。core Round 2 在 settle 管线按 dt 累计接入。

## 5. 成本曲线（B2）

### 5.1 店铺升级 `shopUpgradeCost(shop, level)`

```
cost = 20 × shop.base × (shop.growth + 0.2)^(level−1)
回本时长(无乘区) = 20/(g−1) × ((g+0.2)/g)^(level−1)
```

| 店 | g | Lv1 成本 | Lv1 回本 | 回本每级增速 | Lv20 回本(无乘区) |
|---|---|---|---|---|---|
| 快餐 | 1.18 | 240 | 111s | ×1.169 | ≈36 分 |
| 生鲜 | 1.20 | 440 | 100s | ×1.167 | ≈31 分 |
| 服装 | 1.22 | 720 | 91s | ×1.164 | ≈27 分 |
| 盲盒 | 1.23 | 960 | 87s | ×1.163 | ≈25 分 |
| 占卜 | 1.24 | 1280 | 83s | ×1.161 | ≈24 分 |

（实际回本再除以乘区 M ≈ 2.2–2.9：员工 ×1.36–1.48、伙伴 ×1.6+、魅力 ×1.05+。）

回本增速窗口 **(1.05, 1.20)** 由测试守护，两端都是病：

- 基线 ×1.229：Lv40 回本 32 小时，升级沦为硬墙；且全店共用 80 基价，占卜店 Lv1 升级 7 秒回本，是仅次于盲盒的印钞位。
- 曾试 ×1.08（g+0.1）：贪心复投模拟下单店无限滚雪球，收入 1 小时破 2500 万/秒、等级门 6 分钟穿光。

×1.16 的含义：每家店自然进入平台期，把注意力推向新店/研发/伙伴，但任何时刻回头升级都仍划算。

### 5.2 其他成本

| 项 | 公式 | 理由 |
|---|---|---|
| 招聘 `hireCost(shop, n)` | 4×base×1.5^n | 满员=自动化是 ×2.86 跳变（0.35→1 + 员工加成），必须按店铺体量计价；基线全店 50×1.5^n 让后期店免费拿跳变 |
| 研发 `RESEARCH_NODES` | 1200/8000/5万/30万 → +6/18/60/180 每秒 | 回本 200s→1700s 递增的中期沉没；基线 50s 回本是前 3 分钟收入火箭 |
| 培训 `partnerTrainCost(lv)` | 40×1.6^(lv−1) | 每级 +4.8% 店收入（恒定边际），线性成本=无限白嫖，指数化设自然停手点 |
| 家具 `furnitureCost(item)` | bonus×40000 | 修倒挂；全套 15600 金对 +39% 离线加成，定位 15 分钟后消费 |
| 伙伴叠加 `combinePartnerBonuses` | 降序 ×1, ×0.5, ×0.25… | 堵 B5「全员堆最贵店」；3 个满匹配从 +180% 压到 +105% |

## 6. 等级门与产出公式

产出公式保持基线（已冻结面）：`shopRate = base × g^(lv−1) × (1+0.12×员工) × (1+伙伴) × (1+0.002×魅力)`；离线 65%、8 小时封顶；匹配特长 +60%、错配 +15%，培训每级 +8%。

`LEVEL_INCOME_GATES = [0, 800, 6000, 5万, 40万, 300万, 2000万]`（Lv2 门 800/20 是 60 秒教学节点，测试锁定不动）。上层门为什么抬：基线 4k/20k/100k/600k/3M 从未建模，在任何合理成本曲线下贪心玩家 6–15 分钟穿光全部等级。新门按 §7 模拟轨迹放置，使解锁节奏与收入引擎同步。阅历门 `[0,20,60,140,300,620,1280]` 不变，继续作为挂机路径的主门。

## 7. 节奏基准（前 3 分钟 / 15 分钟 / 1 小时）

模拟口径：dt=1s 跑 3600s；「半活跃」= 前 3 分钟全程手玩、3–15 分钟 50%、之后 25% 在场，每秒贪心复投（留 1.2–3 倍缓冲）；「零手玩」= 不玩小游戏但完美复投。两者都是**机器人上界**，真人有决策与操作摩擦，按 2–5 倍放慢读数。目标完成/超时、tier 升降、盲盒碎片按期望结算全部入模。

| 时点 | 半活跃（上界） | 零手玩复投（上界） |
|---|---|---|
| 3 分钟 | Lv3→4，收入 ≈400/s，累计 4.2 万，完成 5 个目标 | Lv3，收入 ≈334/s |
| 15 分钟 | Lv6，收入 ≈1.9 万/s，四伙伴签约完毕 | Lv5，收入 ≈7000/s |
| 60 分钟 | Lv7（毕业），收入 ≈16 万/s，累计 2.6 亿，tier 回落 6→5 | Lv7 @39.8 分 |

关键里程碑（半活跃上界）：Lv2 @0.5 分、Lv3 @1.3 分、Lv4（盲盒开）@3.3 分、Lv5（占卜开）@6.5 分、Lv6 @11.3 分、Lv7 @21.4 分；首伙伴签约 @4.3 分。

**设计意图（真人体验）**：

- **前 3 分钟**：教学环闭合——首笔快餐订单 ≤60s（A1），首个目标 600 金 @~1 分钟完成拿 140 金 + 20 阅历，首次升级装修 + 首名员工，Lv2 解锁生鲜。爽点密度最高的窗口。
- **15 分钟**：系统全开的边缘——真人约 Lv4–5，盲盒开箱、碎片循环启动，研发首两档、家具开始买得起，目标 tier 爬到 2–4。
- **1 小时**：养成深水区——真人约 Lv6–7，全店自动化，伙伴签约/培训与 tier 5–6 的大额目标构成留存循环；等级毕业后 tier 6 目标（区间=营收 ×12%×6.05）是无限延伸的挑战线。

零手玩与半活跃的等级差约 2 倍用时，主动优势明确但挂机不废——B3 双路径达标。

## 8. 残留风险与 Round 2 接线清单

1. **印钞洞在运行时尚未关死**：盲盒/占卜视图仍内联旧正期望数值（60→90.2 / 30→66.7）。本轮把目标口径钉死在表+测试里，但玩法视图查表改造（`blindboxRoll`/`fortuneSpin`/`paidGameExpectation`）完成前，线上行为不变。**这是 Round 2 玩法视图的第一优先级。**
2. **core 未接线**：`rollNextGoal`、`passiveXpPerSec`、`combinePartnerBonuses` 已导出未被调用——目标仍一次性、被动阅历未生效、伙伴仍可无衰减叠加。接线归核心工程（settle 管线 + `shopBonusMap`）。
3. **state 形状**：接线后 `goal` 新增 `tier/reward` 字段，属形状变更 → 需 `CURRENT_VERSION+1` + 迁移用例（`rollNextGoal` 对无 tier 旧档已兼容，迁移可以是空操作 + 补默认）。
4. **视图旧价目**：mallView 升级 80×1.45^n / 招聘 50×1.5^n、roster 培训 40×lv、mansion 200/bonus 均与新口径不一致，接线前 UI 走旧价（旧价更便宜，玩家只赚不亏，不炸档）。
5. **抽水占比衰减**：盲盒/占卜为平价（60/30），Lv4+ 收入下沉没感趋零，碎片获取实际只受操作节奏限制。负期望不变式已保证不印钞；若要金币沉没有感，Round 2 可让 cost 随主角等级缩放（常量已集中，一处可改）。
6. **老档体感**：上层等级门抬高后，存量档若处 Lv3–6 会感觉下一门变远（`goldEarned` 累计不回退，不炸档、不降级）。
7. **模拟脚本未入库**：本轮文件白名单只含 balance/ECONOMY/economy.test；模拟假设与结论全文记录于 §7，Round 2 建 `scripts/simulate.mjs`（F3 所有权）时按此复刻并入 CI。
8. **事件奖励未缩放**：`copy.js` EVENTS 固定 60–140 金，后期沦为噪声；建议 Round 2 事件奖励按等级/收入查 balance 缩放（归 F4 + F3 会签）。
