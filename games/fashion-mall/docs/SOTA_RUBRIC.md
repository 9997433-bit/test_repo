# SOTA 验收量规（Round 1 / F1 定稿 · 可打分）

## 0. 打分方法

- 每条目 **0 / 1 / 2** 分：`0` 缺失或坏损；`1` 存在但有明确缺陷（缺陷须可指认）；`2` 达到验收标准且有证据。
- 五个维度：**A 体验 20 分、B 数值 16 分、C 性能 12 分、D 无障碍 12 分、E 测试 12 分**，满分 **72**。
- 评分线：**SOTA ≥ 65（90%）；可发布 ≥ 54（75%）；基线实测 30（42%）**。
- 每轮交付必须重打全表并更新"基线"列；打 2 分的条目必须给出证据（命令输出、录屏、代码位置）。
- 基线证据环境：Node v22.14.0，`npm test` 11/11 通过，`npm run bench` 实测 312,290 ticks/s（2026-08 快照）。

## 汇总与缺口

**基线得分：A 11 + B 6 + C 3 + D 4 + E 6 = 30 / 72（42%）**，距可发布线差 24 分。

按投入产出排序的补分路径（对应 ARCHITECTURE §10）：

1. **P0 工程**（约 +12：C2/C3/C4/B4/E2）：时间戳 settle 统一在线/离线、视图 dispose 协议、迁移管线接线 + 旧档用例、HUD 订阅局部刷新。
2. **P0 数值**（约 +8：B1/B2/B6/E4/E1）：赏金入 data 层、堵盲盒/占卜正期望、写曲线模拟与期望值断言。
3. **P0 体验/无障碍**（约 +10：A4/A5/A9/D2/D3/D5/D6）：目标续期、修失误音、focus-visible + ARIA + 减动效 + nav 触控目标。
4. **P1**（其余）：俯视商场地图、事件微交互、盲盒/占卜玩法差异化、帧率取证。
