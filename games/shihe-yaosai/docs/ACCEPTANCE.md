# 蚀核要塞 · 玩家验收单

这份单子写给**以玩家身份做验收的人**：不需要读代码，按体验单逐条打勾即可。每条末尾括号里的 ID 指向同目录 `SOTA_CHECKLIST.md`，一切数值与阈值以那边为唯一事实源。

## 0. 开始之前

- 设备：一台桌面电脑 + 最新版 Chrome（支持 WebGPU 最佳；不支持也应能玩，见第 1 节）。
- 启动：

  ```sh
  cd games/shihe-yaosai
  npm ci
  npm run dev
  ```

  然后打开 `http://localhost:4182`。端口必须是 **4182**（GL-2）。
- 不需要账号、不需要登录、不需要联网素材：把网断了游戏也应照常运行（GL-4 / GL-5）。

## 1. 开场 30 秒 —— Round 1 起生效

- [ ] 页面数秒内出现 3D 场景：中央一颗**发光的星核**、一圈金属环、环上 **24 个插座**、高低错落的**三层轨道**（HM-1 / WF-1）
- [ ] 屏幕上有后端徽标，写着 `WEBGPU` 或 `WEBGL2`，且与你的浏览器实际情况相符（YQ-3 / YQ-5）
- [ ] 关闭 WebGPU（或换不支持的环境）再开：游戏自动回退到 WebGL2，照样能玩，不白屏（YQ-4）
- [ ] HUD 上能看到：核心血量 20/20、屑晶 180、当前波次（WF-2 / WF-3 / WF-8）
- [ ] 发光的东西有溢光（辉光/泛光），画面不是一片死灰（HM-2）

## 2. 放塔与打怪 —— Round 1 起生效

- [ ] 点一个空插座、选一种塔、放下：屑晶被扣掉，塔立在环上（WF-4）
- [ ] 屑晶不够时放塔会被**拒绝**，并有提示（WF-3）
- [ ] 敌人从外圈出生，沿下/中/上三条轨道一路**向星核冲**（WF-1）
- [ ] 塔开火看得见：曳光划过或光束打出，击杀敌人屑晶增加（HM-3）
- [ ] 敌人冲进星核会「漏」：核心血量下降 —— 小怪扣 1、中型扣 3、精英扣 8；血量归零判负（WF-2）
- [ ] 选中一座塔按 **F** 过载：塔身明显**变色**，伤害显著提高约 4 秒，然后停火冷却约 3 秒；过载不花屑晶（WF-5 / HM-6）
- [ ] 至少能连着打完 **5 波**，波次数字正常推进（WF-8）

## 3. 五塔与克制 —— Round 1 打底，Round 2 全量

- [ ] 建造栏里能看到 **5 种塔**：轨炮、棱镜、霰星、坠井、星弩；Round 1 至少 3 种在场景里有形体，Round 2 起 5 种全部能放能看（WF-4）
- [ ] 棱镜打出的是**直线光束**；把两座棱镜放得足够近（逻辑距离 ≤18），光束会**折一次**、连成两段（WF-7）
- [ ] 面对甲壳 / 护盾 / 虫群三类敌人，同一种塔打起来效率明显不同 —— 选对塔有回报（WF-6）

## 4. 完整成品 —— Round 2（L2）起生效

- [ ] **20 波完整战役 + 最终 Boss「蚀主」**：打得赢也输得掉，胜负各有结算画面（WF-9）
- [ ] 5 种塔外形一眼可辨，弹道分三路：曳光、光束、抛物线，各有各的样子（HM-4 / HM-7）
- [ ] 画质三档可切：`high` 辉光 + 阴影全开，`mid` 保留辉光，`low` 素但流畅；切档立即生效不用刷新（YQ-6）
- [ ] 塔能升级，升完打击感和数字都有变化（WF-10）
- [ ] 拉伸浏览器窗口，画面不糊不裂（YQ-7）

## 5. SOTA 打磨 —— Round 3（L3）起生效

- [ ] 满场大战不卡：高画质下依旧流畅（XN-3）
- [ ] 连打 3 局不刷新页面：不崩、不越玩越卡（XN-4）
- [ ] 击杀有反馈、漏敌有痛感、Boss 出场有排面（HM-8）
- [ ] 认真布防能通关，全程挂机必失败 —— 数值是真的（WF-11）

## 6. 我们不承诺什么（画面诚实声明）

以下**不是缺陷**，请不要拿概念海报逐帧对照：

- 没有满屏体积神光，没有电影级焦散，没有海报级的几何密度，没有实时全局光照（SOTA_CHECKLIST §3.1）。
- 画面验收基准是**你电脑上实时跑出来的样子**：星核会发光、金属有质感、弹道看得清、过载看得出 —— 这些必须有，也只承诺这些。

## 7. 顺手可跑的三条命令（可选）

不想跑可以跳过，工程门槛由 Fable-4 按 `SOTA_CHECKLIST.md` 把关：

```sh
cd games/shihe-yaosai
npm test        # 纯模拟单测，应退出码 0（CS-1）
npm run probe   # 无头打满 5 波，输出 JSON 战报（CS-2）
npm run build   # 构建应通过，产物无任何外链（CS-3 / GL-4）
```

- 触碰任何一条 GL 红线（越目录、抢端口、引其它游戏代码、运行时 CDN 等）→ **当轮直接打回**，不看其余条目。
- 当轮生效的条目全部打上勾 → 当轮 **PASS**。
