# 蚀核要塞 · 美术方向（ART_DIRECTION）

> 维护人：Fable-2（美术 UX）。落地文件：`src/styles/index.css`、`src/styles/tokens.css`、`src/styles/hud.css`。
> 3D 侧（材质 / 剪影 / 后处理）由 O1/O2/O3 按本文实现；HUD class 冻结，O4 只写结构不写样式。

## 0. 一句话定位

**深空金属堡垒，被青色能量点亮，被品红蚀化侵袭。** 三个关键词：**冷金属、自发光、可读性**。

不是水墨，不是田园，不与本仓库其他游戏共享任何视觉语言。画面验收按「桌面 WebGPU 实时」，不按概念海报。

## 1. 色彩系统

### 1.1 主色板

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 深空黑 `--sh-bg` | `#05060d` | 页面底、太空背景基调 |
| 渊黑 `--sh-bg-deep` | `#02030a` | 渐变最深处、阴影侧 |
| 舰钢灰 `--sh-steel` | `#232c3d` | 结构金属 albedo、塔身、环体 |
| **蚀青 `--sh-cyan`** | `#3cf0ff` | 己方能量：星核、塔发光条、光束、HUD 主色 |
| 冰白 | `#eafeff` | 发光体核心最亮处、棱镜晶体 |
| **蚀红 `--sh-magenta`** | `#ff3d9a` | 敌方 / 威胁 / 过载激发态 |
| 井紫 `--sh-violet` | `#8a5cff` | 仅 `well` 坠井的引力场专用（青与品红之间的过渡 hue） |
| 熔橙 `--sh-heat` | `#ff6a3d` | 仅**过热**状态专用 |
| 危险红 `--sh-danger` | `#ff4d5e` | 仅核心低血 / 失败警告专用 |
| 纸白 `--sh-paper` | `#e8f4ff` | HUD 正文文字 |
| 雾蓝 `--sh-muted` | `#8fa6c2` | HUD 次要文字、backend 标签 |

### 1.2 配比与层级

- 画面占比大约 **70% 暗中性（深空黑 + 舰钢灰）／ 25% 蚀青 ／ 5% 蚀红与状态色**。暗底是让 Bloom 便宜又好看的前提。
- **hue 纪律**：青 = 己方，品红 = 敌方与越界能量（过载），紫只给坠井，橙只给过热，红只给核心告警。任何新元素先归类再取色，不新增 hue。
- 发光体一律「冰白核心 → 主 hue 中段 → 透明衰减」三段，保证 Bloom 阈值只被核心击穿，光晕不糊屏。

### 1.3 语义色约定（敌我与状态）

| 对象 | 配色规则 |
| --- | --- |
| 星核 | 蚀青自发光呼吸；受击闪冰白；HP<30% 时呼吸转危险红 |
| 敌人（全体） | 品红族。威胁只有一种 hue，靠形体区分种类 |
| `shell` 甲壳 | 大而钝的暗钢躯体 + 品红窄缝棱线（硬、慢、装甲感） |
| `shield` 护盾 | 中型品红核心 + 半透明泡壳；破盾瞬间壳体闪白后消失 |
| `swarm` 虫群 | 小体多单位，高亮品红点阵（亮度高、体积小） |
| 三条轨道 | 全部青系暗描线，不占用敌方 hue。下 / 中 / 上（y=0/4/9）透明度约 0.25 / 0.35 / 0.45，虚线密度递增，高度即身份 |
| 过载中的塔 | 青 → 冰白 → 品红坡道（见第 4 节） |
| 过热的塔 | 熔橙，全场唯一橙色，一眼锁定 |

## 2. 材质规范（Babylon PBR）

**只用程序化纹理与纯色 PBR 参数，禁止下载任何素材 / 字体 / 贴图。**

| 部位 | 材质建议 |
| --- | --- |
| 结构金属（环、塔身、插座台） | PBRMaterial：albedo `#232c3d`，metallic ≈ 0.9，roughness ≈ 0.40–0.50。粗糙度别低于 0.35，镜面过锐在无 IBL 时会显得塑料 |
| 发光条 / 能量缝 | emissive `#3cf0ff`，强度以「high 档 Bloom 阈值 ≈ 0.75 时恰好起晕」为准（约 1.5–2.5）；几何上做成窄条，宁细勿宽 |
| 星核 | 内球强 emissive（≈2.2）+ 外壳低粗糙金属加 Fresnel 边缘光；呼吸周期 ≈ 2s，幅度 ±15% |
| 空插座 | 台座金属 + 环形青色暗描边（emissive ≈ 0.4），悬停 / 选中时提亮到 ≈ 1.2 |
| 天空 | 程序化星野（暗底 + 少量亮点即可），或纯色渐变；不做星云贴图 |
| 敌人 | 品红 emissive 为主，unlit 或低 PBR 成本均可；小单位靠亮度不靠细节 |

补充规则：

- 灯光预算：1 盏主方向光 + 星核 1 盏点光即可，其余亮度全靠 emissive。
- 阴影只在 high 档开（见第 5 节），投影体只算塔与敌人，环不投影。
- 所有材质参数集中可调（供 `setQuality` 降档时统一压 emissive / 关阴影）。

## 3. 塔剪影（5 塔）

**三原则：① 屏幕上 40px 高时仍可互认；② 高宽比与顶部轮廓互不相同；③ 发光位即功能位。** 细节让位于剪影，多边形预算每塔 ≤ 1.5k 三角形。

| 塔 | 剪影 | 比例（高:宽） | 发光位 / 识别色 |
| --- | --- | --- | --- |
| `rail` 轨炮 | 低趴双轨长管，像一副平放的音叉，开火时沿管身推光 | 1 : 2.2（最矮最长） | 双轨内侧青色轨光，蓄能从尾到口 |
| `prism` 棱镜 | 基座上**悬浮旋转的八面体晶体**，不接触底座 | 2 : 1 | 晶体整体冰白半透 + 青核；折射时晶面亮起指向下一段 |
| `scatter` 霰星 | 短粗放射状多管簇（6 管环列），像一朵金属刺球 | 1 : 1.3（最宽最钝） | 每管口一个青色点光，点阵识别（对应虫群点阵语言） |
| `well` 坠井 | 三片弧形叶片围成的竖直环圈，中心悬浮涡点 | 1.6 : 1 | **全场唯一井紫**，环内向下旋涡光 |
| `star` 星弩 | 最高的竖直发射架，顶端一枚上扬箭簇 | 3 : 1（最高最细） | 顶端青白双色星芒，蓄力时从架底向顶爬光 |

高度排序（远景直读）：`rail < scatter < well < prism < star`。

## 4. 过载与过热视觉

时间线（与 sim 冻结值一致：过载 ×2.2 持续 4s，随后停火 3s）：

| 阶段 | 塔体 | HUD |
| --- | --- | --- |
| 触发瞬间（0s） | 冰白闪光一帧级脉冲 | `.sh-overclock` 进入 `.is-active` |
| 过载中（0–4s） | 发光位从青**坡道到品红**（青 → 冰白 → 品红），弹道 / 光束同步变品红，粗度 +30% | 品红热脉冲呼吸 |
| 过热停火（4–7s） | 全塔发光转**熔橙**并按指数衰减变暗，枪口余温残光 | `.is-cooldown`（或 `:disabled`）降饱和置灰 |
| 恢复 | 熔橙 → 青，0.5s 内淡回 | 恢复常态青光 |

规则：品红过载 = 「借用敌方 hue 的越界能量」，熔橙过热 = 全场唯一橙，两者都不做粒子海——**变色 + 亮度坡道就是全部承诺**。

## 5. 质量档 vs 概念图诚实

对应 `src/engine` 冻结契约 `setQuality('high'|'mid'|'low')`：

| 档位 | 后处理 | 3D 侧变化 | HUD |
| --- | --- | --- | --- |
| high | Bloom + Glow + 阴影 | 全量 emissive、星核呼吸、塔阴影 | 不变 |
| mid | Bloom + Glow | 关阴影，其余同 high | 不变 |
| low | 关全部后处理 | emissive 保持纯色高亮（无晕），弹道退化为纯色线 / 点 | 不变 |

**HUD 的发光全部是 CSS（text-shadow / box-shadow），零 GPU 后处理成本，三档一致。** 低档画面「亮但不晕」，依旧可读。

诚实条款（对外承诺口径，禁止越线宣传）：

- **承诺**：PBR 金属质感、星核自发光、Bloom（high/mid）、可辨认的曳光 / 粗光束 / 抛物线、过载与过热变色、三轨道高度可读。
- **不承诺**：满屏体积神光、电影级焦散、屏幕空间反射、概念图 1:5 的几何密度、每弹丸实时点光。
- 概念图仅作氛围参考；验收截图必须来自 :4182 实时运行画面。

## 6. HUD 规范

### 6.1 冻结 class 契约

`.sh-hud .sh-core .sh-scrap .sh-wave .sh-dock .sh-toast .sh-backend .sh-overclock`，canvas 为 `#sh-canvas`。**不改名、不增删结构性要求**；样式全部挂在这些 class 上，O4 的 HTML 无需内联样式。

### 6.2 布局

```
┌────────────────────────────────────────────┐
│ [星核] [屑晶] [波次]              [backend] │  ← 顶部状态排
│                                            │
│                （.sh-toast 顶部居中浮现）      │
│                  3D 画面                    │
│                                            │
│        [ 轨炮 | 棱镜 | 霰星 | 坠井 | 星弩 ]  [过载 F] │  ← 底部
└────────────────────────────────────────────┘
```

`.sh-hud` 是 `position:fixed` 的全屏 Grid 覆盖层，整体 `pointer-events:none`，仅 `.sh-dock` 与 `.sh-overclock` 恢复 `pointer-events:auto`（可点穿到画布拾取插座）。带 `env(safe-area-inset-*)` 安全边距与极淡的顶部压暗渐变（提高芯片可读性，非体积光）。

### 6.3 状态钩子（与 `src/ui/hud.js` 双向确认，不加也有完整基线样式）

| 元素 | 钩子 | 视觉 |
| --- | --- | --- |
| `.sh-hud` | `data-paused`；`data-result="win\|lose"`；CSS 变量 `--sh-core-frac`(0..1) | 整屏压暗；青 / 红终局染边；驱动核心 HP 条 |
| `.sh-core` | `.is-danger` | 危险红描边 + 脉冲（核心低血）；芯片底部有 `--sh-core-frac` 驱动的 2px HP 条 |
| `.sh-backend` | `.is-webgpu` / `.is-webgl2` | 青色亮标 / 蓝白标；默认雾蓝 |
| `.sh-toast` | 内容为空自动隐藏（`:empty`）；`.is-error` | 常态青光胶囊；错误转品红 |
| `.sh-dock button` | `.is-selected` 或 `aria-pressed="true"`；`:disabled`；`data-tower="rail\|prism\|scatter\|well\|star"`；`data-count` | 选中青光内晕；买不起置灰；顶部型别识别条（配色同第 3 节）；右上已放数量角标 |
| `.sh-dock` 子级 | `.sh-dock-name` / `.sh-dock-cost` / `.sh-dock-key`；`.sh-pause` / `.sh-quality` | 名称 / 青色造价 / 键帽（≤640px 隐藏）；暂停与画质为降级视觉的次级按钮 |
| `.sh-overclock` | `.is-active`；`.is-cooldown` 或 `:disabled` | 品红热脉冲；冷却降饱和置灰 |

### 6.4 可用性硬指标

- **触控目标 ≥ 44×44px**：铸塔按钮与过载按钮在所有断点下 min-height/min-width ≥ 52/52（390 宽下仍 ≥52），高于底线。
- **断点**：1280 桌面为基准；≤640px 压缩芯片与坞站、过载按钮上移一行避让；≤400px（覆盖 390 宽）进一步收紧字距与内边距，坞站可横向滚动兜底。
- **对比度**：正文纸白 / 面板 ≥ 10:1，次要雾蓝 ≥ 4.5:1，蚀青数值 ≥ 7:1。
- **动效**：全部尊重 `prefers-reduced-motion: reduce`；键盘可达（`:focus-visible` 青色描边）。
- 字体只用系统栈（Segoe UI / Noto Sans SC / PingFang SC / Microsoft YaHei），数字 `tabular-nums` 防跳动，禁 webfont 下载。
