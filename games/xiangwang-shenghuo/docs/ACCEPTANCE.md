## 0. 准备

```bash
cd games/xiangwang-shenghuo
npm install          # 首次
npm run dev          # 打开 http://localhost:4175
```

- 浏览器：Chrome 或 Edge 最新版；准备秒表（手机即可）。
- 键盘快捷键：`1-6` 选前六种种子，`H` 全部收获，`S` 记下这一天，`M` 静音，`Esc` 回心愿屋面板。
- 被拒操作的中文原因以**屏底飘字（toast）**呈现，约 2.6 秒消失，不写入「村里的闲话」。
- 常用控制台片段（下文以【清档】【读档】等指代）：

```js
// 【清档】纯净开局
localStorage.removeItem("xwsh.save.v1"); location.reload();

// 【读档】查看当前存档状态
JSON.parse(localStorage.getItem("xwsh.save.v1")).state

// 【坏档】写入非法存档（仅 T8 用）
```

- 时间换算（默认 1 游戏时 = 6 秒）：1 游戏分 = 0.1 秒；1 日 = 144 秒；1 季 = 7 日 ≈ 16.8 分钟。

## T1 三分钟新手闭环（A1，P0）

前置：【清档】。从第一次点击起秒表计时。

1. 点「荒地」→ 变「空地」（引导跳到第二步）。
2. 工具条点「白菜」（或按键 `5`），点一块空地播种（−6 金币）。白菜跨春，春季当季 = **14 秒**成熟。
3. 点「水稻」（或按键 `1`），点另一块空地播种（−8 金币；当季，18 秒成熟）。
4. 田块进度条走满、显示「可收」后逐一点击收获（白菜 +2 白菜 +4 经验，日志「收了白菜，2 份进了筐。」；水稻 +2 稻谷 +6 经验；均有收获音效）。
5. 心愿板「一棵白菜（白菜 1/1）」点「送去」，停表。

**预期**：
- 日志出现「心愿达成：一棵白菜，收入 **12** 金币，还捎来**一把斧子**」——12 金 = 基价 10 × 幸福 40 的 +16% 取整；斧子来自新档首单保底（前三单必掉 斧→锯→锹，另有 4% 独立珍珠 roll，捎珍珠时如实记录）。幸福 +1，经验 +5。
- **交付后板上留一个空格**（不再当场补满），约 12 秒后补 1 位——节奏细则见 T2。
- 种子等级门：点「玉米」（Lv3）播种被飘字拒「小镇等级不够」。

**过线**：≤180 秒完成第 5 步；0 报错。
**辅指标**：继续自然游玩，≤12 分钟内攒到 Lv2（40 经验，日志「小镇升到 Lv.2，图纸本上又亮了几张。」）+ 80 金币 + 1 把斧（开局自带 + 首单保底，斧应有富余），点村景「磨坊」→「盖起来」（−80 金 −1 斧），再点「碾米」开工首单（连续实测 2 次取较好值）。
**回归项**：磨坊面板打开后必须**持续可点**（Round 1 缺陷 UI-1 已修，若面板内容再被刷掉即为回归，直接判不通过）。

## T2 心愿屋节奏、换单与掉落（A1 / A5 辅助）

前置：接 T1 存档继续。

1. 补位节奏（本轮已落地，主路径生效）：交付后空出的格子应在 **2 游戏时（12±2 秒，灯哥在场 ≈10.2 秒）**后补上，且一次只补 1 位；板满时计时器停走，空位从空出那一刻起算。板被清空（0 单）时立即补满整板。
2. 换单：任一心愿点「换一个」→ 单子立即被替换、无任何奖励；连换数次不应同款占满整板。**已知偏差（P1）**：换单走的 `refreshWishes` 会把板上**所有**空位（含交付留下的）一起立即补满，等于绕过第 1 条的节拍——如实记录。
3. 连续交付 3 单，记录工具掉落：新档前三单**必掉 斧→锯→锹**（顺序固定）；从第 4 单起基础掉率 25%（权重 锹40/锯35/斧25，珍珠 4% 独立 roll），连续 6 单不掉则下一单必掉（按权重取）。
4. 第 4 心愿格：控制台把存档 `resources.warmth` 改为 100 后刷新 → 心愿板变 4 格（温馨 ≥100 阈值奖励）；改回 20 恢复 3 格。
5. 【快进】把 `day` +3 后刷新：挂满 3 日无人交付的心愿被撤下，日志出现「N 条心愿等太久，被从墙上取了下来。」

**过线**：1、3、4、5 符合；2 的立即替换符合、连带补满按实际记录（当前预期不通过，P1）。

## 附录 A 夹具存档（Lv6 演示状态，仅限【夹具】用例）

先【清档】进入新局，再在控制台执行：

```js
const raw = JSON.parse(localStorage.getItem("xwsh.save.v1"));
const s = raw.state;
s.meta.xp = 420;                                    // 等级由 xp 推导 → Lv6
s.resources = { ...s.resources, coin: 2000, shovel: 8, axe: 3, saw: 3 };
s.inv = { ...s.inv, paddy: 12, soybean: 12, wheat: 12, rice: 6, corn: 6,
          egg: 4, milk: 2, chicken_feed: 12, flour: 4 };   // 饲料 12 份：够 T6 十连喂 + T4 冬季加耗
s.buildings = { ...s.buildings,
  mill:     { built: true, slots: [], slotCount: 2 },
  feedmill: { built: true, slots: [], slotCount: 3 },
  coop:     { built: true, slots: [], slotCount: 3 },
  kitchen:  { built: true, slots: [], slotCount: 2 },
};
localStorage.setItem("xwsh.save.v1", JSON.stringify(raw));
location.reload();
```

> T2 第 4 步 / T6 第 7 步另需临时改 `s.resources.warmth`（100 / ≥60），用完改回 20，
> 避免第 4 心愿格与暴击线干扰其他用例的数值核对。
> 注意：夹具不改 `village.pityStep`，所以夹具局的前三次交单同样必掉 斧→锯→锹；
> 要测 25% 基础掉率，先把前三单交完（或控制台把 `s.village.pityStep` 设为 3）。

## 附录 B 快进（改游戏时间后刷新）

```js
const raw = JSON.parse(localStorage.getItem("xwsh.save.v1"));
raw.state.meta.day = 7;                  // 目标日（冬季用 22）
raw.state.meta.gameMinutes = 23 * 60;    // 23:00，约 6 秒后跨日（第 7→8 日即换季）
localStorage.setItem("xwsh.save.v1", JSON.stringify(raw));
location.reload();
```

> 提醒：夹具与快进都会改变确定性 RNG 的输入（掉落、黑暗料理、暴击由存档内容推导），
> 同一夹具 + 同一操作序列的结果可复现，跨夹具比较概率类数值时需多次采样。
