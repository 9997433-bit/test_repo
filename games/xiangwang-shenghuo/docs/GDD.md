# 向往的生活 · 游戏设计文档（基线）

> 网页致敬复刻。原创角色、文案与美术；还原综艺/手游的田园慢生活闭环，不做官方素材搬运。

## 一句话

你是蘑菇屋的代理村长：种田、养殖、开作坊、完成心愿、招待嘉宾、把破败小村重新养活。

## 参考来源（玩法，非素材）

芒果 TV 授权田园经营手游《向往的生活》（2023–2025）与同名综艺：

- 蘑菇屋是情感与功能枢纽
- 种植 → 工厂加工 → 饲料 → 畜牧 → 再加工 的有机产业链
- 心愿屋订单是经验和金币主来源
- 人口 / 社区决定土地与工厂扩建
- 嘉宾驻留给作坊效率 buff
- 烹饪招待、萌宠互动、摆摊、四季烟火气

## 核心循环

1. 开垦土地，按季节播种  
2. 收获作物，送进磨坊 / 制糖 / 酱料 / 布行  
3. 大米等加工成饲料，喂鸡羊牛  
4. 鸡蛋、牛奶、羊毛进入更深加工  
5. 把产物交给心愿屋 / 货运摊  
6. 获得金币、经验、幸福、建材（锹 / 斧 / 锯）  
7. 盖房加人、建社区提人口上限、扩建田与厂  
8. 升级蘑菇屋，解锁厨房、客房、宠物院  
9. 招待嘉宾、做菜、布置家具提升温馨度  
10. 更高阶作物 / 工厂 / 节日活动

## 时间与季节

- 1 游戏时 = 6 秒现实时间（可在设置改为 3 / 12 秒）
- 1 日 = 24 游戏时；昼夜影响氛围与部分产出
- 1 季 = 7 游戏日，四季轮转：春 → 夏 → 秋 → 冬
- 作物有适宜季节；错季生长 ×0.55，且可能枯萎
- 冬季畜牧饲料消耗 +20%，温室地块免疫错季惩罚

## 种植（详见 `src/data/crops.js`）

水稻、大豆、小麦、玉米、白菜、番茄、草莓、甘蔗、棉花、茶树。  
地块状态：`untilled | empty | growing | ready | wilted`。

## 畜牧与工厂（详见 `src/data/animals.js` `recipes.js`）

产业链铁律（必须被单测锁住）：

```
水稻 → 大米 → 鸡饲料 → 鸡蛋
大豆 → 豆腐 →（+牛奶）→ 豆奶
小麦 → 面粉 → 面包
甘蔗 → 糖
大豆+辣椒 → 酱
棉花/羊毛 → 布
大米+玉米 → 牛/羊饲料 → 牛奶 / 羊毛
```

工厂默认 2 生产位（饲料厂 / 畜牧 3），可用金币解锁到 6。

## 心愿屋

- 同时 3 单，每 2 游戏时刷新 1 空位
- 需求 1–3 种物品，数量随等级上升
- 奖励：金币 + XP + 小概率建材 / 珍珠
- 幸福指数每 10 点订单金币 +4%

## 村落建设

房屋 +1 人口；社区 +人口上限；人口不够不能扩建田/厂。  
摆摊：把库存挂出，按基础价 × 1.15 出售（网页单机版模拟过路客）。

## 萌宠

小花（狗）、小团（猫）、小黄（鸡）：点击互动 CD 后掉少量金币或幸福。

## 公平原则

无内购。加速仅消耗珍珠（任务产）。强度来自产业链规划与季节。
