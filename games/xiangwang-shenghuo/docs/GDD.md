## 一句话

你是蘑菇屋的代理村长：种田、养殖、开作坊、完成心愿、招待嘉宾、把破败小村重新养活。

## 参考来源（玩法，非素材）

芒果 TV 授权田园经营手游《向往的生活》（2023–2025）与同名综艺：

- 蘑菇屋是情感与功能枢纽
- 种植 → 工厂加工 → 饲料 → 畜牧 → 再加工 的有机产业链
- 心愿屋订单是经验和金币主来源
- 人口 / 社区决定土地与工厂扩建
- 嘉宾驻留给作坊效率 buff
- 烹饪招待、萌宠互动、摆摊、四季烟火气

## 核心循环（锁定）

```
种植 → 磨坊 → 饲料 → 畜牧 → 心愿屋 → 扩建 → 更多种植
```

1. 开垦土地，按季节播种
2. 收获作物，送进磨坊 / 制糖 / 酱料 / 布行
3. 大米等加工成饲料，喂鸡羊牛
4. 鸡蛋、牛奶、羊毛进入更深加工（厨房菜品、豆奶、布）
5. 把产物交给心愿屋 / 货运摊
6. 获得金币、经验、幸福、建材（锹 / 斧 / 锯）
7. 盖房加人、建社区提人口上限、扩建田与厂
8. 升级蘑菇屋，解锁厨房、客房、宠物院
9. 招待嘉宾、做菜、布置家具提升温馨度
10. 更高阶作物 / 工厂 / 节日活动

## 有机产业链铁律（必须被单测锁住）

```
水稻 → 大米 → 鸡饲料 → 鸡蛋
大豆 → 豆腐 →（+牛奶）→ 豆奶
小麦 → 面粉 → 面包
甘蔗 → 糖
大豆+辣椒 → 酱
棉花/羊毛 → 布
大米+玉米/小麦 → 牛/羊饲料 → 牛奶 / 羊毛
```

可测不变量（供 `tests/**` 固化）：

1. 每个饲料配方的输入必含磨坊产物 `rice`（锁「种植→磨坊→饲料」）。
2. `ANIMALS` 的每个 `feedId` 只能由饲料厂（`feedmill`）配方产出（锁「饲料→畜牧」）。
3. 每个畜牧产物（`egg`/`wool`/`milk`）至少出现在一条心愿的 `needs`，或作为菜品原料进入心愿（锁「畜牧→心愿屋」）。
4. 除三种饲料与 `feed_chicken_simple` 外，任何配方满足 `基准价(输出) ≥ Σ基准价(输入)`（饲料的利润在畜牧产物端兑现）。
5. 任何心愿满足 `coin ∈ [1.0, 1.8] × Σ基准价(needs)` 且 `xp ∈ [0.35, 0.6] × coin`。**Round 2 起全表无特例**：`w_veg` 已从 2.33× 校准到 1.67×（10 金 / 5 xp），旧的「≤ 2.4× 引导特例」条款作废。
6. 扩建（新田/新厂/温室田）必须消耗锹/斧/锯，而锹/斧/锯只从心愿掉落（含保底）产出（锁「心愿屋→扩建」）。开局赠送工具是过渡权宜，见「工具经济」。
7. `WISH_POOL` 前 9 条的顺序与 id 永不变更（`refreshWishes` 按下标取单）；扩充只许在池尾追加。
8. Lv.1 心愿池（`minLevel: 1` 的 4 条：晒谷 / 一棵白菜 / 泡豆子 / 两把麦子）的每个 `needs` 都必须能由 Lv.1 玩家在**开局季节（春）**当季种出（白菜为此跨春，见「种植」）。

## 时间与季节

- 1 游戏时 = 6 秒现实时间（可在设置改为 3 / 12 秒）
- 1 日 = 24 游戏时；昼夜影响氛围与部分产出
- 1 季 = 7 游戏日，四季轮转：春 → 夏 → 秋 → 冬
- 作物有适宜季节；错季生长 ×0.55，熟后 45s（真实时间）不收就枯萎
- 冬季畜牧饲料 +20%：确定性余数记账，冬天每喂 5 次有 1 次扣 2 份（**已落地**，`production.winterFeedCarry`；常量事实源为 `data/animals.js` 的 `WINTER_FEED_SURCHARGE = 0.2`，production 自 R3 起 import 再导出）
- 温室田免疫错季惩罚与枯萎——**只罩改造过的地块，不是全场**，见「村落建设 · 温室」

## 三条黄金链路（数值走查）

### 米-鸡链（主循环骨架）

```
水稻田(8金, 18s) → 稻谷×2 → 磨坊(10s) → 大米×1
大米×1 + 玉米×1 → 饲料厂(8s) → 鸡饲料×3
鸡饲料×1 → 鸡(20s) → 鸡蛋×1(15)
心愿「荷包蛋」蛋×2 → 36金 + 16xp
```

一轮账（3 蛋）：种子成本 = 1 亩水稻 8 金 + ⅓ 亩玉米 3 金 = 11 金；产出 3 蛋基值 45，走心愿 ≈ 54 金；净 ≈ +43 金，另得 6+8/3+15+24 ≈ 47 xp。瓶颈是鸡舍 3 工位 × 20s，田在等待期并行。

### 豆-豆腐链（最短变现）

```
大豆田(10金, 20s) → 大豆×2 → 磨坊(12s) → 豆腐×1(22)
心愿「嫩豆腐」→ 32金 + 14xp
```

串行 ≈ 32s，净 +22 金 / +21 xp（含收获 7xp），L2 即成型，是前期主力。L8 深化：豆腐 + 牛奶 → 豆奶（66）→ 心愿「一壶豆奶」88 金 + 36 xp，把牛奶从直卖（44）拉高一档。

### 麦-面包链（跨链协作）

```
小麦田(7金, 16s) → 小麦×2 → 磨坊(10s) → 面粉×1(15)
面粉×1 + 鸡蛋×1(米-鸡链) → 厨房(11s) → 面包×1(36)
心愿「早饭面包」→ 48金 + 20xp
```

面包吃掉米-鸡链的蛋，教会玩家两条链要排产错峰：蛋优先喂面包（48 心愿）还是攒两枚交「荷包蛋」（36），取决于面粉库存。净 ≈ +26 金/轮（扣蛋的 15 基值机会成本）。

## 工具经济（锹 / 斧 / 锯）

正规来源只有心愿掉落。开局白送「锹 2 / 斧 1 / 锯 1」是 Round 1 的 UI 权宜，Round 2 契约改为：

- 开局资源：**锹×1 / 斧×0 / 锯×0**（够开第 3 块田；Opus-4 改 `engine.createInitialState`，与 API_CONTRACT §1 的 Schema v1 一致）
- 新手保底：新档前 3 次交单按序必掉 **斧 → 锯 → 锹**（`TOOL_PITY_ORDER`），正好解锁 L2 磨坊、L3 饲料厂、L3 鸡舍的建材需求
- 干旱保底：此后连续 6 次交单未掉工具（`TOOL_PITY_DROUGHT`），下一单必掉（按权重取）
- 两级保底 + 基础 25% 的有效掉率 ≈ 29%，且最坏干旱被封顶在 7 单

### 温室语义（Round 2 裁决，锁定）

**温室建筑只是前置条件，建成不让全村免疫错季。** 免疫是按地块买的：

- 改造一块露天地 = 80 金 + 锯×1（`farm.expandGreenhousePlot`，**已落地**）
- 全村温室田上限 3 块（`GREENHOUSE_PLOT_CAP`）
- 温室田免错季惩罚与枯萎，罩上时现有枯萎倒计时作废
- 判定 `isGreenhousePlot(plot)`（`plot.greenhouse === true` 或专属编号 g1、g2…）；Round 1 草案的 `plot.greenhouse || buildings.greenhouse?.built` 全场判定**作废**，`tests/economy.test.js` 已按本裁决改为 per-plot 断言
- 改造入口的 reducer/UI 接线为 Opus-4 契约

### 扩建曲线

- 新田：40 金 + 锹×1，田数上限 = min(人口×2, 等级+1)（一人照看两块地）
- 工位：第 n+1 位 = 40 + 20 × n 金，上限 6
- 温室田：80 金 + 锯×1 / 块，上限 3 块
- 摆摊：把库存挂出，按 `stallPrice()`（基准价 × 1.15）出售，茶婆婆在座 ×1.1（网页单机版模拟过路客）
