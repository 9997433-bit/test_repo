# 向往的生活 · 游戏设计文档

> 网页致敬复刻。原创角色、文案与美术；还原综艺/手游的田园慢生活闭环，不做官方素材搬运。

## 一句话

你是蘑菇屋的代理村长：种田、养殖、开作坊、完成心愿、招待嘉宾、把破败小村重新养活。

## 参考来源（玩法，非素材）

芒果 TV 授权田园经营手游《向往的生活》（2023–2025）与同名综艺：

- 蘑菇屋是情感与功能枢纽
- 种植 → 工厂加工 → 饲料 → 畜牧 → 再加工 的有机产业链
- 心愿屋订单是经验和金币主来源
- 人口 / 社区决定土地与工厂扩建
- 嘉宾驻留给作坊效率 buff
- 烹饪招待、萌宠互动、摆摊、四季烟火气

## 核心循环（锁定）

```
种植 → 磨坊 → 饲料 → 畜牧 → 心愿屋 → 扩建 → 更多种植
```

1. 开垦土地，按季节播种
2. 收获作物，送进磨坊 / 制糖 / 酱料 / 布行
3. 大米等加工成饲料，喂鸡羊牛
4. 鸡蛋、牛奶、羊毛进入更深加工（厨房菜品、豆奶、布）
5. 把产物交给心愿屋 / 货运摊
6. 获得金币、经验、幸福、建材（锹 / 斧 / 锯）
7. 盖房加人、建社区提人口上限、扩建田与厂
8. 升级蘑菇屋，解锁厨房、客房、宠物院
9. 招待嘉宾、做菜、布置家具提升温馨度
10. 更高阶作物 / 工厂 / 节日活动

## 有机产业链铁律（必须被单测锁住）

```
水稻 → 大米 → 鸡饲料 → 鸡蛋
大豆 → 豆腐 →（+牛奶）→ 豆奶
小麦 → 面粉 → 面包
甘蔗 → 糖
大豆+辣椒 → 酱
棉花/羊毛 → 布
大米+玉米/小麦 → 牛/羊饲料 → 牛奶 / 羊毛
```

可测不变量（供 `tests/**` 固化）：

1. 每个饲料配方的输入必含磨坊产物 `rice`（锁「种植→磨坊→饲料」）。
2. `ANIMALS` 的每个 `feedId` 只能由饲料厂（`feedmill`）配方产出（锁「饲料→畜牧」）。
3. 每个畜牧产物（`egg`/`wool`/`milk`）至少出现在一条心愿的 `needs`，或作为菜品原料进入心愿（锁「畜牧→心愿屋」）。
4. 除三种饲料与 `feed_chicken_simple` 外，任何配方满足 `基准价(输出) ≥ Σ基准价(输入)`（饲料的利润在畜牧产物端兑现）。
5. 任何心愿满足 `coin ∈ [1.0, 1.8] × Σ基准价(needs)`（引导特例 `w_veg` ≤ 2.4），且 `xp ∈ [0.35, 0.6] × coin`。
6. 扩建（新田/新厂）必须消耗锹/斧/锯，而锹/斧/锯只从心愿掉落与任务产出（锁「心愿屋→扩建」）。
7. `WISH_POOL` 前 9 条的顺序与 id 永不变更（`refreshWishes` 按下标取单）。

## 时间与季节

- 1 游戏时 = 6 秒现实时间（可在设置改为 3 / 12 秒）
- 1 日 = 24 游戏时；昼夜影响氛围与部分产出
- 1 季 = 7 游戏日，四季轮转：春 → 夏 → 秋 → 冬
- 作物有适宜季节；错季生长 ×0.55，且可能枯萎
- 冬季畜牧饲料消耗 +20%（`feedAnimal` 按 `meta.season` 判定，Round 2 接入），温室地块免疫错季惩罚

## 三条黄金链路（数值走查）

### 米-鸡链（主循环骨架）

```
水稻田(8金, 18s) → 稻谷×2 → 磨坊(10s) → 大米×1
大米×1 + 玉米×1 → 饲料厂(8s) → 鸡饲料×3
鸡饲料×1 → 鸡(20s) → 鸡蛋×1(15)
心愿「荷包蛋」蛋×2 → 36金 + 16xp
```

一轮账（3 蛋）：种子成本 = 1 亩水稻 8 金 + ⅓ 亩玉米 3 金 = 11 金；产出 3 蛋基值 45，走心愿 ≈ 54 金；净 ≈ +43 金，另得 6+8/3+15+24 ≈ 47 xp。瓶颈是鸡舍 3 工位 × 20s，田在等待期并行。

### 豆-豆腐链（最短变现）

```
大豆田(10金, 20s) → 大豆×2 → 磨坊(12s) → 豆腐×1(22)
心愿「嫩豆腐」→ 32金 + 14xp
```

串行 ≈ 32s，净 +22 金 / +21 xp（含收获 7xp），L2 即成型，是前期主力。L8 深化：豆腐 + 牛奶 → 豆奶（66）→ 心愿「一壶豆奶」88 金 + 36 xp，把牛奶从直卖（44）拉高一档。

### 麦-面包链（跨链协作）

```
小麦田(7金, 16s) → 小麦×2 → 磨坊(10s) → 面粉×1(15)
面粉×1 + 鸡蛋×1(米-鸡链) → 厨房(11s) → 面包×1(36)
心愿「早饭面包」→ 48金 + 20xp
```

面包吃掉米-鸡链的蛋，教会玩家两条链要排产错峰：蛋优先喂面包（48 心愿）还是攒两枚交「荷包蛋」（36），取决于面粉库存。净 ≈ +26 金/轮（扣蛋的 15 基值机会成本）。

## 心愿屋（数据：`src/data/wishes.js`）

- 同时 3 单，每 2 游戏时刷新 1 空位（灯哥驻留时刷新间隔 ×0.85）
- 挂满 3 游戏日没人交的心愿自动撤下
- 候选过滤：`maxLevel ≥ 等级` 已实现；`minLevel ≤ 等级` 为 Round 2 契约（当前 L1 会刷出布/豆奶单）
- 档位：`tier = min(3, 1 + ⌊(等级−4)/3⌋)`；需求 ×tier、金币 ×tier×1.1、XP ×tier，L4 前保持基线
- 金币 = 表值 × 幸福倍率（1 + ⌊幸福/10⌋ × 4%，封顶 ×2）；每次交单幸福 +1
- 掉落：35% 建材（锹 40 / 斧 35 / 锯 25 权重），4% 珍珠×1（同一存档状态掷点确定，可注入 rng 测试）
- 早期心愿保留 `w_paddy`（晒谷）与 `w_veg`（一棵白菜）作开局引导；`w_veg` 是唯一 >1.8× 的特例（2.33×，上限 2.4×）

池子共 30 条：9 条既有（顺序锁定）+ 21 条扩充，覆盖每种原粮、每种一级/二级加工品、每道菜品；饲料永不进心愿（防抽干畜牧）。多物品大单：`w_combo`（一桌家常 90）、`w_feast`（招待远客 162）。
