# 美术与体验（基线）

## 调性

综艺蘑菇屋的烟火气：木结构、暖黄灯光、菜园泥土、黄昏金边、萤火虫。  
治愈、慢、可停留。禁止赛博霓虹、禁止 UI 堆砌商城感。

## 色令牌（实现于 `src/styles/tokens.css`）

- 春：嫩芽绿 `#7dae5a` / 花瓣粉 `#f3c1b6`
- 夏：稻金 `#e6c36b` / 深荫 `#2f6b4f`
- 秋：柿橙 `#d97b3f` / 茅草 `#c4a574`
- 冬：雪青 `#dfe7ef` / 炭火 `#c45c3e`
- 昼夜：白日高对比，夜晚蘑菇屋窗发光，星点与萤火

## 场景层

远山 → 天空粒子 → 田垄 → 建筑剪影 → NPC / 动物 → UI 木牌面板。  
建筑用 CSS / SVG 几何拼贴，不依赖外部图床。

## 动效

播种轻弹、收获上浮数字、工厂烟囱慢呼吸、嘉宾步行循环。  
尊重 `prefers-reduced-motion`。

## 交互

桌面：点击地块 / 建筑打开木纹面板，快捷键 `1-6` 工具。  
触屏：大热区 ≥ 44px，底部工具条。  
中文文案，语气像邻居聊天，不像系统通知。
