# 蘑菇屋 · 慢生活

《向往的生活》同构田园经营网页致敬作。独立目录，不污染仓库根或其他游戏。

## 怎么玩

```bash
cd games/xiangwang-shenghuo
npm install
npm run dev
```

浏览器打开提示的本地地址（默认 `4175`）。

- 点荒地开垦，点空地播种（先在下方选作物）
- 金黄田块可收获
- 点建筑建造 / 加工 / 投喂
- 右侧心愿屋交单赚钱升级
- 蘑菇屋可做饭、逗宠物

## 脚本

- `npm test` 经济与时间不变量
- `npm run probe` 环境与模块探针
- `npm run bench` 时钟与产业链基准
