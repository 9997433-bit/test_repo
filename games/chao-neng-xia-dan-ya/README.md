# 超能下蛋鸭 · 网页复刻

独立目录的重力弹球 + 卡牌肉鸽网页游戏。不依赖仓库内其他游戏。

线上试玩：https://9997433-bit.github.io/test_repo/chao-neng-xia-dan-ya/

## 运行

```bash
cd games/chao-neng-xia-dan-ya
npm install
npm run dev      # http://localhost:4174
npm test
npm run bench
npm run probe
```

## 操作

- 拖拽 / 触摸滑动瞄准，松开发射
- `1-5` 切换英雄，`Q` 大招，`Esc` 暂停
