# 在用物理链无浏览器基准与预算

## 验收预算

- 60 fps 的渲染帧时长是 `1000 / 60 = 16.667 ms`。
- 战斗物理固定步长为 120 Hz（`1 / 120 s`），每个 60 Hz 渲染帧通过在用适配层执行 2 个固定步。
- Round 3 满载口径是 30 蛋 + 200 静态砖 + 8 力场；整帧物理 p95 必须 `< 4 ms`。
- 同一满载世界执行 1,000 次 `predictTrajectory`，每次最多 90 步 / 3 次反弹，总耗时必须 `< 500 ms`。
- 50 波各运行 60 帧，波间强制 GC 后的留存堆增量必须不高于 2 MiB，线性趋势必须不高于 64 KiB/波，且样本不得严格单调增长。

## 被测链路与场景

`bench.mjs` 和 `stress.mjs` 都从战斗实际使用的 `src/core/sim.js` 构造世界并调用 `stepWorld` / `predictTrajectory`；该适配层再复用 `src/physics/index.js` 的积分、碰撞和弹道实现。场景实体先写入 `world.bricks` / `world.fans`，第一次推进必须经过生产链的 `syncStage`，不再绕过适配层直接填充上游 `statics` / `fields`。

| 脚本 | 场景 | 测量 |
| --- | --- | --- |
| `node scripts/bench.mjs` | 空世界对照 | 预热 1,000 步后，在新世界测量 10,000 个固定步 |
| `node scripts/bench.mjs` | 30 蛋 + 200 砖 + 8 力场 | 17 个确定性世界各推进最多 60 个渲染帧，共采样 1,000 个含两固定步的整帧 |
| `node scripts/bench.mjs` | 在用弹道预测 | 同一满载世界，1,000 次、每次最多 90 步 / 3 次反弹 |
| `node scripts/stress.mjs` | 满载整帧尾延迟 | 预热 300 帧后，以 50 个确定性世界采样 3,000 个整帧，报告 p50/p95/p99 |
| `node scripts/stress.mjs` | 50 波留存堆 | 预热 5 波，再运行 50 波 × 60 帧；每波释放世界并强制 GC 后采样 `heapUsed` |

每个计时世界最多只推进 60 帧，避免开放底边回收后退化为空世界。JSON 的 `workload` 同时报告活动蛋、配置实体数和真实碰撞计数；两条命令均输出 `schemaVersion: 3`、逐项 `criteria` 与顶层 `pass`。

## 2026-08-26 切换后实测

环境：Node `v22.14.0`、Linux x64、Intel Xeon、4 个逻辑 CPU。每条命令在独立 Node 进程中执行 6 次；下表给出六次范围。

| 指标 | 在用物理链实测范围 | 预算对照 |
| --- | ---: | --- |
| bench 满载 1,000 整帧总耗时 | `52.825–67.893 ms` | 信息项 |
| bench 满载整帧平均耗时 | `0.052825–0.067893 ms` | 信息项 |
| bench 满载整帧 p95 | `0.054282–0.070860 ms` | `< 4 ms` |
| bench 满载整帧 p99 | `0.392821–1.018807 ms` | 信息项（含窗口首次同步） |
| 1,000 次弹道预测总耗时 | `40.863–57.636 ms` | `< 500 ms` |
| 单次弹道预测平均耗时 | `0.040863–0.057636 ms` | 信息项 |
| stress 满载 3,000 整帧总耗时 | `118.645–141.157 ms` | 信息项 |
| stress 满载整帧 p50 | `0.030784–0.031781 ms` | 信息项 |
| stress 满载整帧 p95 | `0.046435–0.052987 ms` | `< 4 ms` |
| stress 满载整帧 p99 | `0.168408–0.243254 ms` | 信息项（含窗口首次同步） |
| stress p95 预算占用 | `1.16–1.32%` | `< 100%` |
| 50 波留存堆增量 | `-101,672–87,560 bytes` | `≤ 2,097,152 bytes` |
| 50 波堆线性趋势 | `879.10–1,381.55 bytes/波` | `≤ 65,536 bytes/波` |

工作负载没有退化为空转：

- bench 每次固定产生 15,645 次反弹、3,801 次砖碰撞和 5,814 次蛋碰撞；每个窗口结束仍有 30/30 枚蛋。
- stress 每次固定产生 47,300 次反弹、11,550 次砖碰撞和 17,550 次蛋碰撞；每个窗口结束仍有 30/30 枚蛋。
- 1,000 次弹道预测全部返回有效结果，共 31,000 个轨迹点和 3,000 次反弹。
- 六次 50 波检查均为 `noRetainedGrowthTrend: true`，两条命令六次均为 `pass: true`。

结论：切换后的在用物理链通过 Round 3 预算。六次最差满载整帧 p95 是 `0.070860 ms`，占 4 ms 预算 `1.77%`；最慢 1,000 次弹道预测是 `57.636 ms`，占 500 ms 预算 `11.53%`。Round 1 空脚手架与 Round 2 仅测上游模块的数字均不再作为当前基线。
