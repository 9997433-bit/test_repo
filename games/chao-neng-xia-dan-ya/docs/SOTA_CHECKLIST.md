## 判定规则

每项按现状标 **L0 / L1 / L2**：

| 等级 | 含义 |
| --- | --- |
| L0 | 未实现或形同虚设（不通过） |
| L1 | 功能已落地、可玩，但有口径偏差 / 覆盖缺口 / 登记缺陷（带条件通过） |
| L2 | 达到 SOTA 验收线，无保留（通过） |

整体判级沿用 Round 1 口径：**L1 可玩基线 = P0 全部 ≥L1 且其中无 L0 + 自动化链全绿**；**L2 SOTA 达标 = L1 + P1 全部 ≥L1（允许 ≤2 项带条件）**。

> **Round 2 整体判定：未达 L1（但已远超 L0）。**
> 可玩闭环完整成立（主菜单 / 编队 / 冒险 24 关 / 肉鸽 / 爬塔 / 讨伐 / 钓鱼 / 图鉴 / 设置 / 存档），自动化链命令级全绿；但 P0 中仍有 5 项 L0（PF-07、TC-01/02/03/06，全部集中在**确定性与测试链**），12 项 P0 带条件。L1 缺口全部列于 §三。

### 轴 A · Peggle 手感（PF）

**P0**

- [x] PF-01 `[L1]` 固定步物理 + 渲染插值（O1）
  实况：战斗走 `core/sim.js`——`stepWorld` 将帧长切成 ≤8 个 ≤1/120 子步，再按速度自适应微步（单微步位移 ≤0.6r）；常量达标（重力 1680、蛋 r 7–34、弹性 0.72–0.96、限速 1900）。
  缺陷：不是严格「固定步累加器 + 渲染插值」，子步长随帧长变化（连带 PF-07 失败）；上游 `src/physics` 的严格固定步**未接入战斗**（`adapters.js` 自述「内置积分器（上游已就绪，待接入）」，Round 2 O4 分支未合入）。
- [x] PF-02 `[L1]` 反弹方向正确、动能不增（O1）
  实况：`reflect` 恒 e<1 + 切向摩擦，墙 / AABB / 圆 / 线段法线正确；实玩无加速异常。
  缺陷：对**在用**的 `core/sim.js` 无任何动能单测（TC-01 只覆盖未接线的 `src/physics`）。
- [x] PF-03 `[L1]` 无隧穿（O1）
  实况：速度自适应微步 + `MAX_EGG_SPEED=1900` 钳制，2px 薄段（`circleSegment` 有效半径 r+厚度/2）实玩未见穿透。
  缺陷：无自动化隧穿断言。
- [x] PF-04 `[L2]` 拖拽瞄准 ±70°、初速 220–720（O4）
  实况：`MAX_AIM_DEG=70`、`MIN/MAX_SPEED=220/720`，`setAim` 与 UI 双重钳制，力度条 + 角度扇形可视化。
- [x] PF-05 `[L1]` 预测线与实弹同源、ε≤0.5px（O1+O4）
  实况：`predictTrajectory` 与实弹共用同一 `stepEgg`，默认 3 次反弹预览（设置可降 1），首个命中点画准星。
  缺陷：预测用固定 1/120，实弹用帧长切片子步 → ε≤0.5px **无对拍测试保证**（TC-02 缺失）；双积分器并存问题未解。
- [x] PF-06 `[L1]` 回收判定（O1）
  实况：三条兜底——出界（y−r>830）、低速（<45px/s 持续 0.6s）、超时（14s），实玩无卡回合。
  缺陷：数值与契约（y>820、|v|<8px/s）不一致；`src/physics` 侧测试断言 y>820，与在用实现口径分裂。
- [ ] PF-07 `[L0]` 确定性（O1）
  实况：战斗 RNG 已种子化（`hashSeed`），但物理由 rAF 帧长驱动，同种子两次运行轨迹不可复现；1200 步一致性测试不存在。**Round 3 P0。**
