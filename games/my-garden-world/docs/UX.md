# UX 说明 · 我的花园世界

本文档归 fable-ux 维护，描述新手教程、核心交互流程、空/错误状态与移动端手势。涉及文件：`src/data/story.ts`（剧情与门槛数据）、`src/ui/tutorial.ts`（教程渲染与门槛判定）。

## 一、新手教程（六折，门槛式）

教程共六折，采用「折」作章回单位。第一折与最后一折是纯剧情；中间四折各带一个**行为门槛**：玩家没有真正完成对应操作前，「继续」按钮保持置灰，无法点过。

| # | id | 标题 | 门槛（gate） | 达成判定 |
|---|----|------|--------------|----------|
| 一 | `wake` | 荒园来信 | 无 | 点按即过 |
| 二 | `sow` | 下一粒种 | `sow` | `stats.planted ≥ 1` |
| 三 | `water` | 引一瓢水 | `water` | 任一花圃 `watered > 0`（或已有收获） |
| 四 | `harvest` | 剪一枝花 | `harvest` | `stats.harvested ≥ 1` |
| 五 | `order` | 接头一单 | `order` | `stats.ordersDone ≥ 1` |
| 六 | `open` | 自此看花 | 无 | 点按或 Esc 收起 |

设计要点：

- **剧情折**（一、六）沿用 `.modal` 默认样式，居中大幅呈现，营造章回感。
- **门槛折**（二至五）以内联样式收成**顶部横幅**（宽 ≤ 520px，含 safe-area 偏移），让出整座花园与底部工具栏供玩家实际操作。
- 每折显示进度（「第X折 · 共六折」）与目标行：未达成为「◌ 目标 · ……」，达成后变为松石绿的「✓ 已成 · ……」，按钮同步亮起并换文案（如「待你下种……」→「种下了，继续」）。
- 门槛判定是**累计式**的：抢先多做了后面的操作（比如教程还在第二折时就浇了水），进入后续折时按钮直接亮起，不强迫重做。
- **键盘 Esc**：仅在最后一折生效，按下即收起教程开园；前五折按 Esc 无效，门槛不可跳过。最后一折的横幅上有「按 Esc 键亦可收起」提示。

### 与 app.ts 的接口契约

- `renderTutorial(host, state, onNext)`：幂等。外层无论每帧调用（旧版 `paint`）还是仅在换折时调用（新版签名重绘），都不会重建按钮 DOM——同折重复调用只做门槛状态同步，保证 mousedown/mouseup 落在同一元素上。
- `advanceTutorial(state)`：步进 `tutorialStep`，走完置 `tutorialDone`。
- 教程自带 250ms 轮询：门槛折在外层不重绘的情况下也能感知玩家进度并点亮按钮；弹窗被移除或教程完成时轮询自动停止。
- 教程弹窗元素带 `data-tutorial="1"` 与 `data-beat` 标记，外层可按 `.modal` 选择器整体移除。

## 二、核心交互流程

主循环：**播种 → 浇水（→施肥）→ 收获 → 插花/交付订单 → 装扮庭院、请花灵**。

1. **选圃与工具**：底部工具栏切换洒水/施肥/收获工具后点按花圃生效；点圃同时会选中它（金框高亮）。
2. **播种**：点一块空圃选中 → 开「花种」面板 → 点花卡即种下（金币购种）。无选中时自动落到第一块空圃。
3. **浇水**：切「洒水」后点按花圃，或**按住拖过多块花圃连续浇灌**（见移动端手势）。花圃上的水滴点（pips）显示 已浇/需水；水缸每 8 秒回 1 滴，订单奖励也回水。
4. **收获**：花开（「可收」标签）后用「收获」剪下入库；拖过花期会凋残（「凋残 · 速收」），只回两成残值、不入库。
5. **订单**：「订单」面板列出客人需求与倒计时；花材/作品齐备时「交付」可点，缺什么会在按钮提示里写明。「婉拒」换新客但损 4 点口碑；订单超时同样损口碑。
6. **花艺作坊**：选 2–4 枝库存花材、择一花器成作评分；高分作品用于交付定制订单。
7. **装扮与花灵**：金币/碎片购置装饰、套主题；升阶解锁花灵，驻园给增益。

## 三、空状态与错误状态

### 面板空状态（占位文案，非弹窗）

| 场景 | 文案 |
|------|------|
| 订单面板无单 | 客人正在路上…… |
| 作坊无库存花材 | 库存空空，先去花圃收获。 |
| 作坊无陈列作品 | 陈列：空，成作后可交付定制订单。 |
| 库存面板为空 | 匣中空空，去花圃收获几枝吧。 |
| 花种卡不可种 | 还差 N 金 / 暂无空圃（卡片置灰并注明原因） |
| 空花圃 | 圃面显示「空圃／待播种」水印 |

### 错误与受阻状态（warn 色 toast，自动消散、可点按关闭）

| 操作 | 文案 |
|------|------|
| 播种钱不够 | 金币不足，买不起这袋种子 |
| 浇水没水 | 水缸空了，等一等或去做订单 |
| 交付缺指定花 | 花材尚未备齐 · 还缺某花 |
| 交付缺任意花 | 库存花材不足 · 还差 N 枝 |
| 定制单无作品 | 定制单要凭作品交付，先去作坊插一瓶 |
| 定制单分不够 | 这件作品还配不上定制 · 需 N 分 |
| 插花枝数不对 | 请放入 2 至 4 枝花材 |
| 未选花器 | 请先选一只花器 |
| 婉拒订单 | 客人离去，口碑微损 |
| 订单超时 | 客人久候不至，口碑微损 |
| 扩建钱不够 | 扩建需 N 金 |
| 收获凋残花 | 某花已凋残，只清出些许残料 |
| 花灵未解锁 | N 阶后方可请某花灵 |

原则：**受阻必有回声**——任何点了没生效的操作都给一条 warn toast 说明原因与出路（等水回、去做订单、先去作坊……），不做无声失败。相同文案短时间连发会合并成一条并计数。

## 四、移动端手势

- **点按（tap）**：按下与抬起落在同一块花圃视为点按，执行当前工具（种/浇/肥/收）。
- **拖拽浇水（drag）**：洒水工具下按住并扫过花圃，途经的每块只浇一次，抬手后汇总提示「洒水润泽 N 处花圃」。实现上主动释放触摸的 pointer capture，保证手指能拖过相邻花圃；花园容器 `touch-action: none`，拖拽不会触发页面滚动。
- **门槛折教程横幅**顶部悬浮且限宽，不遮花圃与工具栏；剧情折全屏模态在小屏（≤640px）加大内边距占比（`inset: 8% 4%`）。
- toast 与教程横幅均计入 `safe-area-inset-top`，避开刘海。
- 面板（sheet）从底部升起、内部可滚动，小屏最大高约 62vh，不盖住工具栏。

## 五、键盘

- `Esc`：教程最后一折收起开园（唯一键盘捷径，前五折无效）。
- 花圃是 `<button>`，天然可 Tab 聚焦、Enter/Space 触发当前工具；状态经 `aria-label`/`title` 播报。
