# 游戏设计文档 · 我的花园世界（致敬仿写）

## 一句话

扮演穿越花艺师，把荒废宅第花园经营成四季繁花的国风花坊。

## 玩家幻想

在墨色亭台与锦鲤池边，亲手育花、配器插花、接待来客，让一座废园重新开花。

## 核心循环（30 秒）

选种播种 → 浇水/施肥催熟 → 收获花材 → 花艺作坊配器成束 → 交付订单得金币/经验 → 扩建花圃与装扮庭院 → 解锁花灵与更高阶花种。

## 生长阶段

`empty → seeded → sprout → bud → bloom → wilt(超时未收)`

每阶段需水分；缺水停滞。施肥缩短剩余时间。季节匹配时生长倍率 1.35，错季 0.75。花灵可再乘加速。

## 花艺作坊

选择花器（陶瓶/青瓷/竹筒/青铜）+ 2~4 枝花材。评分看：主花层次、配色和谐、季节主题、器花匹配。高分作品可交付高价订单或陈列。

## 订单

- 居民订单：简单花材，经验多金币少
- 花艺定制：指定作品评分档
- 绸缎/建材：用金币或作品换扩建材料（简化为“绸缎券”）
- 组团订单：大批量，时限紧，奖励高

退单降低当日“口碑”，口碑影响客单价。

## 花灵

解锁后驻园，提供：生长加速、自动浇水、驱虫（防枯萎）、订单口碑。同时仅一名出战。

## 装扮

地块外的庭院层：灯笼、石径、亭、池、屏风。主题：春晓 / 盛夏 / 秋宴 / 冬雪 / 墨雅。可一键套用再微调。

## 胜利与长线

无终局。里程碑：花园等级 5/10/15，盛会剧情，收集图鉴 100%。

## 平台

桌面 + 窄屏手机。键鼠与触摸同一套交互（点击地块、拖水壶）。
