# 造化仙府 · 游戏设计文档

## 一句话

洞府经营 × 弟子养成 × 阵营回合自动战：从一座荒废仙府起步，聚灵、开田、招徒、炼丹锻器，率人/神/魔仙友登天塔、御兽潮，证道飞升。

## 参考原作

《造化仙府》（沛炫网络 / 微信小游戏 + 手游）核心卖点：

- 仙府经营：洞府仙居决定建筑上限；灵田 / 木坊 / 石坊保资源；丹房 / 锻造房提战力；灵脉环绕灵田吃邻接加成。
- 弟子：勤勉型采集、武力型战斗；专业等级影响产量。
- 阵营：人（稳、平民）、神（成型强）、魔（爆发、低容错）。
- 法器：攻击 / 防御 / 通用三槽；七星灯、万魂灯、阴阳镜、诛魔刃、残阳妖铠、镇岳钟、朱雀赤羽弓、瑶光潜渊贝等。
- 挑战：登天塔（每章 10 层，5/10 层首领）、兽潮防御。
- 放置：离线按建筑与境界产出，上线一键领取。

本复刻为**公平网页单机**：无付费档、无抽卡氪金，强度只来自经营、阵容克制与操作节奏。

## 核心循环

1. 选阵营入世 → 2. 建/升仙府建筑、派弟子生产 → 3. 修炼突破、炼丹锻器 → 4. 组 6 人阵容打登天塔 / 兽潮 → 5. 掉落法器碎片与天材地宝 → 6. 提高建筑上限与境界 → 7. 更高塔层与兽潮波次。

## 境界

练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升。

每境 9 层。突破失败不掉境，消耗 60% 丹药并积「心魔值」，下次成功率 +8%（上限 +40%）。

## 阵营与仙友

- **人族**：慈航真人、后羿、通天教主、姜子牙 + 人族主角。稳、治疗与破甲。
- **神族**：杨戬、哪吒、真武大帝、九天玄女、女娲 + 神族主角。高成长、反击与增伤。
- **魔族**：孙悟空、猪八戒、申公豹、玉面公主 + 魔族主角。爆发、暴击、低容错。

阵容 6 席：主角锁定 + 5 仙友。克制：神克魔、魔克人、人克神（伤害 ×1.18）。

## 法器（四槽）

攻击 / 防御 / 通用 / 通用。触发按战斗事件（开场、低血、击杀、普攻、大招）。

## 登天塔

每章 10 层；第 5、10 层首领。镇岳钟仅对怪物/首领斩杀生效。失败不掉层，可炼丹再战。

## 兽潮

波次敌人递增，需在仙府门口布阵。失败损失当波 30% 未收取资源。

## 公平性

无内购、无抽卡概率付费。仙友通过悬赏、塔层、剧情解锁。
