# 验收标准（Release Gate）

本文件是《造化仙府》复刻的**发布判定书**：每条验收项都给出可执行的验证方法与通过条件。
细粒度逐项清单与 Round 3 复审差距见 `docs/SOTA_CHECKLIST.md`（两文互相引用，编号一致）。

- 判定规则：G 系列（功能门槛）与 B 系列（数值平衡）**全部通过**方可宣布 SOTA 复刻完成；
  单条不过即整体不过，不允许"大体可用"式模糊验收。**口径类条目（G5.4/G5.2 税基等）以
  「机制、data、GDD、UI 文案四方一致」为通过前提**——任何一方掉队即不过
  （G5.4 已按此前提通过；G5.2 只差 UI 文案一方）。
- 验证环境：`cd games/zaohua-xianfu`，Node ≥ 20，依赖经 `npm install` 就绪；浏览器验收用
  `npm run dev` 后打开 `http://localhost:4174`（端口 4174 为契约，不得改动）。
- 本文修订基线：commit `274b40e` + 2026-08-26 Round 3 复审（已闭环：R2-1 槽型定案、
  R2-3 修业接线、R2-5 直入账阈值提至 60s、R2-6 回归补回、R2-2 之死代码删除。
  仍开项见清单：R2-2 残余（一句 UI 文案）/R2-4/R2-7/R2-8/R2-9/R2-10）。
