# 验收标准（Release Gate）

本文件是《造化仙府》复刻的**发布判定书**：每条验收项都给出可执行的验证方法与通过条件。
细粒度逐项清单与 Round 1 已证实差距见 `docs/SOTA_CHECKLIST.md`（两文互相引用，编号一致）。

- 判定规则：G 系列（功能门槛）与 B 系列（数值平衡）**全部通过**方可宣布 SOTA 复刻完成；
  单条不过即整体不过，不允许"大体可用"式模糊验收。
- 验证环境：`cd games/zaohua-xianfu`，Node ≥ 20，依赖经 `npm install` 就绪；浏览器验收用
  `npm run dev` 后打开 `http://localhost:4174`（端口 4174 为契约，不得改动）。
- 本文修订基线：commit `419f9d7` + 2026-08-26 Round 1 并发工作区实测（详见清单附录）。
