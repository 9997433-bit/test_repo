# 美术方向

## 气质

清雅国风:**纸本水墨为底,朱砂与泥金点睛**。不是赛博修仙,也不是 Q 版卡通;定位是「漆木沙盘洞天 + 工笔名录笺」——像一幅摊在案上的山水手卷,府邸沙盘、弟子名录、战报印章都是卷上的裱片。

三条铁律:

1. 一切颜色、圆角、阴影、时长取自 `src/styles/tokens.css`,组件文件不许出现裸 hex(装饰性 rgba 微调除外)。
2. 纯 CSS 实现——纹理、远山、印章全部用渐变与伪元素,零图片、零新依赖。
3. 动效克制:金边一闪 280ms、血条推移 280ms、粒子慢升;禁止全屏闪光。

### 描线

`--line`(纸色发丝线,卡片外框)、`--line-strong`(可交互描边)、`--line-gold` / `--line-gold-dim`(金边:卡角裱边、悬浮态)、`--line-cinnabar`(危险描边)。

## 纹理配方(全 CSS,无图片)

- **纸纹 `--grain`**:两层 1px 重复线性渐变(纵横交错、透明度 ≤ 0.045),叠在卡面与顶栏,近看有帘纹、远看不可察。
- **远山雾霭**(`body` 背景):七层渐变——左上金霞、右上朱霭、底部灵息青,叠三座石青/松绿的椭圆「远山」,压在 `#261a10 → --ink → --ink-0` 的暮色墨底上。
- **沙盘等高线**(`.plot-grid`):`repeating-radial-gradient` 画同心细环(透明度 0.024),加顶部受光与四周 `inset` 深影,形成「漆木框中盛沙」的下陷感。
- **裱边角**(`.card::before/::after`):左上、右下两枚 13px 金丝 L 形角线,来自手卷裱片的包角。

## 字体与题字

- 标题:Ma Shan Zheng(楷书笔意),`font-weight: 400`,`letter-spacing: 0.1em+`——书法字体不加粗。
- 正文:Noto Serif SC;数字一律 `tabular-nums`。
- 开屏「造化仙府」:纸白→泥金→暗金的 `background-clip: text` 鎏金题字,加 `drop-shadow` 托墨。
- **印章体系**(伪元素,不占 DOM):
  - 引首章:顶栏题字前的「洞天」朱砂竖排小印,`rotate(-3deg)`;
  - 落款印:开屏题字右下的同款印,`rotate(3deg)`;
  - 战果印(`.vs`):3.2rem 朱砂方章钤「胜 / 败」,`radial-gradient` 做印泥浓淡,纸色双线印框,`rotate(-4deg)` 仿手钤。

## 人 / 神 / 魔 可辨

阵营三色贯穿全局,选阵营牌(`.faction[data-faction=…]`)用三重信号编码,不靠单一颜色:

| 阵营 | 主色 | 水印字 | 顶缘线 |
| --- | --- | --- | --- |
| 人族 mortal | `--pine-bright` 松绿 | 「人」 | 松绿丝线 |
| 神族 divine | `--gold-bright` 泥金 | 「神」 | 泥金丝线 |
| 魔族 demon | `--cinnabar-bright` 朱砂 | 「魔」 | 朱砂丝线 |

水印为 6.4rem 楷书大字淡书于牌角(opacity 0.12,悬浮升至 0.22)。战场同理:我方(仙府)标题泥金、敌阵标题朱砂,并各带同色笔锋下划线。

## 组件语汇

- **卡片**:纸本裱片——纸纹 + 左上受光渐变 + 金丝内衬(inset box-shadow)+ 两枚金角。标题为泥金楷书,前缀朱砂小菱 `◆`,压一道向右淡出的金丝线。
- **签条导航**:横向滚动不折行(七签在 320px 也不崩);当前签金字加粗,底压「朱→金」3px 笔锋。
- **资源筹码**:墨底圆签,标签纸灰、数值泥金等宽。
- **按钮三级**:素笺(默认,悬浮金边)/ 朱漆 `primary`(上亮下深的漆面 + 内高光)/ 泥金 `gold`(墨字金身,最高优先级动作)。按下 `translateY(1px)` 落笔感。「重置」降为石青小字素描边,悬浮才转朱砂。
- **沙盘地块**:空地为虚线圈地;建筑为浮雕小筑(顶部受光、金丝勒边、落影),楷书字号 + 金签等级(`Lv.` 药丸);选中金环外扩 + 光晕。地色经 `--plot-accent` 调制,默认松绿,三新筑按五行换色(见「经营信号」节)。
- **气血/修为条**:墨槽内 `深朱→朱→金` 的火焰渐变,顶缘一线高光,宽度推移 280ms。
- **府报**:朱点起行、虚线分条,最新一条纸白、余者纸灰。
- **战损**:褪墨(灰度 0.75 + opacity 0.38)、虚框、名字朱线划除——三信号并用,色盲亦可辨。

## 经营信号(R2 增补):三新筑 / 风水 / 法器槽位

`tokens.css` 新增一层**语义别名令牌**,全部引自基色,组件端只取语义名;调色只动令牌层。
铁律一的补充口径:`color-mix(in srgb, var(--令牌) N%, transparent)` 视同取令牌,不算裸色。
本节新增以着色为主,仅两处轻排版(分组题压线的 0.25rem 底衬、评签 `::before` 自书评语),零新动效——窄屏断点与 `prefers-reduced-motion` 行为不变。

### 三新筑地色(`--bld-*`)

沙盘建筑地块由 `--plot-accent`(地色)与 `--plot-glyph`(字号色)调制,默认松绿;三新筑按**五行**换色,与楷书字号、建筑名构成三信号,不靠单一颜色(窄屏舍名后仍有字号 + 地色两信号):

| 建筑 | 五行 | 令牌 | 地色 | 字号色 |
| --- | --- | --- | --- | --- |
| 灵泉「泉」 | 水 | `--bld-spring(-ink)` | 泉青 `--spirit` | `--spirit` |
| 悬赏阁「赏」 | 金 | `--bld-bounty(-ink)` | 泥金 `--gold` | `--gold-bright` |
| 演武场「武」 | 火 | `--bld-drill(-ink)` | 朱砂 `--cinnabar` | `--cinnabar-bright` |

选择器双轨:现有 DOM 按 `.plot.filled[aria-label^="灵泉"]` 名称前缀命中(aria-label 恒以建筑名开头);`[data-type="spring"]` 钩子并列备用,UI 层日后补 data 属性即自动接管,样式零改动。地色用 `color-mix` 从令牌调透明度,前置一条松绿字面量作老浏览器回落。金丝勒边、悬浮金边、选中金环一律不变——金仍是「可交互」的专用信号。

### 营造目录

`.build-list` 条目内造价/拦截原因(`.muted`)退为 0.72rem 价笺小字;不可点条目(未解锁、资源不足、已驻守)改**虚框**示禁,透明度从全局 0.38 抬到 0.55,保证「为何不可」读得清——禁用态靠虚框 + 灰字双信号,不只靠变淡。

### 风水评签(`--fengshui-*`)

摘要行每秒产量数字(`.rate-line b`)鎏金,与顶栏资源筹码同语汇。风水分徽章 `.fengshui[data-tier]` 视觉已齐、只候 DOM:上吉 `good` 泥金 / 中平 `fair` 石青淡彩 / 下乘 `poor` 朱砂,药丸描边取同色 45% 透明,再铺同色 8% 淡染。评语(上吉/中平/下乘)由 `::before` 依 `data-tier` 楷体自书,UI 不必拼评语文案——评语 + 分数 + 档色三信号并用,不靠单一颜色。接入时把「风水 s/100」包进 `<span class="fengshui" data-tier="…">` 即得完整评签,档位建议 ≥70 上吉、≥35 中平、其余下乘;未落 `data-tier` 退为素签,老浏览器不识 `color-mix` 时丢描边/淡染、保留分档文字色。

### 法器槽位(`--slot-*`)

| 槽位 | 令牌 | 色 |
| --- | --- | --- |
| 攻击 attack | `--slot-attack(-ink)` | 朱砂 |
| 防御 defend | `--slot-defend(-ink)` | 石青 `--azurite` |
| 通用 util | `--slot-util(-ink)` | 青莲 `--lotus` |

已佩法器(`.art-card.in`)默认与上阵弟子同语汇:鎏金侧栏 + 淡金渐染。`data-slot` 钩子的视觉已补齐、只候 DOM——UI 层(AD-8 改造)给四处落上 `data-slot` 即自动转槽色,样式零改动:

- `.art-card.in[data-slot]` 已佩卡片:侧栏、描边、渐染整卡转槽色,比例与金版一致(描边 50% / 渐染 10%);
- `.d-chip[data-slot]` 槽签 chip:槽色文字 + 55% 描边 + 9% 淡染;
- `h4.sub[data-slot]` 法器名录分组题:槽色文字压 currentColor 笔锋线(与战场标题同语汇;旧版误写 `border-color`,而 `h4.sub` 无边框,已改压底一线);
- `.slot-row[data-slot]` 槽位盘行:行名与计数转槽色,已佩格 `.slot-cell.filled` 改槽色 45% 描边 + 10% 淡染;空格与「未佩 / 无槽 / 已满」保持素虚框——金仍是「可交互」的专用信号。

退化口径:未落 `data-slot` 时规则不命中,观感与现版一致;老浏览器不识 `color-mix` 的声明整条失效,回落 `.art-card.in` 与 `.slot-cell.filled` 的既有金底——退化仍是完整视觉,故不设字面量回落。**槽位色与品阶色分工**:品阶 chip(金品/红品)沿用金/朱文字,槽位另用朱/石青/青莲三色,二者不混用。

## 动效

| 动效 | 时长 | 备注 |
| --- | --- | --- |
| 悬浮金边 / 签条切换 | 150ms `--t-fast` | `--ease-brush` 起笔快收笔缓 |
| 血条推移 / 金线一闪 | 280ms `--t-med` | |
| 灵气粒子 `.spirit-orb` | 3.6s 循环慢升 | 单粒 9px,禁大面积粒子 |
| 阵营牌 / 地块悬浮 | 150ms,`translateY(-3px / -1px)` | |

**`prefers-reduced-motion: reduce` 策略**:不作 `animation: none`(会丢终态),而是全局时长压至 0.01ms、循环一次;悬浮位移 `transform: none`;灵气粒子整体 `display: none`。

## 无障碍

- 正文对比 ≥ 4.5:1(`--paper` 于 `--ink` ≈ 13.9:1;`--wash` 注释 ≈ 6.5:1;暗底彩字一律 `-bright` 档)。
- 焦点环:全局 `:focus-visible` 亮金 2px 外扩环,任何底色可见;输入框另有金晕。
- 选区、滚动条随主题(泥金选区、浮面墨滑块)。
- 状态编码不依赖单一颜色(见战损、阵营)。
