# 美术方向

## 气质

清雅国风、纸本水墨底 + 朱砂/雌黄点睛。不是赛博修仙，也不是 Q 版无脑卡通；偏「 cub 仙府沙盘 + 工笔小像」。

## 色板

| token | hex | 用途 |
| --- | --- | --- |
| `--ink` | `#1b140f` | 底 |
| `--paper` | `#f3e6c9` | 纸 |
| `--cinnabar` | `#c23b22` | 强调、危险、魔 |
| `--gold` | `#d4a017` | 神、突破、仙玉 |
| `--pine` | `#2f6b4f` | 人、灵田 |

## 字体

- 标题：Ma Shan Zheng
- 正文：Noto Serif SC
- 数字：tabular-nums，石青色

## 动效

- 灵气：慢上升粒子，12–18fps 错觉即可
- 建筑升级：纸面金边一闪 280ms
- 战斗：血条与飘字，禁止闪瞎眼全屏

## 无障碍

对比度正文 ≥ 4.5:1；焦点环可见；减少动效遵循 `prefers-reduced-motion`。
