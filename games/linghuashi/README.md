# 灵画师 · 墨御

独立目录中的《灵画师》SOTA 网页复刻：以笔绘符、水墨国风、职业克制、境界养成、画阁与挂机。

本游戏位于 `games/linghuashi/`，不占用仓库根，便于同目录再放其他游戏。

## 玩法

- 六式符箓：直线穿透、曲线束缚、圆圈护盾、折线破甲、螺旋阵法、云形回春
- 双输入：鼠标/触屏挥毫，或键盘【1–6】施法（合成笔迹走同一识别管线），Esc 收笔撤退
- 六职业 + 隐藏墨客：剑修 / 体修 / 法修 / 道修 / 妖修 / 气修；六式精度皆达 60% 感召「墨客」
- 五行反应与职业克制环；敌人特性：迅捷、甲壳、狂化、回复、反噬
- 十关秘境顺序解锁（含终章 Boss「执墨者」），敌方意图电报可读
- 教程关：六式引导虚线逐式教学，键盘亦可走完
- 养成：境界突破、三系天赋（攻伐/守御/辅弼）、灵兽三栏（暴击/回灵/开盾），全部实际接入战斗
- 画阁：每笔墨迹归一化存档，点击回放挥毫动画；六式精进度一目了然
- 挂机：离线按境界产灵气丹与包子，8 小时封顶

## 无障碍

- 全程键盘可玩（教程与战斗均可 1–6 施法）
- 战斗日志 aria-live、血条 progressbar、择业 radiogroup、切屏焦点管理
- 设置内可静音与减少动效，另尊重 `prefers-reduced-motion`

## 开发

```bash
cd games/linghuashi
npm install
npm run dev      # http://localhost:4173
npm test         # 70 项：识别/模板/战斗/养成/教程/循环/UI 冒烟
npm run probe    # 冒烟探针：识别+模板+战斗+tick 守恒+解锁+迁移
npm run bench    # 性能预算：识别 <4ms/笔、战斗 tick <0.05ms
npm run build    # 生产构建
```
