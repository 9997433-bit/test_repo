# 灵画师 · 墨御

独立目录中的《灵画师》网页复刻：以笔绘符、水墨国风、职业克制、境界养成、画阁回放与挂机。

## 目录隔离

本游戏完整地住在 `games/linghuashi/` 里：自带 `package.json`、`vite.config.js`、`node_modules`、测试与文档，不向仓库根写任何文件，也不依赖根目录的构建配置。同目录可以并排再放其他游戏，互不影响。所有命令都在 `games/linghuashi/` 内执行。

## 玩法

- 六式符箓：直线穿云剑（穿透直伤）、曲线缚灵丝（束缚并伤）、圆护体罡（护盾）、折线破军刺（破甲穿刺）、螺旋五行阵（最高倍率轰击）、云纹回春笔（治疗）；识别失败落为「余墨」弱攻击兜底
- 手绘施法：鼠标/触屏在宣纸画布上落笔，识别器按轨迹判型，精度与笔势（速度反推伪压感）决定威力
- 七职业：剑修 / 体修 / 法修 / 道修 / 妖修 / 气修，外加隐藏职业「墨客」——在画阁集齐六种笔法（余墨不计，精度不设门槛）即解锁
- 五行反应（水火蒸发、水木藤缚、金雷引暴击、压制/受制）与七职业克制环（剑→妖→气→法→体→道→墨→剑）
- 十三关秘境（山海经 × 敦煌），从入卷试笔到终章 Boss「帝江浑沌」；关卡全部开放不上锁，推荐境界仅作提示，打不过就回头刷修为
- 敌方意图电报可读：出手前 400ms 翻为「蓄势」，被缚时显示「被缚」且出手冷却冻结
- 教程：首次进战斗弹出「入世第一课」，图解六式与两条施法通路（图例与真实识别模板同源），枢纽可随时重看
- 养成：境界突破（练气到飞升九境）、三系天赋（攻伐/守御/辅弼，各三点五级）、灵兽三栏（暴击/回灵/开盾，可收伏/合成/洗练/放生），全部实际接入战斗
- 挂机：离线按境界产灵气丹、按 0.6/分产包子，8 小时封顶；包子是收兽的主要货币

## 键盘施法（1–6）

- 战斗中按数字键 **1–6**（或点击画布下方的符键条）依次施放直线、曲线、圆、折线、螺旋、云纹
- 按键会合成一段标准轨迹，走与手绘完全相同的识别管线；精度固定 0.7、笔势固定 0.6，模板不匹配时精度再 ×0.8——键盘路径可预期，但不会强过手绘满精度
- 键盘施法的墨迹会回显在画布上，同样计入画阁与墨客解锁
- **Esc** 收笔撤退回枢纽；教程弹层内 Esc 关闭弹层
- 符键条实时标注每式的灵气消耗，灵气不足时置灰（`aria-disabled`）

## 画阁回放

- 战斗中每一笔真正成符的墨迹（灵气不足散掉的不算）都会归一化存档：降采样到 32 点、收进 [0,1]² 单位空间，换设备也能按当时的笔路回放；最多留最近 24 笔（约 18KB）
- 进入画阁自动逐笔错开回放（每笔约 0.62 秒的挥毫动画，一次起笔逐点续接一次收笔），点单张卡片重看该笔，也可「重放全部」
- 卡片标注笔法名与精度；开启减少动效（或系统 `prefers-reduced-motion`）时整笔直接落纸不播动画
- 早期旧档只记了笔法没有笔路，画阁用标准字形占位并标注「无笔路」
- 画阁同时显示六式收集进度：集齐六种笔法即感召隐藏职业「墨客」

## 无障碍

- 全程键盘可玩：战斗 1–6 施法、Esc 撤退，择业 radiogroup 支持方向键，切屏自动聚焦标题
- 战斗日志 `role="log"` + aria-live、血条/灵气条 progressbar、符键条 `aria-keyshortcuts`、画阁卡片带完整 aria-label
- 各屏工具区提供静音开关（声息/静音），枢纽与画阁另有减少动效开关（流墨/静纸），改动立即落盘；另尊重系统 `prefers-reduced-motion`

## 存档

- 单键 localStorage JSON（`linghuashi.save.v1`，版本号以 JSON 内 `version` 为准，当前 v2）
- 旧档读取时自动逐级迁移（v0 字符串画阁、v1 无 uid 灵兽都能救回），迁移前原始串备份到 `linghuashi.save.bak`
- 战斗态不入存档：读档回到枢纽，不会站在半场战斗里

## 开发

```bash
cd games/linghuashi
npm install
npm run dev      # 开发服务器 http://localhost:4173（--host 0.0.0.0，端口固定）
npm test         # vitest 全量：识别/模板/战斗/养成/画阁/存档迁移/灵兽面板/动效/UI 冒烟
npm run probe    # 冒烟探针：六式识别 + 余墨兜底 + 战斗 50 回合守恒
npm run bench    # 性能预算：3000 笔识别均值与 p95 ≤ 4ms/笔，战斗压力测输出每回合耗时
npm run build    # 生产构建到 dist/
npm run preview  # 预览生产构建（同端口 4173）
```
