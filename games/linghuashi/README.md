# 灵画师 · 墨御

独立目录中的《灵画师》SOTA 网页复刻：以笔绘符、水墨国风、职业克制、境界养成、画阁与挂机。

本游戏位于 `games/linghuashi/`，不占用仓库根，便于同目录再放其他游戏。

## 玩法

- 直线穿透、曲线束缚、圆圈护盾、折线破甲、螺旋阵法、云形回春
- 六职业：剑修 / 体修 / 法修 / 道修 / 妖修 / 气修
- 五行反应与职业克制
- 秘境出战、天赋、灵兽、挂机领丹

## 开发

```bash
cd games/linghuashi
npm install
npm run dev      # http://localhost:4173
npm test
npm run probe
npm run bench
```
