# 灵画师 · 游戏设计文档（数值版）

## 一句话

以笔绘符、以画通灵的国风修仙网页游戏：绘制轨迹即施法，精度与笔势决定威力。

## 核心循环

1. 选职入世 → 2. 出战秘境 / 画阁回看 / 挂机化缘 → 3. 战斗中手绘符咒或按 1~6 施法 → 4. 胜场结算修为与灵气丹（挂机另产包子） → 5. 突破境界、点天赋、收伏养成灵兽 → 6. 更深秘境。

## 绘符识别（战斗主操作）

| 轨迹 | 符箓 | 灵气 | 战斗倍率 | 效果 |
| --- | --- | --- | --- | --- |
| 直线 line | 穿云剑 | 13 | ×1.0 | 单体直伤，越直精度越高 |
| 曲线 curve | 缚灵丝 | 14 | ×0.55 | 附控制 `(500 + 1100×精度 + 反应控制) × supMult` 毫秒 |
| 圆 circle | 护体罡 | 16 | — | 护盾 `(18 + 42×精度×(1+加成)) × defMult + 灵兽盾` |
| 折线 zigzag | 破军刺 | 18 | ×1.15 | 破甲：敌受伤 `+4% + 12%×精度`，上限 +35% |
| 螺旋 spiral | 五行阵 | 20 | ×1.25 | 最高单发倍率，手绘难度也最高 |
| 云形 cloud | 回春笔 | 15 | — | 治疗 `(16 + 36×精度×(1+加成)) × supMult` |
| 兜底 scribble | 余墨 | 9 | ×1.0 | 识别失败的弱攻击，精度仅 0.15~0.4 |

精度 `precision ∈ [0,1]`：识别置信 × 几何规整度 × 最小长度门槛；战斗侧下限钳到 0.2。
笔势 `pressure`：速度反推伪压感，影响墨迹粗细与伤害区间（见公式）。
键盘施法（1~6 键，或点击符键条）：合成标准轨迹走同一识别管线，固定精度 0.7、
笔势 0.6，模板不匹配时精度 ×0.8——键盘路径可预期，但不会强过手绘满精度。
Esc 收笔撤退。键盘笔同样计入画阁与墨客解锁。

余墨定价说明：余墨曾为 4 灵气，在精度钳到 0.2 时每灵气伤害约 0.22×攻击，
是直线（0.115×攻击）的近两倍——纯点废笔反而是最优解。改为 9 灵气后每灵气
约 0.098×攻击，回到「兜底但不亏」的定位；只有妖修（scribble +22%）能把它打平直线。

破甲定价说明：破甲原为 `8% + 8%×精度`，在战斗侧精度下限 0.2 处每层仍有 0.096
（满精度 0.16 的六成），乱画 4 笔即封顶 35%——对精度几乎不敏感。现收紧为
`4% + 12%×精度`（底噪减半、斜率抬高）：下限每层 0.064（满值四成），封顶从
4 笔变 6 笔（按 18 灵气/笔多付 36 灵气），满精度仍 3 笔封顶、每层 0.16 不变。
高手零损失、乱画显著变慢，气修/妖修的新手下限回落到与剑修/法修同档。
该公式已落地 combat/battle.js（SHRED_BASE 0.04 / SHRED_PER_PRECISION 0.12 /
SHRED_CAP 0.35）。预算权重按精度 0.75 折算时每层 0.13（旧 0.14），
zigzag 权重 1.1 与各职业加权预算无需重算。

控制定价说明：控制时长同理收紧为 `500 + 1100×精度` 毫秒（旧 `700 + 900×精度`）：
满精度仍 1600ms 不变，精度下限 0.2 处从 880ms（满值 55%）降到 720ms（45%），
乱画的免伤窗口显著变短而高手零损失。已落地 combat/battle.js
（CONTROL_BASE_MS 500 / CONTROL_PER_PRECISION_MS 1100）。

## 伤害总公式（combat/battle.js）

```
伤害 = 攻击
     × (0.65 + 1.15 × 精度)          // 精度段：0.88 ~ 1.80
     × (1 + 职业笔法加成)             // classes.js bonus
     × (0.85 + 0.30 × 笔势)          // 笔势段：0.85 ~ 1.15
     × atkMult                       // 天赋攻击树（1 + 0.19/级 满 1.95）
     × 五行反应                       // 0.82 ~ 1.35，见下表
     × 克制系数                       // 克敌 1.18 / 被克 0.88
     × (1 + 敌方破甲层)               // zigzag 叠层，≤ 1.35
     × 连击倍率                       // 1200ms 窗口内连续施法 +6%/层，≤ 5 层（+30%）
     × 暴击                          // (灵兽暴击率 + 金雷引 15%) 触发，×1.6
```

再乘符箓自身倍率（表见上）。灵气回复固定 8/秒 + 灵兽 qiRegen；
敌人每 1800ms 出手一次，伤害 `敌攻 × (0.85~1.25)`，被控期间出手冷却冻结。
敌方意图可读（combat/ai.js）：出手前 400ms 翻为「蓄势」，被控显示「被缚」，
其余时间「观势」——护盾与控制可以踩着电报出。

## 职业与加成预算

单点加成对不同笔法价值不同，按「每灵气产出」折算权重：

```
zigzag 1.1（破甲叠层实战最值钱）| line 1.0 | spiral 0.85 | curve 0.55（控制不吃加成）
circle 0.6 | cloud 0.6 | scribble 0.35
加权预算 = Σ(bonus × 权重)，全职业统一 0.31 ~ 0.35
```

| 职业 | 定位 | 本命 | bonus | 加权预算 |
| --- | --- | --- | --- | --- |
| 剑修 jian | 爆发 | 金 | line 24% · zigzag 10% | 0.350 |
| 体修 ti | 坦克 | 土 | circle 32% · line 12% | 0.312 |
| 法修 fa | 法师 | 火 | spiral 28% · curve 14% | 0.315 |
| 道修 dao | 治疗 | 木 | cloud 30% · circle 10% · line 8% | 0.320 |
| 妖修 yao | 召唤 | 木 | curve 30% · scribble 22% · zigzag 8% | 0.330 |
| 气修 qi | 刺客 | 雷 | zigzag 24% · spiral 8% | 0.332 |
| 墨客 mo（隐藏） | 控制 | 水 | curve 18% · spiral 14% · cloud 12% · circle 8% | 0.338 |

旧版失衡：剑修加权 0.40、妖修仅 0.16；本版把剑修 line 28%→24%，
给道修补 8% line（治疗不再打不死人）、给妖修补 zigzag 并把余墨做成本命武器。
20 局×13 关×7 职业模拟（精度 0.75、1 笔/秒）：全职业推荐境界胜率 100%，
平均击杀 3.4~5.6 秒（气修最快、墨客最慢但最稳），终局 Boss 战 5~11 秒。

墨客解锁：画阁集齐六式笔法（余墨不计），四系全能但单项皆非顶尖，
作为通关奖励允许预算略高（0.338）。

### 克制环

```
剑 → 妖 → 气 → 法 → 体 → 道 → 墨 → 剑
```

七职业闭环，每职业恰克一个、被克一个（旧版剑修游离环外、妖修被双克）。
克制方伤害 ×1.18，被克方 ×0.88。敌人也占用职业位，用于排布关卡顺逆风。

## 敌人与关卡曲线（山海经 × 敦煌）

敌人数值锚点（推荐境界攻击记 A、生命记 H）：

```
敌 hp  ≈ A × （前期 6~8 | 后期 10~14 | 终局 Boss ~18）
敌 atk ≈ H × 1.8/20 （敌 1800ms 一击，玩家不防不奶约扛 20 秒）
```

后期血量抬高的原因：若击杀恒快于裸抗窗口，战斗退化为纯竞速，护盾/治疗/控制
永无出场机会。抬到 10~14×A 后，低精度乱画在后期会输给生存窗，
必须靠防御笔法、克制选关或回去刷修为/天赋弥补——这正是技术上限的来源。

十三关全部开放、不设顺序锁：推荐境界只是提示（data/stages.js 的 tier，
战斗代码不读取），玩家可以随时越级挑战或回头刷修为——门槛由数值曲线而非开关把守。

## 灵兽（progression/beasts.js）

| 被动 | 一星基准 | 二星 ×1.65 | 三星 ×2.6 | 持有者 |
| --- | --- | --- | --- | --- |
| crit 暴击率 | 0.08 | 0.132 | 0.208 | 墨狐、白泽崽 |
| qiRegen 回气/秒 | 2 | 3.3 | 5.2 | 纸鲤、迦陵频伽 |
| shield 附加盾 | 12 | 19.8 | 31.2 | 山海鹿、旋龟 |

养成定价（数值源为 data/beasts.js 导出常量；例外见表注）：

| 操作 | 货币 | 数值 | 常量 |
| --- | --- | --- | --- |
| 收兽（6 种均匀随机，包子优先） | 包子 | 36（不足时灵气丹 8 兜底） | `BEAST_CATCH_COST`（丹价暂在 progression 层） |
| 洗练（必换被动） | 灵气丹 | 18 | `BEAST_REROLL_COST` |
| 合成（同种同星升星） | 灵气丹 | 30 × 星级 | `BEAST_EVOLVE_COST_PER_STAR` |
| 放生（腾栏，UI 二次确认） | 包子 | 返还 18（收兽价折半，只退包子） | `RELEASE_REFUND`（progression 由收兽价推得） |

栏位 3。收兽定价锚：包子只产自挂机（0.6/分），36 = 一小时挂机产出，
满额一次结算（288）恰好 8 只；至此包子有了主消耗出口（对应架构 D10
「buns 无消耗」），首兽在新档约 1 小时挂机后即可入手；包子攒不齐时
可用 8 灵气丹替付，新档不至于卡在零包子。放生返还 = ⌊收兽包子价 / 2⌋，
且只退包子——用灵气丹替付收的兽放生也退包子，防止「收兽↔放生」刷丹。
洗练/合成维持 progression 现值（18 / 30×星级）零变化，仅把数值源迁到 data 层。
约束：同一被动全图鉴 value 必须一致（升星与洗练按首见基准重算）。

## 天赋（classes/talents.js）

三树九点，每点 12 丹、5 级封顶（全满 540 丹）：
攻（6%/5%/8% → atkMult 满 1.95）、防（10%/4%/8% → defMult 满 2.10）、
辅（12%/8%/10% → 治疗 heal 满 2.00、控制 control 满 1.90，linger 双吃）。

## 挂机经济（progression/idle.js）

```
灵气丹 = min(离线分钟, 480) × 境界 idlePerMin
包子   = min(离线分钟, 480) × 0.6
```

8 小时封顶。满挂练气 1920 丹 ≈ 天赋 160 级消耗节奏的源头，后期以关卡奖励为主。
包子的消耗出口是收兽（`BEAST_CATCH_COST` = 36/只，见「灵兽」节）：满挂一档
恰好 8 只；放生按收兽价折半返还包子。若上调 0.6/分的产率，须同步重定收兽价，
保持「约一小时挂机一只」。

## 非战斗系统

- 画阁：保存最近 24 笔成符墨迹（每笔归一化 32 点存入 [0,1]²，约 18KB 上限），
  点卡片按原笔路回放约 0.62 秒挥毫动画，进阁自动逐笔错开重放，可一键重放全部；
  减少动效时整笔直接落纸。旧档无笔路的条目用标准字形占位。
  集齐六种不同笔法（余墨不计，精度不设门槛）即解锁隐藏职业墨客。
- 灵兽：收伏、合成、被动洗练、放生（3 栏位，四门操作都在枢纽灵兽卡内）。
- 教程：首次进战斗弹「入世第一课」，图解六式与两条施法通路，图例与真实识别
  模板同源；枢纽可随时重看。
- 存档：单键 localStorage JSON（版本以 `version` 字段为准，当前 v2）；旧档读取时
  逐级迁移（v0 字符串画阁、v1 无 uid 灵兽都能救回），迁移前原始串备份到
  `linghuashi.save.bak`。战斗态不入存档，读档回枢纽。
- 公平：无付费档，强度只来自技术、克制与养成。

## 调参守则

1. 改职业 bonus 前先按权重重算加权预算，压回 0.31~0.35。
2. 改符箓 qi 前重算「每灵气伤害」，保持 line 为基本盘上限、余墨不越线。
3. 新敌人套 `hp≈(6~18)A 分段、atk≈H×0.09` 锚点，新关奖励沿 xp ×1.2~1.35/关外推。
4. 练气 xp=80 与 idlePerMin=4 有测试断言，动之前改 tests/progression.test.js。
5. 新灵兽只用三种被动且 value 对齐基准；新增被动需先扩 battleModifiers 消费端。
6. 灵兽成本只改 data/beasts.js 的 `BEAST_*_COST*` 常量，progression/UI 不得
   另写字面量（现存例外：收兽的 8 丹替付价暂在 progression 层，待补
   `BEAST_CATCH_QI_COST` 后上移）；放生返还 = ⌊收兽价/2⌋ 自动联动，无需单改。
   改收兽价先按 0.6 包子/分换算成「多少分钟挂机一只」，低于 30 分钟包子会
   重新失去意义，高于 180 分钟新手首兽太迟。

## 已知平衡风险

- 破甲（`0.04+0.12×精度`）与控制（`500+1100×精度` ms）均已按建议收紧并落地
  combat/battle.js（见「破甲定价说明」「控制定价说明」），不再是风险项。
- 三只异种灵兽在手的死锁已由「放生」解开（返还半价包子，见「灵兽」节）；
  残余风险是放生返还只退包子，重度洗练玩家的灵气丹仍只出不进——观察后期
  丹经济，必要时给三星兽加放生退丹。
- 黛瓦古村（水狼）对新手法修是硬克制墙（火受制 ×0.82），设计上靠回打入卷试笔
  刷两胜升筑基即可碾过；若玩家反馈过挫，可把墨瞳狼五行改 earth。
- 熟练玩家可稳定越一级打关，属「技术换进度」的预期收益；若挂机产出后续上调，
  需同步抬后期关卡血量锚点，防止双重加速。
- 收兽包子不足时的 8 丹替付明显便宜于 36 包子的时间价值（约 0.7 关早期关奖励）：
  刻意如此，给新档一个快速首兽入口；若后期出现「只用丹收兽」，把替付价
  抬到 20~30 丹即可，不动包子主价。
