# 灵画师 · 游戏设计文档（基线）

## 一句话

以笔绘符、以画通灵的国风修仙网页游戏：绘制轨迹即施法，精度与笔势决定威力。

## 核心循环

1. 选职入世 → 2. 画阁修炼 / 出战秘境 / 挂机化缘 → 3. 战斗中手绘符咒 → 4. 掉落灵气丹、符纸、灵兽幼体 → 5. 突破境界、点天赋、养成灵兽 → 6. 更高秘境。

## 绘符识别（战斗主操作）

| 轨迹 | 技能原型 | 默认效果 |
| --- | --- | --- |
| 直线 line | 穿云剑 / 穿透 | 单体高伤，直线越直倍率越高 |
| 曲线 curve | 缚灵丝 / 控制 | 范围减速或束缚 |
| 圆 circle | 护体罡 / 盾 | 护盾量随闭合度上升 |
| 折线 zigzag | 破军刺 / 穿刺 | 破甲 + 爆发 |
| 螺旋 spiral | 五行阵 / 元素爆发 | 按当前元素打 AoE |
| 云形 cloud | 回春笔 / 治疗 | 道修加成，回复生命 |

精度 `precision ∈ [0,1]`：识别置信 × 几何规整度 × 最小长度门槛。  
笔势 `pressure`：速度反推伪压感，影响墨迹粗细与覆盖半径。  
未识别或过短：消耗少量灵气，释放「余墨」弱攻击，保证新手不空放。

## 职业

剑修、体修、法修、道修、妖修、气修；隐藏进阶墨客（画阁收藏满 6 式解锁）。

克制环：`体 → 道 → 禅 → 妖 → 气 → 法 → 体`（禅为 NPC/秘境敌人位，玩家侧由墨客暂代）。

## 五行

金木水火土 + 雷（气修偏雷）。反应：水火蒸发（伤×1.35）、水木藤缚（控制+0.4s）、金雷引（暴击+15%）。

## 境界

练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 飞升。

## 非战斗系统

- 画阁：保存自己的符咒笔迹（归一化 32 点），可回放挥毫动画；展示六式最佳精度。
- 挂机：离线按境界产出灵气丹与包子，上线一键领取，8 小时封顶。
- 灵兽：捕捉（40 丹）、放归、被动叠加（3 只栏位：暴击/回灵/开盾），实际接入战斗。
- 公平：无付费档，强度只来自技术、克制与养成。

## 战斗节奏（本轮定稿）

- 固定步长 200ms 累加器 tick：任意帧率下敌方出手次数守恒；挂起恢复钳制 1s。
- 敌方意图电报：游走观势 → 蓄势欲袭（槽 >70%）→ 出手；受缚显示倒计时。
- 连击：3 秒窗口内连续成符，伤害 +4%/层（封顶 +30%）。
- 敌人特性：迅捷（出手 -25% 间隔）、甲壳（开局 20% 盾，折线双倍削盾）、狂化（<45% 血伤害 ×1.35）、回复（0.8%/s，受缚停止）、反噬（反弹 10% 笔伤）。
- 护盾缓慢衰减（3/s），鼓励攻防轮换而非无限叠盾。

## 键盘施法与无障碍

- 【1–6】对应六式：合成模板笔迹走同一识别管线，威力按模板精度 ×0.85（手绘可超越），
  但六式精进按模板原始精度记录——键盘玩家同样能感召墨客。
- 教程六步均可键盘完成；Esc 收笔撤退。

## 关卡（10 关）

入卷试笔（教学）→ 黛瓦古村 → 潇湘竹海 → 画阁夜巡 → 太液莲池 → 莫高残壁 → 丹炉遗窟 → 寒潭镜面 → 禅钟秘境 → 墨渊天阙（Boss 执墨者）。顺序解锁，胜过前一关开启下一关。

## 墨客解锁（定稿）

六式各有一笔精度 ≥ 60%（`strokeStats` 记录历史最佳）即解锁隐藏职业墨客；择业页出现第七席，洞府亦有「感召墨客」捷径。
