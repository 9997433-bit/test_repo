# 三国：冰河时代（网页致敬作）

独立目录网页 SLG，致敬《三国：冰河时代》：**火炉为核心的极寒城建 + 魏蜀吴群武将养成 + 兵种/阵营克制自动战**。

纯 ESM、零依赖、无打包——任何静态服务器即可游玩；模拟层与 UI 完全解耦，Node 可直接跑单测/基准/平衡探针。

## 运行

```bash
cd games/sanguo-ice-age
npm start          # 即 python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4173/`。

## 测试

```bash
npm test           # node tests/runner.mjs — 107 项零依赖单测（含全模块导入烟测）
npm run bench      # node tests/bench.mjs  — 模拟/战斗/招贤性能基准
npm run probe      # node tests/probes.mjs — 贪心机器人 60 天自动局平衡验证 + 放置必败压力验证
```

## 玩法

- **火炉**：全城命脉。等级 = 其他建筑等级上限；烧木/煤维持温度，可调火候（熄/微/正常/旺）与燃料（自动/只木/只煤）。
- **资源**：肉 / 木 / 煤 / 铁，仓库扩容，厨房省粮。
- **寒潮**：每约 7 天一次且逐次加深——降温、减产、民心下降、冻毙流失；医馆/城墙/暖房减伤。
- **16 种建筑**：伐木场、猎人小屋、煤矿、铁矿、民居、仓库、厨房、步/弓/骑兵营、军医所、太学院、招贤馆、城墙、使节馆、医馆、火炉。
- **44+ 武将**：魏蜀吴群 × 蓝紫橙红品质；招贤馆抽卡，重复得将魂养成；三人编队，同阵营协同（2 同 +8%，3 同 +20%）。
- **克制**：阵营 吴→蜀→魏→吴（+20%）；兵种 步克骑、骑克弓、弓克步（+35%）。
- **讨伐**：12 关自动战，回合制战报（技能/克制/溃散），军医所抢救战损。
- **主线**：15 个任务自动判定发奖；行军令每日恢复。
- **操作**：空格暂停，1/2/3 变速（1×/2×/4×），点击城镇建筑定位面板，20 秒自动存档，可导入/导出 JSON 存档。

## 画面

Canvas 2.5D 等距城镇：程序化建筑造型、雪粒子（寒潮增强）、小人通勤、火炉暖光与寒潮冷色调、昼夜光照、屋顶积雪、等级金点与建筑旗标。

## 结构

```
index.html  css/style.css
js/
  config.js            # 全部数值参数（气候/经济/民心/军队/战斗/招贤/建筑成本）
  engine/              # rng（确定性）/loop（固定步长）/save（可注入存储）/bus
  data/                # 16 建筑、44+ 武将、12 讨伐关、15 主线任务
  sim/                 # 纯逻辑：气候/经济/人口/建筑/武将/练兵/战斗/任务/使节/tick
  render/              # Canvas 2.5D 渲染：等距投影/雪/小人/光照
  ui/                  # DOM UI：顶栏/六页签/弹窗/toast/日志栏
tests/
  harness.mjs runner.mjs bench.mjs probes.mjs bot.mjs cases/*.test.mjs
```

模拟层不触碰 DOM，`sim/` 与 `engine/` 在 Node 与浏览器中行为一致；战斗与招贤共用存档内 RNG 状态，同一存档同一操作序列结果可复现。
