# 三国：冰河时代（网页致敬作）

独立目录网页 SLG，模仿《三国：冰河时代》的极寒城建 + 武将养成 + 自动战斗。

本目录与仓库内其他游戏隔离，可单独打开运行。

## 运行

```bash
cd games/sanguo-ice-age
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4173/`。

## 测试

```bash
node tests/runner.mjs
node tests/bench.mjs
node tests/probes.mjs
```

## 核心玩法

1. 升级 **火炉**（决定其他建筑等级上限，燃烧木/煤维持温度）
2. 发展伐木场、猎人小屋、煤矿、铁矿，囤积寒潮物资
3. 维持民心与人口，厨房/医馆/暖房降低寒潮崩盘风险
4. 招贤馆招募魏蜀吴群武将，凑同阵营加成
5. 编队讨伐流寇，步骑弓互相克制
