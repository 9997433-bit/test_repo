# 三国：冰河时代 · UX 规范 v1

本文是 `css/tokens.css` 的配套规范。所有颜色、尺寸、动效引用均为该文件中的
CSS 变量；所有数值阈值均对齐 `js/config.js`（温度阈值 -6 / 0 / 8，民心崩溃线
15，寒潮每 7 天一次、持续 2 天，每天 16 tick、每 tick 250ms）。

---

## 0. 设计原则

1. **火即希望，温度即张力。** 画面的"视觉温度"必须跟随游戏温度移动：舒适时
   炉火暖光从屏幕底部涌起（`--clime-veil` 暖相），冻结时冷雾从顶部压下、HUD
   描边结霜（`--hud-edge` → `--border-frost`）。玩家不看数字也能感知处境。
2. **数字优先可读。** 资源、温度、民心是每秒都在看的数字：一律
   `--font-num` + `tabular-nums`，禁止数字跳动引起横向抖动。
3. **危机要被看见，但不惩罚感官。** 警报闪烁频率 < 3 次/秒、最多闪 3 次后转
   常亮（WCAG 2.3.1），亮度变化用不透明度而非纯白爆闪。
4. **单机快节奏，操作 ≤ 2 层。** 任何高频操作（升级、招募、出征）从主界面
   出发最多点两次。弹层永远可用 Esc / 点击遮罩关闭。

## 1. 信息架构

```
主城（唯一常驻场景）
├── 顶栏 HUD（常驻）
│   ├── 日期与寒潮倒计时（第 N 天 · 距寒潮 N 天 / 寒潮进行中）
│   ├── 资源四联：肉 food · 木 wood · 煤 coal · 铁 iron（存量 + 每秒净增减）
│   ├── 温度计（中央主视觉，读数 + 温度带色 + 趋势箭头）
│   ├── 人口（当前/上限）
│   └── 民心（0–100，<30 预警，≤15 崩溃）
├── 左栏：武将（roster）
│   ├── 武将卡列表（品质框 + 阵营徽记 + 兵种 + 战力）
│   ├── 同阵营羁绊加成提示（魏/蜀/吴/群 计数）
│   └── 空态（未招募）
├── 右栏：建筑列表
│   ├── 分组：热源（火炉/暖房） · 生产（伐木场/猎人小屋/煤矿/铁矿）
│   │        · 民生（厨房/医馆） · 军事（校场）
│   ├── 每行：图标 · 名称 Lv · 产出/耗能摘要 · 升级按钮（费用）
│   └── 锁定行（"火炉 Lv.N 解锁"）
├── 底坞 dock（四大行动）
│   ├── [1] 火炉：燃料策略（烧木/烧煤/混烧）、温度详情
│   ├── [2] 招贤：招贤馆抽取武将（消耗资源）
│   ├── [3] 讨伐：编队（步/骑/弓） → 选流寇目标 → 自动战斗战报
│   └── [4] 太学：科技/政策树（全局增益）
├── 弹层
│   ├── Modal：建筑详情 / 武将详情 / 战报回放 / 招贤结果
│   ├── Drawer（窄屏）：左右栏收纳为抽屉
│   ├── 事件横幅：寒潮预警、寒潮降临、崩溃警告（顶部下探）
│   └── Toast：资源不足、升级完成、羁绊激活（右上堆叠，最多 3 条）
└── 全屏罩层（pointer-events: none）
    ├── 气氛罩 --clime-veil（z: --z-weather）
    ├── 风雪粒子（canvas，z: --z-weather）
    └── 危机红晕 --crisis-vignette（z: --z-vignette）
```

## 2. HUD 布局

### 2.1 桌面骨架（≥ 1200px）

```
┌─────────────────────────────────────────────────────────────────┐
│ 顶栏 --hud-top-h(56px)  --bg-hud + backdrop-filter --panel-blur │
│ [第7天·距寒潮1天] [肉 木 煤 铁]   [ -4.2° ▼ ]   [人口] [民心]  │
├──────────┬───────────────────────────────────────┬──────────────┤
│ 左栏武将  │                                       │ 右栏建筑     │
│ --rail-  │        主城场景（火炉居中，            │ --rail-      │
│ left-w   │        建筑环绕，辉光 --glow-warm-lg） │ right-w      │
│ (296px)  │                                       │ (324px)      │
├──────────┴───────────────────────────────────────┴──────────────┤
│ 底坞 --dock-h(72px)：[1 火炉] [2 招贤] [3 讨伐] [4 太学]        │
└─────────────────────────────────────────────────────────────────┘
```

- 容器：CSS Grid，`grid-template-rows: var(--hud-top-h) 1fr var(--dock-h)`，
  `grid-template-columns: var(--rail-left-w) 1fr var(--rail-right-w)`。
- 左右栏为浮层面板（`--bg-panel` + `--panel-blur` + `--bevel-frost` +
  `--shadow-2`），不遮挡场景边缘辉光；内部滚动，外部不滚。
- 场景层 `z: --z-scene`，可拖拽平移；HUD 各区 `--z-hud/--z-rail/--z-dock`。

### 2.2 顶栏细则

| 区块 | 规格 |
| --- | --- |
| 日期 | `--fs-sm` `--text-mid`；寒潮倒计时 ≤1 天时切 `--warn-400` + `--anim-pulse` |
| 资源四联 | 每项 = 图标(16px, 资源色 `--res-*`) + 存量(`--fs-lg` `--font-num` `--text-hi`) + 每秒净值(`--fs-2xs`，正 `--success-400` / 负 `--danger-400`)。存量变化用 300ms 数字滚动，不闪色块 |
| 温度计 | 顶栏视觉锚点：读数 `--fs-3xl` `--font-display`，颜色 `--temp-readout`（随温度带自动切换）；旁附趋势箭头与"到冻结还差 N°"微文案 |
| 民心 | 数字 + 迷你条（槽 `--bg-inset`，填充 `--success-400`，<30 转 `--warn-400`，≤15 转 `--danger-500` + `--anim-pulse`） |

资源即将耗尽（按当前净耗 < 1 天）时，对应资源项加 `--danger-400` 下划线并
触发一次 `--anim-shake`，同时 Toast 提示，不做持续闪烁。

### 2.3 左栏 · 武将

- 武将卡：56px 高行卡。品质用**双通道**表达：边框渐变 `--q-*-frame` +
  ★数（蓝★ / 紫★★ / 橙★★★ / 红★★★★，`--q-*-text` 着色）。
- 阵营徽记：20px 圆形，底色 `rgb(var(--f-*-rgb)/.18)`，描边 `--f-*`，内为
  单字"魏/蜀/吴/群"（`--f-*-bright`）。颜色仅是辅助，单字才是主通道。
- 栏底常驻羁绊条：如"蜀 ×3 → 攻+9%"，激活时 `--success-300` + 一次
  `--anim-pop-in`。
- 排序：战力降序；出征中的武将行加 `--text-low` 蒙灰 + "出征中"角标。

### 2.4 右栏 · 建筑

- 分组标题 `--fs-xs` `--ls-wide` `--text-low` 大写间距风格。
- 每行：图标 · 名称+Lv（`--text-hi`）· 摘要（`--text-mid`，如"木 +2.4/s
  煤 -0.3/s"）· 右侧升级按钮。
- 升级按钮三态：可升（`--ember-500` 实心 + `--text-inverse`，悬浮
  `--glow-warm`）；资源不足（描边灰态 + 缺口资源标红，点击触发
  `--anim-shake`）；达火炉上限（禁用 + "受火炉等级限制"提示）。
- 锁定行：整体 `--text-low`，左侧锁形符号，文案"火炉 Lv.N 解锁"。

### 2.5 底坞

- 四按钮等分，`--tap-min` 以上命中；图标 24px + 文字 `--fs-xs` + 快捷键
  角标（1/2/3/4，`--fs-2xs` `--text-low`）。
- 当前激活面板对应按钮加 `--border-ember` 上边线 + `--text-warm`。
- 红点脉冲（`--anim-pulse`）规则：招贤可免费抽 / 讨伐部队已归来 /
  太学有可研项且资源足够。

### 2.6 断点

| 断点 | 行为 |
| --- | --- |
| ≥ 1200px | 三栏常驻（上图） |
| 900–1199px | 左右栏改为图标窄条（56px），悬浮/点击展开为覆盖式面板 |
| < 900px（token 已自动重映射） | 左右栏转全高抽屉（宽 `--rail-*-w` = min(86vw, …)），由底坞左右两端的把手或边缘轻扫唤出；顶栏 48px，资源四联收合为两列；底坞加 `--safe-bottom` |

## 3. 空态与危急态

### 3.1 空态

| 位置 | 文案 | CTA |
| --- | --- | --- |
| 左栏无武将 | 符号"❄ 空座" + "帐下尚无武将，乱世英杰正待明主。" | 主按钮"前往招贤（2）"，跳底坞招贤 |
| 讨伐无战报 | "尚未出征。流寇在风雪中窥伺你的存粮。" | "编队讨伐（3）"；无武将时按钮禁用并提示先招贤 |
| 太学未解锁 | 整面板灰态 + "火炉 Lv.3 后，学问方能取暖。" | 无 CTA，点击火炉等级文字可跳火炉面板 |
| 招贤结果为空史 | "招贤榜虚位以待。" | 首抽按钮加 `--anim-pulse` |

空态插画统一用字符/线稿风（雪花、空印绶），色 `--text-low`，不引入位图。

### 3.2 温度状态机（视觉合同）

JS 每 tick 把状态写到 `<html>`：`data-temp ∈ comfort | mild | cold | freeze`，
`data-crisis ∈ ""(移除) | blizzard | collapse`。CSS 端零 JS 动画逻辑。

| 温度带 | 阈值（config） | 视觉 |
| --- | --- | --- |
| comfort | ≥ 8° | 暖罩自底部涌起，温度读数 `--temp-comfort` |
| mild | 0–8° | 默认态，读数 `--temp-mild` |
| cold | -6–0° | 冷雾顶部压下（`--clime-veil` 加重），读数 `--temp-cold`，风雪粒子出现 |
| freeze | ≤ -6° | 读数 `--temp-freeze`，HUD 描边结霜（`--hud-edge`），粒子加密，左栏武将卡浮现霜纹角标 |

### 3.3 寒潮（红闪规范）

时间线（寒潮每 7 天、持续 2 天）：

1. **T-1 天预警**：顶部事件横幅下探（`--anim-pop-in`），底色
   `rgb(var(--warn-400-rgb)/.15)`、描边 `--warn-400`，文案"寒潮将至：明日
   气温骤降 14°。囤积燃料！"。倒计时进入顶栏日期区。横幅 6s 后自动收起，
   可手动关闭，关闭后顶栏保留角标。
2. **寒潮降临瞬间**：全屏危机罩（`--z-vignette`，pointer-events: none）
   执行 `--anim-danger-flash`——**1.6s 一循环、共 3 次、约 0.6 闪/秒**，
   之后切 `--anim-crisis-breathe` 常亮红晕呼吸。同时 `role="alert"` 播报
   "寒潮降临"。禁止任何元素做高频白闪。
3. **寒潮期间**：`data-crisis="blizzard"` 常驻：红晕呼吸 + `--clime-accent`
   转 `--danger-400`（温度计、倒计时同步变红）；每日燃料缺口在火炉按钮上
   以红角标常显。
4. **寒潮结束**：红晕 480ms 淡出（`--dur-4`），Toast"寒潮退去"（
   `--success-300`），温度带视觉自然回落。

### 3.4 民心崩溃

- **预警（民心 < 30）**：顶栏民心条转 `--warn-400`；左栏顶部出现常驻黄条
  "民心浮动：加餐或提高温度"。
- **崩溃（民心 ≤ 15，`MORALE.collapseAt`）**：`data-crisis="collapse"`——
  画面整体 `--panel-desat`（去饱和 + 压暗），黑色暗角罩，**不闪烁**：崩溃
  的情绪是"死寂"而非"警报"。事件横幅（`--danger-500` 描边）说明后果
  （人口流失速率）与两条明确出路按钮："加开厨房" / "提高供暖"。
- 恢复到 > 20 后延迟 2 天再解除崩溃视觉，避免在阈值上反复横跳。
- 寒潮与崩溃同时发生时，`collapse` 的去饱和优先，红晕保留但停止呼吸
  （两套全屏动画不叠加）。

### 3.5 即时反馈

- 资源增减浮字：`--anim-rise-fade`，正值 `--success-300`、负值
  `--danger-300`，同一资源 500ms 内合并为一条。
- 升级完成：建筑行 `--anim-pop-in` + 一次 `--glow-warm` 外发光渐隐。
- 战斗结算：战报 Modal 内逐段展开（每段 `--dur-2` 级联），胜负标题用
  `--fs-hero` `--font-display`。

## 4. 键盘与触控

### 4.1 键盘映射

| 键 | 作用 |
| --- | --- |
| `1 / 2 / 3 / 4` | 打开底坞：火炉 / 招贤 / 讨伐 / 太学（再按一次关闭） |
| `Space` | 暂停 / 继续（暂停时全屏顶部显示"⏸ 已暂停"细条） |
| `Esc` | 关闭最上层弹层；无弹层时打开系统菜单（存档/设置） |
| `G` | 聚焦左栏武将列表 |
| `B` | 聚焦右栏建筑列表 |
| `↑ ↓` | 列表内移动（roving tabindex，仅一个 tab 停靠点） |
| `Enter / Space` | 激活当前项（打开详情 / 确认升级） |
| `U` | 对当前聚焦建筑执行升级（不足时播 `--anim-shake` + Toast） |
| `Tab` | 区块级循环：顶栏 → 右栏 → 场景 → 左栏 → 底坞 |
| `?` | 快捷键帮助 Modal |

- Modal 内焦点圈闭（focus trap），关闭后焦点还原到触发元素。
- 所有可聚焦元素依赖全局 `:focus-visible` 焦点环（`--ring-color`），
  禁止 `outline: none` 裸奔。

### 4.2 触控

- 命中区一律 ≥ `--tap-min`(44px)；底坞按钮实际命中含上下留白 ≥ 48px。
- 左/右屏幕边缘 20px 内水平轻扫 → 唤出武将/建筑抽屉；抽屉内下拉不穿透。
- 长按 350ms → 显示 tooltip（费用明细 / 武将属性）；松手即散。
- 场景单指拖拽平移、双指捏合缩放；交互层设
  `touch-action: manipulation` 防双击缩放误触。
- 底坞是拇指区：高频操作永不放在顶栏（顶栏只读）。

## 5. 无障碍

### 5.1 对比度（WCAG 2.x 实测值）

| 前景 → 背景 | 比值 | 判定 |
| --- | --- | --- |
| `--text-hi` → `--bg-app` | ≈ 16.6:1 | AAA |
| `--text-hi` → `--bg-panel-solid` | ≈ 14.4:1 | AAA |
| `--text-mid` → `--bg-panel-solid` | ≈ 8.1:1 | AAA |
| `--text-low` → `--bg-panel-solid` | ≈ 5.1:1 | AA（仅辅助文字） |
| `--text-warm`(ember-300) → 面板 | ≈ 10.1:1 | AAA |
| `--temp-cold`(frost-300) → 面板 | ≈ 10.7:1 | AAA |
| `--temp-freeze` → 面板 | ≈ 11.6:1 | AAA |
| `--text-inverse` → `--ember-500`（主按钮） | ≈ 8.8:1 | AAA |
| `--danger-300` → 面板 | ≈ 8.2:1 | AAA |
| 品质 blue/purple/orange → 面板 | 6.6 / 6.6 / 8.1 | AA+ |
| 品质 red：`--q-red` 5.1 → 小字用 `--q-red-text` | ≈ 6.9:1 | AA |
| 阵营小字一律用 `--f-*-bright` | 7.4–10.0 | AAA |

规则：面板底上正文 ≥ 4.5:1；`--text-low` 只用于可推断的辅助信息；
品质/阵营色用于小号文字时必须取 `-text` / `-bright` 变体。

### 5.2 色彩之外的通道

- 品质：颜色 + ★ 数量（1–4）+ 边框渐变强度，三通道冗余。
- 阵营：颜色 + 徽记单字（魏/蜀/吴/群）。
- 资源增减：颜色 + 明确的 `+ / -` 符号。
- 温度：颜色 + 数字 + 趋势箭头 + 文案（"距冻结 2°"）。

### 5.3 语义与播报

- 资源区包 `aria-live="polite"`，播报节流 ≥ 5s 一次且只报显著变化。
- 寒潮/崩溃横幅 `role="alert"`（assertive），即时播报。
- 纯装饰图标 `aria-hidden="true"`，交互元素必有可见文字或 `aria-label`。
- 全屏罩层（气氛罩/红晕/粒子）全部 `aria-hidden` + `pointer-events: none`。
- 进度条用原生语义（`role="progressbar"` + `aria-valuenow`）。

### 5.4 动效与偏好

- `prefers-reduced-motion: reduce`：tokens 层已把所有 `--dur-*` 压到 1ms、
  环境循环与警报闪烁归零；寒潮改为**静态**红晕常亮（信息不丢，只去运动）；
  风雪粒子 canvas 由 JS 检测同一 media query 后直接不启动。
- `prefers-contrast: more`：tokens 层自动加深描边、提亮次要文字、撤掉
  气氛罩与玻璃模糊。

## 6. 动效规范

### 6.1 时长与曲线

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dur-1` 100ms | 悬浮变色、按压 scale(0.97) |
| `--dur-2` 180ms | 淡入淡出、tooltip、tab 切换 |
| `--dur-3` 280ms | 面板/抽屉/Modal 开合（配 `--ease-out`；小元素弹入配 `--ease-spring`） |
| `--dur-4` 480ms | 场景级转场、危机罩淡出、战报展开 |
| `--dur-amb` 2.4s | 环境呼吸循环基准 |
| `--ease-out` | 一切入场（快到慢，先见内容） |
| `--ease-in` | 一切退场 |
| `--ease-spring` | 仅限 ≤ 80px 小元素（徽章、toast、掉落），大面板禁用防晕动 |

### 6.2 环境循环（常驻，各 ≤ 1 层）

| 动画 | 载体 | 说明 |
| --- | --- | --- |
| `--anim-ember-flicker` | 火炉辉光伪元素 | 不规则 8 帧摇曳，opacity-only |
| `--anim-cold-breathe` | `--clime-veil` 罩层 | cold/freeze 带启用 |
| `--anim-crisis-breathe` | 危机红晕罩 | 仅寒潮期 |
| 风雪粒子 | 单 canvas | 粒子数上限 120（窄屏 60），tab 失焦暂停 |

### 6.3 性能红线

- 只动 `transform` 与 `opacity`；禁止对大元素动画 `box-shadow` /
  `filter`——辉光呼吸一律做成"伪元素预渲染阴影 + opacity 动画"。
- `backdrop-filter` 表面全屏同时 ≤ 3 块（顶栏、底坞、一个弹层）。
- 全屏罩层同时最多 2 层（气氛罩 + 危机罩），且都 `pointer-events: none`。
- `will-change` 只允许出现在抽屉与 Modal 开合期间，用后移除。
- 数字滚动用 rAF 插值 300ms，禁用逐字符 DOM 重排。

---

## 7. Token 消费约定（给 layout / panels）

- 只引用变量，不写裸色值、裸时长；新色先进 tokens 再使用。
- 品质/阵营样式通过 `data-quality="blue|purple|orange|red"` /
  `data-faction="wei|shu|wu|qun"` 属性选择器映射到 `--q-*` / `--f-*`，
  与 `js/config.js` 枚举字面量一致。
- 主题切换只经由 `<html data-temp data-crisis>` 两个属性，UI 组件不得
  自行侦测温度写内联样式。
- 全部数字容器：`font-family: var(--font-num); font-variant-numeric: tabular-nums;`
- 焦点样式禁止覆盖，统一吃 tokens 的 `:focus-visible` 与 `--focus-ring`。
