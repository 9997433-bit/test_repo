# 时尚百货城 · 产品规格（SOTA 契约）

## 1. 产品定位

网页端、移动优先的女性向超休闲放置经营游戏。玩家扮演事业受挫后刮中刮刮乐、意外接手整座百货城的女主角，从一家快餐店起步，盘活服装店 / 生鲜 / 潮玩 / 占卜等业态，最终成为商业女王。

参考原作（爱的番茄《时尚百货城》，2026 上线）：店铺经营 + 轻量小游戏 + 伙伴数值养成 + 换装家装 + 放置离线收益。本实现是独立致敬作品，不使用原作素材、商标或版权资源。

## 2. 核心循环

```
限时经营目标 → 店铺产出 / 小游戏爆点 → 升级店铺与主角
→ 解锁新店与伙伴 → 委派加成 → 关卡研发吃资源
→ 换装/家装提供魅力与离线加成 → 更高收入
```

三大收入：店铺（基础+小游戏）、关卡研发、影视城（后期可做成轻量模拟）。
三大养成：伙伴（休闲/购物/丽人/娱乐）、主角阅历、装扮魅力。

## 3. 必须落地的系统（P0）

1. **开场叙事**：刮刮乐中奖 → 取名 → 初次换装 → 接手快餐店。
2. **商场地图**：2D 俯视百货城，店铺可点击进入；未解锁店灰态 + 解锁条件。
3. **店铺**：快餐店、生鲜超市、服装店、盲盒潮玩、占卜店。每店：等级、员工槽、自动经营开关、特色小游戏。
4. **快餐小游戏**：按订单组装汉堡/薯条/饮品/蛋挞（沙威玛式点击流水线）。
5. **生鲜小游戏**：接物进货 + 上架。
6. **服装店小游戏**：根据顾客描述选风格标签，再选搭配方案。
7. **盲盒 / 占卜**：开盒稀有度、简易占卜转盘，奖励招募碎片。
8. **放置**：在线 tick + 离线结算（上限 8 小时），员工满员可自动经营。
9. **伙伴**：招募、升级、晋升、按特长委派店铺。
10. **换装**：发型/上装/下装/鞋/饰品，魅力影响客流。
11. **家装**：豪宅房间摆放家具，部分家具加离线收益。
12. **突发事件**：失物招领、抓小偷、顾客求助。
13. **存档**：localStorage，导出/导入 JSON。
14. **主角等级**：阅历 + 累计收入门槛解锁新店。

## 4. P1（Round 2+）

影视城拍摄与联动模拟、宴会人气、名媛会排行榜（本地假数据即可）、商战阵容、工厂研发关卡完整数值曲线。

## 5. 视觉与体验 SOTA 标准

- 明亮通透：奶油白 + 玫瑰金 + 珊瑚粉 + 薄荷绿点缀。
- 圆角卡片、柔光阴影、微动效（入场 240–360ms，弹性 1.05）。
- 中文 UI，字号层级清晰，移动 390×844 与桌面 1280 双端可用。
- 无障碍：焦点环、对比度 AA、关键操作键盘可达。
- 60fps 主界面；小游戏不掉到 30fps 以下。
- 音效用 Web Audio 合成，不依赖外部音频文件。

## 6. 技术约束

- 目录：仅 `games/fashion-mall/`。
- 零构建或极简静态：ES modules，`npx serve` 或 `python -m http.server` 可玩。
- 不引入 React/Vue/大型打包器（保持与未来其他游戏并列的轻量）。
- 测试：Node 原生 runner（`node --test`），不强制浏览器 E2E。
- 禁止付费诱导、真实抽奖、外部账号。

## 7. 数值骨架（可被 F3 覆写）

- 快餐店基础产出：`12 * 1.18^level * (1 + staff*0.12) * (1 + partnerBonus) * (1 + charm*0.002)` 金/秒
- 离线：`onlineRate * 0.65 * min(hours, 8)`
- 主角升级：收入门槛 `[0, 800, 4e3, 2e4, 1e5, 6e5, 3e6]`
- 伙伴特长匹配：+60% 店收入；错配 +15%
- 自动经营：员工槽满即可开
