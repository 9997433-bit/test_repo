# fable-4 — UX / 视觉 SOTA 规格（Round 1）

> 交付对象：opus-4（UI 实现，拥有 `index.html` / `css/**` / `js/ui/**` / `assets/**`）。
> 本文档是**可直接落地**的规格：token 可整段粘贴进 `:root`，时间轴精确到毫秒，线框对应 GDD 第 4 节六 Tab 信息架构。
> 所有 ASCII 线框为示意图（CJK 双宽字符导致对齐非像素精确），以标注的 px 值为准。
> 优先级标记：**P0** = Round 1 必须、**P1** = Round 2 补齐、**P2** = 可砍。

---

## 0. 设计北极星（SOTA 的定义）

1. **每次点击都有反馈**：按压、音效（可选）、粒子、数字滚动，反馈延迟 < 100ms。
2. **稀有即演出**：品质越高，揭示演出越长越夸张（六档分级），玩家形成「赌一锤」的期待感。
3. **三分钟上手**：首屏即锻造炉，首锤 → 上阵 → 首战全程有视觉引导，无文字墙。
4. **国风暗金一致性**：墨底、鎏金描边、朱砂点缀；任何新元素必须取自本规范 token，禁止硬编码色值。
5. **60fps 或降级**：动效全部走 `transform` / `opacity` / canvas，尊重 `prefers-reduced-motion`。

**硬性规则（供 code review）**：
- 禁止在组件 CSS 中出现裸 hex；一律引用 token。
- 所有数字显示容器加 `font-variant-numeric: tabular-nums;`（资源条、战力、倒计时防跳动）。
- 动效只用 `transform`/`opacity`/`filter`；布局属性（width/top/margin）禁止参与动画。
- 品质色**永不单独承载信息**：品质必须同时有「色 + 中文字徽章（凡铁/精钢/玄兵/紫霄/传说/神话）」。
- 元素色同理：火/冰/雷 各配固定形状图标（火=焰形▲、冰=六角✻、雷=折线⚡），色弱可辨。

## 2. 布局系统（App Shell）

- 移动优先 390×844；桌面居中 `max-width: 430px`，外侧显示 `--bg-vignette` 氛围底。
- 结构：顶部资源条（sticky，`--topbar-h` + `--safe-top`）→ 内容滚动区 → 底部 Tab（sticky，`--tabbar-h` + `--safe-bottom`）。
- 内容区左右留白 `--sp-4`，区块间距 `--sp-6`。
- 顶部资源条按 Tab 上下文显示 3–4 个资源（工坊显铜钱/精铁/体力，试炼显体力/铜钱，竞技显玄晶），点资源数字弹出全部资源浮层。

## 5. 无障碍（P0，验收必查）

1. **`prefers-reduced-motion: reduce` 替代表**（必须逐项实现）：

| 原动效 | 降级为 |
| --- | --- |
| 屏幕震动/锤击震屏 | 取消位移，仅保留砧面单帧亮度变化 |
| 粒子（火星/光雨/碎裂） | 全部关闭，canvas 只画静态光晕 |
| 卡片翻转 | 直接交叉淡入淡出 240ms |
| 弹道飞行 | 省略飞行，仅命中处单次光斑 + 伤害数字 |
| 数字滚动 | 直接落定终值 |
| 呼吸光/流光 | 静态弱光晕（不循环） |
| `navigator.vibrate` | 不调用 |

2. **对比度**：正文用 `--text-hi/mid`（≥8:1）；`--text-low` 仅用于占位与禁用；品质/元素信息必须「色+形+字」三通道（见 §1 硬性规则）。
3. **触控目标**：一切可点 ≥ `--tap-min`(44px)；底部 Tab 每项实际热区 = 整列高 56px。
4. **键盘/焦点**（桌面兜底）：`:focus-visible` 统一 2px `--gold` 外描边 + 2px offset；modal/抽屉焦点圈闭（focus trap），`Esc` 关闭；网格内方向键移动、`Enter/Space` 激活。
5. **ARIA**：底部 Tab 用 `role=tablist/tab/tabpanel` + `aria-selected`；资源变动区 `aria-live="polite"`；锻造结果播报 `aria-live="assertive"`（「锻得 紫霄·青霜，攻击 420」）；战斗逐帧 log **不**进 live region（噪音），仅战斗结果播报；进度条用 `role=progressbar` + `aria-valuenow`。
6. **文本缩放**：全部字号 token 落地为 `rem`；200% 缩放下不横向溢出（卡片网格自动降列）。
7. 拖拽上阵必须有**点选等价路径**（§3.3），长按预览必须有**详情按钮等价路径**。

## 7. 错误态（禁止裸 alert，全部走统一组件）

| 错误 | 呈现 | 恢复路径 |
| --- | --- | --- |
| 资源不足（锻造/强化/扫荡） | 按钮不禁用，点击后：按钮左右晃动 ±6px 240ms + 资源条缺口项红闪 2 次 + toast「精铁不足，还差 8」 | toast 附 [去获取]，跳到产出该资源的试炼关 |
| 体力不足 | modal：「体力将于 04:12 后 +1」+ 倒计时 | CTA1 [去竞技（不耗体力）]，CTA2 [知道了] |
| 阵容为空点挑战 | 抖动 + toast「至少上阵一把兵器」 | toast 附 [去战阵] |
| 上阵中兵器点分解 | 分解按钮禁用态 + 行内说明「上阵中，不可分解」 | 详情内提供 [卸下] |
| 存档损坏（hydrate 失败） | 全屏恢复页（--z-modal）：「兵谱残卷受损」 | [导出损坏存档]（textarea 备份）/ [重铸新档]（二次确认，红色按钮） |
| localStorage 不可用/满 | 顶部常驻警示条（--warn 底）：「存档暂不可写，进度仅保留在本次会话」 | [重试写入] |
| 每日次数用尽（大师熔炉/竞技/扫荡） | 按钮变倒计时态「明日 05:00 重置」，非报错 | 无 toast 骚扰 |
| 离线收益达 8h 上限 | 挂机卡片角标「已达上限」--warn 色 + 副文案「尽快领取，炉火已满」 | 领取即清 |

统一 toast 规格：底部距 Tab 栏 `--sp-3`，`--surface-3` 底、`--r-2` 圆角、`--shadow-2`，错误态左侧 `--danger` 竖条 3px。同屏最多 1 条，后到顶替。

## 11. 可砍范围（若 Round 1 时间不够，按此顺序砍）

1. 神话兵器名毛笔字逐字描边 → 降级为逐字淡入（保留分档时长）。
2. 下拉刷新罗盘 loading → 普通转圈。
3. 拖拽上阵 → 只保留点选两步上阵（点选是无障碍兜底，本来就必须有）。
4. 长按快速预览 → 点开详情抽屉替代。
5. WebAudio 合成音 → 完全静音（vibrate 保留，成本极低）。
6. spotlight 新手教程 → 高亮脉冲 + 单按钮引导（§6 首启线已够用）。
7. 桌面键盘网格方向键导航 → 仅保留 Tab 顺序 + focus-visible。
8. 竞技防守阵容独立编辑页 → 直接复用战阵当前阵容。

**不可砍**：三锤时间轴、品质六档揭示、三套元素弹道、受击闪白+飘字、KO 慢动作、品质边框流光、空/错误态、reduce-motion 降级、概率公示。这些是「精品 vs demo」的分界线。
