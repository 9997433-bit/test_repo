# 异掌 · 安全区选掌大厅（Goal）

工作目录已隔离：`games/yizhang/`（端口 **4181**）。**禁止再复制一份游戏目录。** 禁止改 `games/` 下其他游戏。

本轮叠在手感轮之上：键鼠方向、皮肤、每掌战斗 VFX、打击感仍然有效，额外落地 **3D 安全区 → 走道选掌 → 传送门进格斗区**。

## 用户原话（必须兑现）

人物开始在**另外一个区域**，属于**安全区**。有一个**走道**，两边各**一排手套**，可以挑选。每个手套下面有个**台子**，手套**手指朝上**放置，要有**对应特效**。靠近能**选择和说明**。选完手套，通过**传送门**进入格斗区域。SOTA 级打磨。

## 空间与流程

1. **安全区（Hub）**：无击退、无掉落出局、无 Bot 袭击。出生点在走道一端（或小平台）。
2. **走道**：两侧对称摆 **8 只原创掌**（木棉/磐石/疾风/冰霜/弹簧/分身/磁掌/陨掌），每侧 4 座（或 4+4 对开）。台座有高度、磨损、识别色漆线。
3. **展示掌**：低面数几何体，掌心/手指朝上（+Y），轻微悬浮或呼吸，**idle VFX 必须能辨认是哪一只掌**（霜雾、岩屑、风带、磁弧等）。禁止纯色光球。
4. **靠近交互**：进入半径（建议 1.6–2.2m）显示名称、一句说明、主/副掌槽位提示；确认键（键鼠 E / 触控按钮）装备。未解锁的掌可见但选不中，并显示解锁条件。
5. **双掌**：沿用主+副。走道里可先选主、再选副；HUD 显示当前配装。
6. **传送门**：走道尽头（或安全区中央门洞）。未选主掌时靠近只提示「先选一只掌」。选完后穿过/确认进入 **格斗岛**（现有裂岛规则不变）。可用短过渡（淡场或门内粒子），不要加载条糊屏。
7. **回程**（Round 2+）：对局结束后可回安全区再选，不要逼玩家刷新页面。

## 验收线

- 开局相机跟在安全区角色身后，**不是**直接扔到裂岛中央。
- 8 座展示掌可走过去看、可辨特效、可装备；触控与键鼠同一套靠近+确认。
- 传送门把玩家送到现有格斗岛，Bot 只在格斗区出现。
- 视觉：底座 B，暮蓝+暖黄裂纹，饱和只给当前掌识别色。
- 测试：`npm test` 全绿；新增 hub 接近/选掌/传送用例；`npm run probe` 仍能打出 kills（可从传送后开始模拟）。
- 回归：键鼠 W=镜头前方（若手感轮已修则保持）；不碰其他 `games/*`。

## 与 2D 菜单的关系

3D 走道是**主路径**。现有 `.yz-home` 选掌板可降为暂停/设置里的备选，不要删到无法配装；但默认开局不再先弹一块平面网格再进岛。
