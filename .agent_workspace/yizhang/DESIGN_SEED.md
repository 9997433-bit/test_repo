# 异掌 · 策划种子（已与用户对齐，子代理不得推翻主循环）

这是全新游戏，不要模仿、引用或复用同仓库其他游戏的玩法、视觉、文案、架构文档。只占用 `games/yizhang/`。

## 定位

工作名 **异掌**。第三人称浮空擂台：装备会「活」的手套，扇击积掌意，主动技改写战场，把对手打出岛外。

不是 Roblox / Slap Battles 复刻：禁止官方手套名、徽章跑图、方块人审美、商标。

## 核心循环

1. 选 **2 只手套**（主掌 + 副掌）进裂岛  
2. 走位、绕背、卡边  
3. 扇击积掌意；E 放当前掌技能；Q 切换副掌（0.4s 收掌）  
4. 掌意满觉醒 8s，当前手套形态变强  
5. 扇出岛 = 击杀；自己掉落则重组，断连胜  
6. 局内挑战解锁手套，本地 `localStorage` key `yizhang-save-v1`  
7. 4 分钟或先到 7 杀  

单机 + Bot。规则按可联网写（输入 + 固定步），第一版不上服务器。

## 与同类的三处差异（必须做）

1. **双掌配装** — 主副切换，拼组合  
2. **掌意觉醒** — 扇/被扇/技能命中加条，满条 8s 强化  
3. **台面碎裂** — 重击让地面裂、塌，边线会变  

## 操作

| 输入 | 行为 |
| --- | --- |
| WASD / 左摇杆 | 移动，有惯性 |
| 鼠标 / 右空白拖 | 转向+相机 |
| 左键 / 右下大钮 | 扇击，有前摇后摇 |
| E / 技能钮 | 当前掌主动技 |
| Q / 换掌钮 | 主副切换 |
| Shift / 冲刺钮 | 短冲 |
| 空格 / 跳钮 | 轻跳 |

禁止锁敌自动瞄。打空有后摇。横屏优先；竖屏能玩。触控最小 48dp，扇击 72dp。安全区 `env(safe-area-inset-*)`。DPR 封顶 2。画质 high/mid/low 自动测 2s。
