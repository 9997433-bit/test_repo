# 兵器王者 — 游戏设计文档（原创致敬实现）

> 本作为原创网页游戏，玩法向「兵器王者」类国风放置锻造小游戏致敬，不复制任何官方素材、文案或商标资源。

## 1. 一句话卖点

你是少年铁匠，在火、冰、雷三相炉火中寻器、造器、用器，集齐神兵、克制强敌，成为兵器王者。

## 2. 核心循环

```
挂机/试炼掉落材料 ──► 锻造兵器（精铁→白银→黄金）
        ▲                        │
        │                        ▼
   竞技/分解回收 ◄── 上阵自动战斗（火克冰克雷克火）
```

## 3. 系统规格

### 3.1 资源

| ID | 名称 | 来源 |
| --- | --- | --- |
| `coin` | 铜钱 | 挂机、战斗、分解 |
| `iron` | 精铁 | 普通试炼 / 挂机 |
| `silverOre` | 秘银 | 精英试炼 |
| `goldOre` | 赤金 | 高阶试炼 / 竞技 |
| `fireCrystal` / `iceCrystal` / `thunderCrystal` | 三相晶 | 对应元素关卡 |
| `luckyCharm` | 幸运符 | 每日 / 兑换 |
| `stamina` | 体力 | 上限 120，每 6 分钟 +1 |
| `diamond` | 玄晶 | 成就 / 竞技（非强付费墙） |

### 3.2 品质

`common < uncommon < rare < epic < legendary < mythic`

中文：凡铁 / 精钢 / 玄兵 / 紫霄 / 传说 / 神话

颜色：灰 / 绿 / 蓝 / 紫 / 橙 / 红金

### 3.3 元素

循环克制：`fire → ice → thunder → fire`

克制伤害倍率：`1.35`；被克：`0.75`；同属：`1.0`

每把兵器主元素 1 个，可洗出副元素词条。

### 3.4 兵器原型（图鉴至少 24 把）

必须覆盖：剑、刀、枪、戟、弓、弩、斧、锤、扇、笛、伞、戟刃、以及 4 把神话神器。

每把兵器字段：

```
id, name, title, type, element, baseAtk, baseHp, skillId,
forgeStage, lore, tags[]
```

### 3.5 锻造

三阶段：`iron`（精铁炉） / `silver`（白银炉） / `gold`（黄金炉）

- 消耗对应矿 + 可选晶石（指定元素偏向）+ 可选幸运符（品质权重上移）
- 大师熔炉：每日 1 次，史诗+权重 ×1.8
- 锤击演出：3 锤；第 3 锤揭示品质与词条
- 词条池：元素伤害、暴击、吸血、连击、减伤、速度、反伤
- 强化：消耗同品质碎片/铜钱，每 3 级解锁 1 技能槽（最多 3）
- 分解：返还 60% 材料

### 3.6 战斗（自动、可跳过）

- 玩家上阵 1–5 把兵器（阵容栏位随进度解锁：1/2/3/4/5）
- 敌方关卡波次 1–3，BOSS 有元素与技能
- 回合制速度条：`speed` 决定行动顺序
- 技能：主动（CD）+ 被动羁绊（同类型 ≥2、同元素 ≥3、神话 1 把即可触发「兵魂」）
- 战报时间轴 + 画布层元素弹道

### 3.7 关卡 / 寻器

- 主线试炼 40 关，每 5 关一个精英 BOSS
- 挂机：按已通关最高关卡产出，离线最多结算 8 小时
- 每日普通试炼 2 次免费；精英需战力门槛

### 3.8 竞技场

- 本地镜像：根据玩家战力生成 20 名 AI 对手
- 进攻消耗 0 体力，每日 5 次；奖励玄晶与赤金
- 排名积分 ELO-lite

### 3.9 元系统

- 图鉴：收集度加成（全图鉴 ATK/HP 最多 +15%）
- 成就 / 七日目标
- 设置：音效开关、战报速度、重置存档
- 本地 `localStorage` 键：`bqwz.save.v1`

## 4. 界面信息架构

1. **炉火工坊**（Home）：锻造、挂机领取、今日熔炉
2. **试炼**（Campaign）：关卡地图、扫荡
3. **战阵**（Lineup）：5 栏拖拽上阵、羁绊预览
4. **图鉴**（Codex）：筛选元素/类型/品质
5. **竞技**（Arena）：对手列表、防守阵容
6. **背包**（Bag）：强化、符文、分解

底部 Tab + 顶部资源条。移动优先（390×844），桌面居中最大 430px 卡片。

## 5. 视觉与音频方向（SOTA）

- 国风暗金：墨底 `#0b0a09`，朱砂 `#c23a2b`，鎏金 `#e4b84a`，青冰 `#7ec8e3`，雷紫 `#9b6bff`
- 锻造：锤击震动、火星粒子、炉心呼吸光
- 品质：边框流光 + 揭示卡翻转
- 战斗：火团 / 冰晶碎裂 / 雷链，受击闪白，KO 慢动作
- 字体：系统宋/楷 fallback 栈，标题用衬线
- 动效 60fps，尊重 `prefers-reduced-motion`
- 音频可选：用 WebAudio 合成锤击/克制音（禁止外部版权曲）

## 6. 数值目标

- 新手 3 分钟内完成：首次锻造 → 上阵 → 打过第 1 关
- 无付费可在 40–60 分钟推到第 20 关
- 战力公式：`sum(atk * (1+crit*0.5) * elementMod) + hp*0.15 + setBonus`
- 所有随机必须可注入 `seed`（测试与回放）
