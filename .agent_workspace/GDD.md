# 超能下蛋鸭 · 游戏设计文档（基线）

## 一句话

搞怪鸡鸭鹅天团的重力弹球卡牌肉鸽：滑动瞄准、蓄力下蛋，用物理反弹与流派羁绊把战场打成蛋液烟花。

## 参考原型（非克隆商标）

《超能下蛋鸭》（娱公互动 / 假面科技）= 重力弹球（Peggle / 弹珠） + 英雄卡牌技能 + 单局肉鸽构筑 + 关卡/爬塔/讨伐/钓鱼。  
本复刻为独立网页作品，角色名为戏仿原创（避免官方商标素材）。

## 核心循环

1. 主菜单组 5 人禽类小队（或肉鸽内三选一）
2. 进入关卡：顶部发射台，底部/两侧敌人与砖块
3. 滑动瞄准 + 蓄力 → 当前英雄竖直向下偏转发射「超能蛋」
4. 蛋受重力、墙壁、钉板、斜面反弹；命中敌人掉血，可分裂/爆炸/穿透/附魔
5. 连击与元素反应叠层；英雄大招按能量释放
6. 清场结算金币/碎片 → 升级进化 → 下一关或切换模式

## 操作

| 输入 | 行为 |
| --- | --- |
| 鼠标拖拽 / 触摸滑动 | 瞄准角（默认朝下，左右各限 ±70°） |
| 拖拽距离 / 空格蓄力 | 初速度 220–720 px/s |
| 松开 | 发射 1 枚主蛋 + 英雄被动可能的额外蛋 |
| Q / 点击大招 | 释放当前英雄技能（需能量） |
| 1–5 | 切换上场英雄（冒险模式） |
| R | 重新瞄准（蛋落地/出界后） |
| Esc | 暂停 |

瞄准须绘制虚线预测弹道（最多 3 次反弹预览）。

## 物理

- 世界：480×800 逻辑坐标，左右墙、顶板发射口、底板回收。
- 蛋：半径 10–14，弹性 0.78–0.92，空气阻力极低，重力 1680。
- 静态体：砖（可碎 HP）、钉（圆形钉，改变方向）、斜面、传送门、炸弹砖、冰面（低摩擦）、风扇（加速度场）。
- 连锁：分裂蛋继承 0.7 速度；爆炸对半径内敌人与砖结算。
- 出界：蛋 y>820 或静止 <8px/s 连续 0.6s → 回收，回合结束。

## 流派与羁绊

| 流派 | 核心机制 | 适合 |
| --- | --- | --- |
| 连击流 combo | 短间隔命中叠 Combo，每层 +6% 暴击伤，满 20 层触发「爆蛋时刻」 | BOSS |
| 直殴流 brute | 主蛋伤害 ×1.25，击退砖块，稳定清图 | 开荒 |
| 属性流 elemental | 火/冰/雷残留与反应（灼烧、冻结、感电扩散） | 群怪 |
| 碰撞流 collide | 蛋与蛋、蛋与钉的碰撞次数转化为额外伤害与分裂 | 钉板图 |

2 同流派激活小羁绊，3 同流派激活大羁绊，4+ 激活「禽王光环」。

## 元素反应

- 火+冰 = 蒸发，伤 ×1.4 并移除冻结
- 雷+冰 = 超导，破甲 8s
- 雷+火 = 超载，小爆炸
- 同元素 3 层：火持续灼烧、冰冻结 1.2s、雷弹跳 2 次

## 敌人

- 史莱姆砖怪、飞行鸽盗、盔甲猪、钉盾蟹、回复图腾、精英「厨子狐」、BOSS「魔王油锅」「海神雕像」「机械孵化器」。
- 敌人有 HP、护甲、元素抗性、接触伤害（漏到发射台扣玩家生命）。
- 部分敌人会移动或在回合间隔放技能。

## 模式

1. **冒险关卡** 24 关，6 章主题：农场晨曦、夜市霓虹、火山温泉、冰川港、电路都市、魔王厨房。每章末 BOSS。
2. **极限挑战（肉鸽）**：不能带自己的养成，每 2 波三选一英雄/神器；无尽波次，本地排行。
3. **试炼之塔**：30 层，可扫荡已通层（快速结算资源）。
4. **讨伐魔王**：60s 挑战，魔王无限重生且成长，按总伤害发档位奖。
5. **佛系钓鱼**：3 海域，节奏小游戏钓怪物球，给战斗临时 BUFF（攻/暴/蛋数）。

## 养成

- 金币升级等级 1–40（基础攻/蛋半径/能量回复）。
- 碎片升星 1–5（解锁技能词条）。
- 图鉴收集度提供全局 0–15% 攻击。
- 公平：无内购。

## 关卡内道具

炸弹、冰锥、多重蛋、磁铁（吸向敌人）、时间减缓、钉板刷新。

## 失败 / 胜利

- 胜利：本波敌人清零。
- 失败：玩家生命 ≤0（漏蛋/敌人接触累积）或肉鸽全灭。
- 评分：连击峰值、用时、剩余生命、砖块清扫率。

## 音频与手感（SOTA）

- WebAudio 合成：发射啵、撞墙嘀、爆蛋、连击升调、BOSS 鼓点。
- 屏幕轻震、命中停顿 30ms、飘字、轨迹残影。
- 色盲友好：元素不只靠色相，附带图标。
- 减少动态可关。
